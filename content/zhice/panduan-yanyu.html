怎么用这份手册：不要通读。刷题时遇到某类题卡壳，直接翻到对应框架，按「识别标志 → 思考路径」一步步走一遍；做错的题在「高频陷阱」里找到对应条目，用红笔在错题本上标出来。考前 3 天只翻「判定标准」和「高频陷阱」两块。

模块一 · 判断推理

目标用时 24—28 分钟 ｜ 目标正确率 80% ｜ 题量通常 30—35 题（图形 5—6、定义 8—10、类比 8—10、逻辑 8—10）

A. 图形推理（6 份框架）

1图形推理 · 总判定链（先背这一条）

识别标志题干给出一组图形（顺推型 / 九宫格 / 分组分类 / 空间折叠）
思考路径（严格按顺序，不可跳步）
  1. 看元素是否相同：组成元素完全一样 → 位置类（平移/旋转/翻转）
  2. 看元素是否相似：外形相似、局部有变化 → 样式类（加减同异/黑白叠加/遍历）
  3. 看元素是否凌乱：差异大 → 数量类（点线面素角笔）
  4. 数量无规律 → 属性类（对称/曲直/封闭开放）
  5. 以上都无规律 → 考虑特殊：一笔画、重心、相对位置、功能元素标记、图形间相对关系
判定标准速记口诀
相同看位置，相似看样式，凌乱看数量，数量不通看属性。
顺推型：从左到右找递变；九宫格：先横行、后竖列、再米字/对角；分组分类：找"三三一致"的共同属性。
选项处理不要一个一个套，先用规律画出"下一幅图应该长什么样"的草图，再去选最像的。两套规律难分时，选覆盖面更广（能解释更多已知图）的那个。
高频陷阱
  • 一上来就数数，忽略了明显的旋转/翻转——先扫一眼位置。
  • 九宫格只横看不看竖列，漏掉"每行之和相等"型。
  • 把"对称轴的数量"和"对称轴方向"混为一谈，实际常分开考。
  • 分组分类题当成顺推题，找递推关系找半天。

2位置类（平移 / 旋转 / 翻转）

识别标志每幅图元素完全相同，只是位置/朝向变了
思考路径
  1. 锁定一个标记元素（最显眼/最角落的黑块或小图形），盯住它的移动轨迹。
  2. 平移：步数是恒定（1、2、3…）还是递增（1、2、3、4）？方向是顺/逆时针还是左右上下？走到头是循环还是反弹？
  3. 旋转：顺时针 / 逆时针，角度是 45°、90° 还是 180°。
  4. 翻转：横轴翻转 / 纵轴翻转（翻转后的图和原图成镜像，不能用旋转得到）。
  5. 多元素：分别验证每个元素，可能各走各的。
判定标准 平移：步数恒定/递增 + 方向固定 旋转：角度恒定 翻转：横/纵轴对称 循环 vs 反弹看首尾
高频陷阱混淆"整体旋转 180°"与"横向翻转+纵向翻转"——两者结果一样，但题目若只写旋转，中间步骤要一致；另外时针方向可区分旋转和翻转：旋转不改变时针方向，翻转改变。
示例演示 黑块在九宫格外圈每次顺时针走 1 格，内部白块每次逆时针走 2 格 → 下一步分别推 1 格、2 格，画草图直接匹配。答案 = 外圈黑块顺时针 1 格且内部白块逆时针 2 格的选项。

3样式类（叠加 / 遍历 / 加减同异）

识别标志图形外形相似，局部增减变化；或九宫格每行元素种类相同
思考路径
  1. 先看是不是遍历：每行/每列出现的元素种类一致，只是排列不同（缺什么补什么）。
  2. 再看加减同异：图 3 = 图 1 + 图 2？图 1 − 图 2？"同去异留"还是"异去同留"？
  3. 黑白叠加：白+白、白+黑、黑+白、黑+黑 四种组合分别等于什么，逐格验证。
判定标准 遍历：每行元素种类和数量相同 叠加：第三幅 = 前两幅按规则合成 黑白叠加：先定 4 种组合规则，再套全图
高频陷阱黑白叠加只验证了 1—2 格就下结论，实际规则是"白+黑=黑、黑+白=白"（有顺序，不可交换）；九宫格叠加常是"行内叠加"而不是"逐列叠加"。
示例演示九宫格前两格：图1 白+白=白，白+黑=黑，黑+白=白，黑+黑=白 → 得到第三格。答案 = 符合该四规则合成的选项。

4数量类（点、线、面、素、角、笔画）

识别标志图形凌乱、差异大、无明显位置/样式关系
思考路径（按命中率顺序试）
  1. 面（封闭区域数）—— 最常见、最快，优先数。
  2. 线：直线数 / 曲线数 / 总线条数。内外分开数。
  3. 点：交点、切点、顶点、出头点；内外交点分开数。
  4. 角：直角数、锐角数（较少单独考）。
  5. 素：元素种类数、元素个数、部分数（连通块数）。
  6. 一笔画：数奇点（从该点出发的线条数为奇数），奇点数 = 0 或 2 → 一笔画；笔画数 = 奇点数 ÷ 2。
判定标准数量型答案通常是常数数列、等差、或两项求和=第三项；九宫格常是"每行数量之和相等"或"行内等差"。
选项处理数量类四个选项数字差异明显时，先数 1—2 幅图就能排除两个选项，不要全数完。
高频陷阱
  • 数"面"时把背景外的大空白也算进去（只数封闭区域）。
  • 数"线"时没区分直线/曲线，实际考的是"曲线数"。
  • 一笔画忘数"端点"也算奇点（端点出发线条数为 1，是奇点）。
示例演示三幅图封闭区域数为 1、3、5 → 等差 2 → 下一幅应为 7 个面。答案 = 含 7 个封闭区域的选项。

5属性类（对称 / 曲直 / 封闭开放）

识别标志数量怎么数都没规律；图形看起来"规整""有美感"
思考路径
  1. 对称性（最高频）：是否轴对称？是否中心对称？对称轴条数是多少？对称轴方向（横/竖/斜）？相邻图对称轴是否依次旋转 45°？
  2. 曲直性：全直线 / 全曲线 / 直曲混合。
  3. 封闭开放性：全封闭 / 全开放 / 半开半闭。
判定标准属性类常考"分类"：①②③ 一组轴对称、④⑤⑥ 一组中心对称。
高频陷阱把"既是轴对称又是中心对称"的图（如正方形、圆）只归入一类；注意正六边形有 6 条对称轴、正三角形 3 条。
示例演示对称轴方向依次是 竖、横、左斜、右斜 → 循环 → 下一幅回"竖"。答案 = 对称轴为竖直方向的选项。

6空间重构（六面体折叠）

识别标志给出平面展开图，问折叠后哪个立体图正确 / 或给立体图问展开图
思考路径（两套方法，二选一）
  1. 相对面法（先做）：展开图中相隔一个面（中间隔一格）或同一直线间隔一个的两个面是相对面 → 立体图中相对面永远不能相邻。据此可直接排除 1—2 个选项。
  2. 时针法 / 相邻面法（再做）：锁定三个相邻面，看它们在展开图中的顺时针排列顺序；折叠后这个顺序不变。选项里顺序反了 = 错。
  3. 或公共边法：两个相邻面的公共边，看各自图案在公共边的哪一端。
判定标准立体图中同时出现的三个面，必须能在展开图中找到对应的"三面相邻关系"且时针方向一致。
高频陷阱把"相对面"当成"相邻面"；只看图案不看图案的朝向（箭头朝上还是朝下）；跳过了"相对面排除"直接硬折，浪费 1 分钟。
示例演示展开图中 A 与 D 隔一格 → 相对面；选项中 A 与 D 出现在相邻两个面上 → 直接排除。答案 = 剩余选项中三面时针方向与展开图一致者。

B. 定义判断（2 份框架）

7定义判断 · 单定义（含做题标准动作）

识别标志"下列属于/不属于××的是"，给出一个定义
思考路径（八要素拆分法）
  1. 先读问法：是"属于"还是"不属于"——用笔圈出来，很多错在这里。
  2. 拆定义，抓八要素：①主体 ②行为/方式 ③客体 ④目的 ⑤原因 ⑥条件 ⑦结果 ⑧性质。
  3. 把每个要素前圈 "不" 字：主体不是××、目的不是××、条件不满足××……这就是排除依据。
  4. 拿选项逐要素比对，违反任意一个硬性要素（尤其主体、目的、条件）即排除。
判定标准 主体不符、目的不符、条件不符 → 必错。三个是符合性判断中最硬的"一票否决"项；结果、方式有时会放宽。
选项处理选"最符合"时用符合要素最多原则；选"最不符合"时找明确违反硬要素的那个，而不是"没提到"的那个（没提到 ≠ 违反）。
高频陷阱
  • "不属于"看成"属于"（最高频，约 30% 的失分来自这里）。
  • 选项里加了定义没有的新条件，考生自己脑补觉得合理就选了。
  • 定义里的"除外条款"（"……的除外""但……不在此列"）被忽略。
  • 把"举例说明"当成定义要件。
示例演示定义："行政指导：行政机关为实现行政管理目的，以建议、劝告等非强制方式……"
选项：某市法院建议企业合规 → 主体不符（法院非行政机关）→ 不属于，排除。

8定义判断 · 多定义

识别标志题干给出 2—3 个相关定义（常为种属或相反关系）
思考路径
  1. 先看问法问的是哪一个定义，只精读那一个。
  2. 其余定义快速扫一眼抓差异点即可，不必拆全要素。
  3. 关键：找出几个定义之间的区分要素（通常就在主体或目的上），用它排雷。
高频陷阱选项对应的是另一个定义，看起来非常符合，但问的不是它——这叫"张冠李戴"，是多定义题第一大坑。
示例演示给出"正迁移"与"负迁移"，问"属于负迁移的是" → 选项"学会骑自行车后更容易学电动车"是促进作用 → 属于正迁移，正是陷阱项，排除。

C. 类比推理（3 份框架）

9类比推理 · 两词型 / 三词型

识别标志"×× 对于 （） 相当于 （） 对于 ××" 或 "A：B" / "A：B：C"
思考路径（先语义，后逻辑，再语法）
  1. 语义关系：近义 / 反义 / 比喻象征（如"鸿雁：书信"）。
  2. 逻辑关系（命中率最高）：
    • 全同（土豆：马铃薯）
    • 包含（种属：苹果：水果）／（组成：轮胎：汽车）← 必须区分
    • 交叉（党员：医生）
    • 并列（矛盾：生：死）／（反对：红：蓝）
    • 顺承（报名：考试：录取）
    • 因果（地震：房屋倒塌）
    • 目的（学习：提升能力）
    • 条件（氧气：燃烧）
    • 职业—工具／对象／场所（医生：手术刀／病人／医院）
    • 成品—原料（面包：面粉）、物品—功能（钥匙：开锁）
  3. 语法关系：主谓、动宾、偏正、并列结构。
判定标准 · 二级辨析（排除两个选项后用） 词性一致感情色彩（褒/贬/中）程度轻重必然/或然主动/被动自然物/人造物同一领域
选项处理先定一级关系（把 A:B 造一个句子），能淘汰两个；剩下两个用二级辨析；还有两个就把句子造得更细（"医生用手术刀给病人做手术" vs "老师用粉笔给学生讲课"）。
高频陷阱
  • 包含关系混淆："苹果：水果"是种属（苹果是一种水果），"轮胎：汽车"是组成（轮胎是汽车的一部分）——判断口诀："××是一种××"成立 = 种属；"××是××的一部分"成立 = 组成。
  • 顺序颠倒：题干是"原因：结果"，选项是"结果：原因"。
  • 只看语义忘了逻辑（近义词不一定逻辑关系相同）。
示例演示"医生：手术刀"→ 造句"医生用手术刀"。A. 木匠：锯子（木匠用锯子 ✓）；B. 学生：书包（学生用书包？书包不是专业工具 ✗）。答案 = A（职业—专业工具，二级辨析"专用工具"胜出）。

10类比推理 · 填空型

识别标志"×× 对于 （ ） 相当于 （ ） 对于 ××"
思考路径
  1. 必须把选项逐一代回，读成完整两句话。
  2. 先验证关系是否一致，再验证前后顺序是否一致。
  3. 常见错误：关系对但顺序反了——题干是"工具：职业"，选项代回后变成"职业：工具"。
高频陷阱只代入前一半觉得对就选，没检查后一半；或前后都代入了，但没核对方向。
示例演示"手术刀 对于 （ ） 相当于 （ ） 对于 教师"
代入 A：手术刀对于医生相当于粉笔对于教师 → 前句"医生的工具是手术刀"，后句"教师的工具是粉笔" → 顺序一致、关系一致 → 选 A。（若选项为"粉笔：医生"，代回后前后方向相反，错。）

11类比推理 · 提速与取舍

思考路径
  1. 类比是整张卷最该抢时间的题，平均每题 25—30 秒。
  2. 30 秒内定不下一级关系 → 立刻用"造句法"强行造一个最普通的句子。
  3. 还是纠结 → 凭语感 + 词性一致直接选，不回头。
高频陷阱在类比上反复纠结 2 分钟，把资料分析的时间吃掉了——类比一题的分和资料分析一题的分一样，但后者确定性强得多。

D. 逻辑判断（7 份框架）

12翻译推理（假言命题）

识别标志"如果…那么…""只有…才…""除非…否则…""…是…的必要条件/充分条件"
思考路径
  1. 先翻译，把题干全部写成箭头式。
  2. 再推理，只用三条规则：肯前必肯后、否后必否前；否前、肯后 → 无效，推不出。
  3. 连成链：A→B→C，则 A→C；注意箭头方向。
判定标准 · 翻译对照表
原句翻译
如果 A，那么 BA → B
只要 A，就 BA → B
只有 A，才 BB → A（A 是 B 的必要条件）
除非 A，否则 B¬A → B（等价于 ¬B → A）
A 是 B 的充分条件A → B
A 是 B 的必要条件B → A
没有 A 就没有 BB → A
A 且 BA ∧ B
A 或 BA ∨ B（至少一个成立，可同真）
不可能 A必然 ¬A
德摩根定律：¬(A 且 B) = ¬A 或 ¬B；¬(A 或 B) = ¬A 且 ¬B。
逆否命题：A → B 等价于 ¬B → ¬A（这是最常用的一招）。
选项处理把选项也翻译成箭头，看能否与题干链对接。看到"肯后推肯前""否前推否后"的选项直接排除。
高频陷阱
  • "只有 A 才 B" 翻成 A→B（应为 B→A）——最高频错误。
  • 把"A 或 B"理解为"要么 A 要么 B（排斥性）"，实际"或"是相容的，可以都成立。
  • 把"有些"当"所有"。
示例演示"只有努力工作，才能取得好成绩" → 翻译：好成绩 → 努力工作。
已知"小张没努力" → 否后 → 否前 → 小张不能取得好成绩（唯一可推出的结论）。而"小张努力了" → 肯后 → 推不出是否有好成绩。

13真假推理（矛盾关系）

识别标志给出几句话，告知"其中只有一句是真的/假的"，问能推出什么
思考路径（三步走，套路固定）
  1. 找矛盾：四句话中找一对矛盾命题（必有一真一假）。常见矛盾对：
    • "所有 S 都是 P" ↔ "有的 S 不是 P"
    • "所有 S 都不是 P" ↔ "有的 S 是 P"
    • "A 是" ↔ "A 不是"
    • "A → B" ↔ "A 且 ¬B"
    • "A 且 B" ↔ "¬A 或 ¬B"
  2. 绕开矛盾看其余：既然矛盾对中已占掉一真（或一假），那么其余的话真假已确定——若题干说"只有一真"，则其余全假；若"只有一假"，则其余全真。
  3. 回代：用确定的真假反推事实，再回头判定矛盾对谁真谁假。
判定标准矛盾关系必一真一假；反对关系（"所有都是"vs"所有都不是"）可同假不可同真；下反对关系（"有的是"vs"有的不是"）可同真不可同假。
高频陷阱找不到明显的"是/不是"矛盾时，忽略了 "A→B" 的矛盾是 "A 且 ¬B" 这一隐藏对；或把"反对"当"矛盾"。
示例演示四人中只有一人说真话：甲"是乙"、乙"是丁"、丙"不是我"、丁"乙说谎"。
乙与丁矛盾 → 必有一真 → 甲、丙皆假 → 丙说"不是我"为假 → 是丙做的。

14集合推理 / 换位推理

识别标志"所有/有些""是/不是"，几个集合之间圈圈关系
思考路径
  1. 牢记四个基本形式：所有 A 是 B / 所有 A 不是 B / 有些 A 是 B / 有些 A 不是 B。
  2. 换位规则：
    • 所有 A 是 B → 有些 B 是 A（"所有"换位后变"有些"，不能直接说"所有 B 是 A"）
    • 所有 A 不是 B → 所有 B 不是 A（可直接互换）
    • 有些 A 是 B → 有些 B 是 A
    • 有些 A 不是 B → 不能换位
  3. 递推：所有 A 是 B + 所有 B 是 C → 所有 A 是 C；"有些"开头的两个前提不能递推（推不出必然结论）。
高频陷阱"所有 A 是 B" 直接推出 "所有 B 是 A"（错误，这叫不当换位）；两个"有些"前提硬推结论。
示例演示"所有团员都是青年，有些青年是学生"。
A. 有些团员是学生 → 推不出（两个集合青年与学生关系不明，无法递推）→ 不能选。

15加强 / 削弱（论证类核心）

识别标志"最能支持/加强/削弱/反驳上述观点的是"
思考路径（固定四步）
  1. 找论点和论据：结论句（常带"因此、可见、这表明、认为"）；论据是支撑它的理由。论点才是攻击/支持的对象。
  2. 看清论证方式：是由 A 推 B（因果）？是由样本推总体（归纳）？是由类比推结论？
  3. 削弱的四条路径：
    • 削弱论点（最直接，力度最强）——直接说结论不成立
    • 削弱论据——论据本身有误/样本不具代表性
    • 削弱论证方式（拆桥）——指出论据和论点之间没有必然联系，这是考试最爱考的
    • 提出他因——有另一个原因也能导致该结果（对因果型论点削弱力度中等）
  4. 加强的四条路径：加强论点 / 加强论据（举实例、数据）/ 建立联系（搭桥）/ 排除他因。
判定标准 · 力度排序 削弱：削弱论点 > 拆桥（削弱论证） > 削弱论据 > 提出他因
加强：搭桥（建立联系）> 排除他因 > 加强论点 > 加强论据（举例）
注意："举例/类比"加强力度最弱，只在没有更强的选项时才选。
选项处理先看四个选项各自属于哪一类（削弱论点/拆桥/他因/无关），按力度排序挑最高档。与论点话题不一致的（跑题项）最先排除。
高频陷阱
  • 削弱了论据却当成削弱论点——力度比直接削弱论点弱一档。
  • 选项"另有他因"时，若题干论点是"A 导致 B"，他因只能削弱"A 是唯一原因"，不能否定 A 的因果作用，力度有限。
  • 题干问"最能支持"，看成了"削弱"（同定义判断的"不属于"陷阱）。
  • 类比加强/举例加强看似合理，但力度最弱，有搭桥项时优先搭桥。
示例演示论点："喝咖啡能降低患病风险"（论据：调查发现喝咖啡的人患病率低）。
削弱项对比：A"患病风险低的人更爱喝咖啡"（因果倒置，力度极强）；B"调查样本仅 50 人"（削弱论据）。答案 = A。另注：因果倒置是最强削弱之一，见到优先选。

16前提 / 假设型

识别标志"上述论证成立所必需的前提/假设是"
思考路径
  1. 找论点和论据，看两者之间缺什么——缺的那一环就是前提（搭桥法）。
  2. 用否定代入法验证：把选项否定后，如果论证完全崩溃，则该选项是必需前提；如果否定后论证仍成立，则不是。
判定标准前提 = 论证成立"少了就不行"的条件（必要而非充分）。用否定代入法一验即出。
高频陷阱把"能加强论证的选项"当成"必需前提"——加强项加了更好，去掉也能成立；前提项是去掉就崩的。另外选项若引入新概念而未与原文挂钩，多半是干扰项。
示例演示论据"该药在动物实验中有效" → 论点"该药对人有效"。
前提选项："动物实验结果可外推至人"。否定它 → 动物有效不代表人有效 → 论证崩溃 → 是必需前提，选它。

17日常结论 / 归纳推理

识别标志"由此可以推出/不能推出的是"（题干无明确论点，只是给一段信息）
思考路径
  1. 用"三不一可能"排除法：绝对化的不选（所有、一定、必然、唯一、只要…就）；程度过强的不选；无中生有的不选；含"可能、有些、未必"的温和表述优先选。
  2. "不能推出"型：找偷换概念 / 无中生有 / 强加因果 / 范围扩大的那一项。
高频陷阱题干说"有些"推出"所有"；题干是"可能"推出"必然"；把"相关"当成"因果"。
示例演示题干："调查显示，经常运动的人普遍心态更乐观。"
正确推论："有些心态乐观的人常运动"或"运动可能有助于心态"；"所有常运动的人都乐观" → 范围扩大，不能推出。

18解释型 / 排序匹配 / 数字推理型逻辑

识别标志"以下哪项最能解释上述现象"；"已知甲乙丙分别来自…，问对应"
思考路径
  1. 解释型：先找出题干中的"矛盾点/反常识点"（本来应该 A 结果却是 B），正确选项必须同时关照矛盾双方，只解释一方的通常不对。
  2. 排序匹配：把已知条件写成表格，用"确定信息优先"（谁的位置/身份已确定就从谁入手）→ 逐条打勾排除。
高频陷阱解释型选了"只解释了一半"的选项；排序匹配中把"最大信息优先"用在无确定信息时，导致反复试错。
示例演示矛盾："某商品价格上涨，销量却不降反增。"
正确解释："消费者预期该商品还会继续涨价，故提前抢购" —— 同时解释了"涨价"和"销量增"两面。

模块二 · 言语理解与表达

目标用时 21—26 分钟 ｜ 目标正确率 78% ｜ 题量通常 25—30 题（填空 10—15、片段 8—12、语句表达 3—5）

A. 逻辑填空（5 份框架）

19逻辑填空 · 总原则与标准动作

识别标志文段中挖 1—3 个空，给出四组词语
思考路径（标准动作，务必按序）
  1. 先读文段，不读选项——先理解语境，避免被选项带偏。
  2. 找逻辑关系：看空前空后的关联词、标点、解釋性语句，判定空处该填近义 / 反义 / 递进 / 因果中的哪一种。
  3. 预判词义：在脑子里先想一个"大概意思"，再去看选项。
  4. 以空排项：用最有把握的那个空先排除，不要试图一次定三个。
  5. 剩余选项代入通读，凭语感定夺（注意搭配是否顺口）。
判定标准 · 逻辑关系对照表
逻辑关系标志词空处要求
转折但是、然而、却、其实、尽管如此与前文语义相反
并列和、与、也、同样、并且、顿号、分号与并列成分语义相近、词性一致
递进而且、甚至、更、不仅…还语义更进一层、程度更重
因果因此、所以、导致、使得、由于填结果或原因（看空的位置）
解释即、也就是说、换言之、冒号、破折号与解释句同义
反义并列不是…而是…、要…不要…前后反义
条件/目的只有…才、为了、旨在填条件或目的
高频陷阱
  • 先看选项后读文段，被生僻词吸引，结果语义不符。
  • 只看被挖空那半句，忽略后文的解释句（解释句往往是答案直接来源）。
  • 忽略感情色彩：文段褒义却选了贬义词。
  • 忽略搭配："提高水平"对，"提升水平"也对，但"改善水平"错。

20实词辨析（四维度）

识别标志选项为意义相近的实词（动词、名词、形容词）
思考路径（四维度，按顺序比）
  1. 语义轻重：程度不同。如"缺陷 < 缺点 < 错误 < 犯罪"；"失望 < 绝望"。
  2. 搭配对象：固定搭配。如"改进方法"、"改善生活"、"提高水平"、"加强管理"。
  3. 感情色彩：褒义 / 贬义 / 中性。如"果断（褒）vs 武断（贬）"、"团结（褒）vs 勾结（贬）"。
  4. 语体风格：书面 vs 口语；正式 vs 随意。
判定标准先用搭配对象排除（最硬性），再用语义轻重和感情色彩收口。搭配不对，一定不选。
高频陷阱两个词都能讲通时，忽略了语义轻重是否与文段程度匹配（文段说"严重"却选了程度轻的词）。
示例演示"这项政策_____了群众的积极性。" 选项：A 激发 / B 激励 / C 激烈。
C 是形容词，先排；"激励"多接人（激励员工），"激发"多接抽象物（激发积极性、热情）→ 答案 = A 激发。

21成语辨析

识别标志选项含成语，或成语 + 实词混合
思考路径
  1. 先判断成语能不能用（望文生义 & 对象误用 & 褒贬误用 是三大死穴）。
  2. 再按语义侧重区分近义成语。
  3. 成语与实词混搭时，成语是突破口——先用成语排除，再看实词。
判定标准 · 高频易错成语分类
类别易错成语
望文生义不刊之论（不可改动，非"不能刊登"）、差强人意（大体满意）、首当其冲（最先受冲击）、文不加点（一气呵成）、炙手可热（权势大，非"热门"）
褒贬误用处心积虑（贬）、殚精竭虑（褒）、趋之若鹜（贬）、蔚然成风（褒）、弹冠相庆（贬）、粉墨登场（贬）
对象误用美轮美奂（建筑）、汗牛充栋（书籍）、豆蔻年华（女子十三四）、举案齐眉 / 相敬如宾（夫妻）、鳞次栉比（房屋等密集排列）
语义重复忍俊不禁地笑了、难言之隐的苦衷、显得相形见绌、目前的当务之急
高频陷阱"炙手可热"被误用为"很受欢迎/热门"（实为权势大、气焰盛，贬义）；"差强人意"被当成"不满意"（实为大体还能让人满意）。
示例演示"他的文章写得很好，_____" 选项含"不刊之论" → 指不可磨灭/不可修改的言论，用于文章言论，语境吻合 → 可选。若选项是"炙手可热"形容文章受欢迎 → 对象与感情色彩双错 → 排除。

22多空（两空 / 三空）混合填空

识别标志一题挖 2—3 个空，选项为词语组合
思考路径
  1. 先找"突破口空"：哪一个空的前后逻辑提示最明确（有解释句、有明显关联词、或搭配最固定），就从它下手。
  2. 用突破口空排除 2 个选项，剩下 2 组再用第二个空定夺。
  3. 不要试图同时满足三个空，满足两个空且第三个空讲得通即可。
判定标准"两空都对 > 一空特别好"。若某选项第一空极贴切但第二空搭配错误 → 排除；反之某选项两空都平平但都成立 → 可选。
高频陷阱被第一空的"完美契合"迷惑，没检查第二空；或者两个空都纠结，浪费 90 秒。
示例演示文段"……虽然起步较晚，但凭借____的投入和____的机制，最终实现了赶超。"
突破口在第二空"机制"，"健全的机制/完善的机制"是固定搭配 → 排除"优秀机制/优越机制" → 用第二空锁定答案。

23逻辑填空 · 提速与取舍

思考路径
  1. 单题 40 秒为红线，填空总量控制在 7—9 分钟。
  2. 40 秒拿不定 → 选读起来最顺口的那个（语感在填空上准确率高于反复纠结）。
  3. 遇到完全不认识的成语，看它的字面是否能与文段形成呼应，不行就先排除它（不认识的词不等于答案）。
高频陷阱在填空上反复改答案——第一语感正确率约 70%，改动后反而更差，除非找到了明确的逻辑错误，否则不改。

B. 片段阅读（6 份框架）

24中心理解（主旨概括）

识别标志"这段文字主要说明/意在说明/主旨是/核心是/概括最准确的是"
思考路径（三步）
  1. 找主题句：重点读关联词后半句——转折后（但是/然而/其实）、因果后（因此/所以）、递进后（甚至/更）、对策句（应当/必须/需要）。
  2. 划结构：是"提出观点—举例论证"？"提出问题—分析原因—解决对策"？"现象—本质"？举例、数据、引用、背景介绍都不是重点。
  3. 抓主题词：全文高频出现的核心名词（通常出现 3 次以上），正确选项必须包含主题词。
判定标准正确答案 = 主题词 + 作者观点/结论。缺主题词的、只概括了例子的、只讲了背景的一律排除。
选项处理（四类必排除） ① 无中生有（文段没提） ② 以偏概全（只说了局部） ③ 范围扩大/缩小 ④ 非重点（是例子/背景/原因，不是结论） 剩余两项时，选表述更具体、更贴合原文的那个；若一项过于绝对（"所有""必然"），慎选。
高频陷阱
  • 把"例子"当成主旨（文段"例如""比如"之后的内容永远不是主旨）。
  • 选项表述正确但不是文段重点（这是最难辨的陷阱，常见于"原因分析"项）。
  • 忽略了"然而"之后才是真观点。
示例演示文段：介绍某现象 → "然而，这种做法也带来了……问题" → 接着举例。
主旨 = "转折后"的问题（如"××做法存在隐患"），举例部分不选。

25意图判断

识别标志"这段文字意在说明/表达的意思是/作者的意图是/想告诉我们"
思考路径（判断口诀）
  1. 先按中心理解的方法找主旨。
  2. 看文段有没有"问题"：
    • 文段只阐述一个观点/事实（无问题）→ 选主旨概括项。
    • 文段提出了问题（负面现象、危害、不足）→ 优先选对策项（"应当/需要/必须…"）；没有对策项时，退而选问题项。
  3. 对策项必须针对文段的问题，不能是"万能正确但无关"的呼吁。
判定标准有问题 → 选对策；无问题 → 选主旨。且对策要"对症"——解决的是文段说的那个具体问题。
高频陷阱
  • 文段有问题，选项也有对策，但对策不对症（说的是别的问题的解决方案）。
  • 文段无问题，却选了"呼吁式"的引申项（过度引申）。
  • 把"意图"当成"主旨"，漏掉了隐含的对策倾向。
示例演示文段："……农村留守儿童心理健康问题日益突出……"
选项：A"留守儿童心理健康问题严重"（问题项）；B"应加强对留守儿童的心理疏导"（对策项）。答案 = B。若选项 B 是"应加强农村教育投入" → 不对症 → 选 A。

26细节判断

识别标志"下列说法与原文相符/不相符的是""下列说法正确的是"
思考路径
  1. 先圈"符合"还是"不符合"（同定义判断的陷阱）。
  2. 按选项顺序回文段定位（不要先读完整段再做题，浪费时间）。
  3. 逐字比对，找六种偷换。
判定标准 · 六种典型设错
设错类型表现
偷换时态文段"将要/已经"，选项"已经/将要"；加"了""过"
偷换数量"有些"→"所有"；"部分"→"全部"
偷换语气"可能"→"一定"；"也许"→"必然"
偷换概念换成相近但不同的名词
强加因果/因果倒置文段无因果却说"因为…所以"；或把因说成果
无中生有文段完全没有提及
另：选项表述温和（可能、有些、一定程度上）的，正确的概率更高。
选项处理"不符合"题：先找最明显错误的那项（通常是无中生有或绝对化），定位到就直接选，不必验证其余。
高频陷阱选项本身说法正确但文段没提（常识干扰项）——细节判断只看文段，不看常识对错。
示例演示文段："该技术在实验室阶段已取得突破。" 选项："该技术将在实验室取得突破。" → 偷换时态（已→将）→ 与原文不相符。

27标题填入

识别标志"最适合做这段文字标题的是"
思考路径本质是中心理解 + 形式要求。先找主旨，再按三标准筛： ① 紧扣主题词② 全面（不含糊、不片面）③ 生动简洁、有吸引力
判定标准记叙文/新闻类标题要有事件主体；说明文标题要点明说明对象；议论文标题最好体现观点。
高频陷阱选了"生动但没点出主题词"的（太文艺/太宽泛，如"人生的智慧"）；或选了"只是文段一个小方面"的（片面）。
示例演示文段讲"人工智能在医疗影像诊断中的应用与局限"。
候选：A"人工智能"（太宽）；B"医疗影像诊断"（偏）；C"AI 看片：能力有多大，边界在哪里"（点明主题 + 生动）→ 答案 = C。

28词语理解 / 代词指代

识别标志"文中的'××'指的是""'这''它''此'指代的是"
思考路径
  1. 代词指代：往前找（就近原则），找最近出现的、能被替代的名词性成分；代入读一遍看通不通。
  2. 词语理解：定位原词，读前后句的解释/例子；把选项代入原句，看语义是否连贯。
  3. 注意"这""此"常指代前面一整句话或一种现象，而非单个名词。
高频陷阱只往前找最近的一个词，而实际指代的是前面整件事；或往后找（错误，指代必在前）。
示例演示"……很多年轻人选择'反向消费'，这反映了消费观念的转变。"
"这"指代 = "很多年轻人选择反向消费"这一现象，而非"年轻人"或"消费"。

29下文推断

识别标志"接下来最可能讲的是""作者接下来会谈论""这段文字是一篇文章的引言，文章接下来最可能讨论的是"
思考路径
  1. 紧扣最后一句：接下来要讲的，一定是尾句话题的延续。
  2. 已讲过的一律排除（这是最高频的排除依据）。
  3. 若尾句提出了一个新概念/新现象，下文通常是解释它；若尾句提出了问题，下文通常是分析原因或给对策。
判定标准话题一致（与尾句同主题）+ 内容未讲过。二者缺一不可。
高频陷阱选了"文段已经详细讲过的内容"；或选了与尾句话题无关的新话题（跳跃太远）。
示例演示文段尾句："……而'数字鸿沟'正是当下亟待解决的问题。"
A"数字鸿沟的定义"（若前文已讲过 → 排除）；B"化解数字鸿沟的具体措施" → 答案 = B（问题 → 对策）。

C. 语句表达（2 份框架）

30语句排序

识别标志给出 5—7 个打乱的句子，要求重新排列
思考路径（四步，不要直接硬排）
  1. 定首句（先排除不能做首句的）：含指代词且指代不明的（"这""他""其"）；含关联词后半部分的（"但是""而且""因此""所以"）；含补充/递进词的（"另外""此外""同时"）；具体举例句。适合做首句：下定义、提背景、总起句。
  2. 找捆绑：① 关联词配对（虽然…但是…、不但…而且…）；② 指代词 + 被指代对象（"这"前必有指代内容）；③ 同一话题相邻；④ 时间顺序/逻辑顺序（先…后…、起因→经过→结果）。
  3. 看选项：用首句排除 + 捆绑排除，一般能剩下 1—2 项。
  4. 通读验证：把剩下的选项连起来读一遍，语感不通的即错。
判定标准首句要能"独立成立"；捆绑要"挨着且顺序对"；整体要"逻辑通顺 + 指代明确"。
选项处理从选项入手，不要从句子入手——比较四个选项的首句，先干掉两个，再比较尾句，最后验证中间捆绑。
高频陷阱从头到尾硬排序（最慢且易错）；忽略了"指代词必须紧跟被指代对象"这条硬规矩。
示例演示选项中首句分别是 ②"这导致了……"（含"这"，排除）和 ④"近年来，随着……"（背景句，保留）→ 直接排除含 ② 开头的选项，剩两项再比尾句。

31语句填空（衔接）

识别标志文段中间挖一句，要求填入最恰当的一句（通常在段首/段中/段尾）
思考路径
  1. 看位置定功能：
    • 段首：总起、引出话题 → 要能统领后文
    • 段中：承上启下 → 既要承接上文又要引出下文
    • 段尾：总结、得出结论 → 要能收束全段
  2. 抓话题一致：填入句的主题词必须与前后文一致。
  3. 注意关联词：空格后有"但是" → 空格句应与后文构成转折；空格在"因此"前 → 应是原因。
判定标准"话题一致 + 逻辑连贯"，代入后读一遍，代词有指代、关联词能配、语气能接。
高频陷阱填了"本身很漂亮但与前后文话题无关"的句子；或段尾填了"开启新话题"的句子（段尾应收束）。
示例演示"_____，但是在实际操作中却困难重重。"
空格后是"但是" → 空格应说"理论上可行/前景良好" → 选"该方案在设计上颇具创新性"这类句子。
