模块一 · 资料分析

职测分值密度最高、提分最快的模块，属必拿分区。核心是「ABRX 四要素 + 三大速算」，掌握后单篇 5—6 分钟、正确率 90%。

项目要求
目标用时单篇 5—6 分钟（A 类整体控制在 20 分钟内）
目标正确率90%（错≤2 题）
做题位次全程第 2 个做（常识之后），绝不留到最后

一、ABRX 四要素（所有题的地基）

符号含义别名核心式
A现期量今年 / 本期 / 报告期A = B ×（1 + R）
B基期量去年 / 上期 / 基期B = A ÷（1 + R）
R增长率增速 / 增幅 / %R =（A − B）÷ B = X ÷ B
X增长量净增额 / 增量 / 绝对数X = A − B = B × R
核心记忆：知任意两个，可求另外两个。90% 的题都是「已知二求三」。
求已知公式
BA、RB = A ÷（1 + R）
XA、RX = A × R ÷（1 + R）　→　实际用 415 份数
XB、RX = B × R
RA、XR = X ÷（A − X）
AB、RA = B ×（1 + R）

二、三大速算方法

1. 截位直除（求基期首选，一切除法通用）

先看选项，再定截几位——顺序不能反。

选项特征分母截几位
首位不同（13% / 15% / 18% / 21%）2 位
首位同、第二位不同（12.1 / 12.5 / 12.8）3 位
前两位同（12.11 / 12.15）4 位
前三位同精算

步骤：看选项定截位 → 分母四舍五入截位 → 分子尽量不截（分子小于分母 1/10 时绝不截）→ 相除。

示例：4287 ÷ 32456 = ？ 选项 A.13.2% B.15.6% C.18.4% D.21.1%
→ 首位全不同，截 2 位：43 ÷ 325 ≈ 43 ÷ 32 × 1/10 ≈ 1.34 × 0.1 = 13.4% → 选 A
易错：① 分母首位是 1 或 2 时误差大，多截一位；② 下降时（1+R）变（1−|R|），别写成加；③ 没看选项就截位，是最高频错误；④ 算完回乘验一次，防小数点错位。

2. 415 份数法（求增长量专用）

核心比例：基期 : 增长量 : 现期 = 100 : R :（100 + R），即 现期 : 增量 =（100+R）: R

步骤：写比例 → 化简（110:10 → 11:1）→ 每份 = 现期 ÷（100+R）（用截位）→ 增长量 = 每份 × R

示例：8680 亿元，同比 +8.4%，求增长量
→ 108.4 : 8.4 → 每份 = 8680 ÷ 108.4 ≈ 8680 ÷ 108 ≈ 80
→ 增长量 = 80 × 8.4 ≈ 672 亿元
→ 验算：8680 − 672 = 8008（基期），8008 × 8.4% ≈ 672 ✓
R基期:增量:现期简化比口算
5%100:5:10521:1现期 ÷ 21
10%100:10:11011:1现期 ÷ 11
20%100:20:1206:1现期 ÷ 6
25%100:25:1255:1现期 ÷ 5
33.3%100:33:1334:1现期 ÷ 4
50%100:50:1503:1现期 ÷ 3
易错：① 下降时现期 = 100 − |R| 份，不是加；② 已知基期+R 求增量不用 415，直接 X = B × R；③ 下降时减少量 大于 现期×R（因为是基期×R，基期更大）。
1/n 快解：R = 1/n 时，增长量 = 现期 ÷（n+1）；下降 1/n 时，减少量 = 现期 ÷（n−1）。
25%→÷5、20%→÷6、16.7%→÷7、12.5%→÷9、11.1%→÷10、9.1%→÷12

3. 假设分配法（求基期，R 在 5%—25% 最准）

步骤：① 假设基期 = 现期 → ② 假设增量 = 现期 × R → ③ 真实增量 = 假设增量 ÷（1+R）→ ④ 基期 = 现期 − 真实增量

示例：2023 年产量 5460 万吨，同比 +14%，求 2022 年
→ 假设增量 = 5460 × 14% = 764.4
→ 真实增量 = 764.4 ÷ 1.14 ≈ 670
→ 基期 = 5460 − 670 = 4790 万吨
方法选择口诀：求基期 → 截位直除（稳）；求增量（现期+R）→ 415；求现期（基期+R）→ 假设分配。R > 50% 时假设分配误差大，改截位直除。

综合分析题（每篇最后一道）

  • 验证优先级：直接读材料 > 简单比较 > 简单计算 > 复杂计算 > 综合判断。
  • 问"可以推出"：找到一个对的立即选，不验证其余；经验上从 D 往 A 验。
  • 每个说法 ≤40 秒，整题 ≤3 分钟；有"约/左右"多半对，有"超过/不足"要精算。
  • 绝对化表述（一定、所有）多为错；没时间蒙 B 或 C。

五、口诀汇总

ABRX 互推：现期除以一加率得基期，基期乘率得增量
截位直除：选项差距看首位，不同截二同截三
415 份数：现期除以一加率，得每份再乘增长率
假设分配：基期设百份，现期百加率
比重升降：部分大则升，部分小则降
综合分析：先算简后算繁，找到一个就收手
时间陷阱：基期现期要分清，同比环比别混淆

六、拿到一篇材料的标准动作

  • 30 秒圈读材料：标题、时间、单位、表头，判定材料类型。
  • 动笔标三件事：划时间词、圈单位、标主体（防"出口/进口"看串行）。
  • 读题干先定性：划时间定现期/基期，划问法定题型（占→比重、平均→平均数、增长__%→率、增长__→量），写公式再找数。
  • 先看选项定截位，再选方法，算出先对量级再选答案。
  • 综合分析题放本篇最后，做不完蒙 B/C。

子题型单题用时目标正确率

定义判断50 秒85%

模块内部顺序：类比（最快，先抢时间）→ 定义（稳）→ 逻辑（慢，留足时间）→ 图形（最后做，卡壳率最高）。单题超 1 分钟立即跳过做标记。

一、图形推理

规律优先级（看到图按序试）：
元素相同 → 位置规律（平移、旋转、翻转、遍历）
元素相似 → 样式规律（叠加、求同、求异、黑白叠加）
元素不同 → 数量规律（点→线→角→面→素）
都不行   → 属性规律（对称→曲直→封闭）

口诀：相同看位置，相似看样式，不同看数量，都不行看属性
规律识别具体清单
位置元素完全相同，只是位置/角度变平移（方向+步数，恒定/递增）、旋转（顺逆，30/45/60/90/180°，可交替）、翻转（上下/左右镜像）、遍历（每行每列各出现一次）
样式元素相似（有同有异）叠加、求同（留相同）、求异（去同存异）、黑白叠加（规则每题不同，必须从已知图反推）
数量元素完全不同点（交点/切点/顶点）、线（直线/曲线/总线/一笔画）、角（直角/锐角/钝角）、面（封闭区域数）、素（种类数/个数/部分数）；常见数列：等差、对称、恒定、运算
属性数量走不通对称性（轴/中心，再看轴的数量与方向）、曲直性、封闭性
一笔画判定：奇点 = 引出奇数条线的点。奇点数 = 0 或 2 → 可一笔画；≥4 → 不能。常见一笔画图形：圆、椭圆、三角形、五角星、"日"、"中"。

分组分类：6 图分两组，依次试 对称 → 曲直 → 封闭 → 数量奇偶 → 元素种类，找能把 6 图整齐 3+3 切开的依据。

空间重构（六面体）：① 相对面法先用——展开图中"相间排列"或"Z 字两端"为相对面，一对相对面不能同时出现 → 直接排除；② 相邻面用时针法判方向；③ 验证剩余项。

提速：只盯一个元素（如黑块）不盯整图；先试高频规律（面>线>点）；30 秒看不出规律就跳过，最后蒙 B/C。易混：种类数 vs 部分数（"△△□"种类 2、部分 3）。

二、定义判断

读题步骤：① 先看问法（圈"不"字）→ ② 读定义只划要素关键词，不读全段 → ③ 多定义题只看被问的那个 → ④ 逐项比对，一要素不符即排除。

要素问法标志词
主体谁做谁、什么人/组织
客体对谁做对什么、把什么
目的为了什么为了、目的是
方式怎么做通过、以…方式
条件什么情况下在…情况下 / 时
原因 / 结果因为 / 导致因为、由于 / 导致、使得
易错：①"不属于"看反；② 被常识带跑（用生活理解替定义）；③ 漏掉限定词（"直接""故意""以营利为目的"）；④ 主体/客体/方式/目的偷换；⑤ 结果"已发生"与"可能发生"混同。

三、类比推理

步骤：判大类（语义/逻辑/语法/对应）→ 判小类 → 看方向（A→B 还是 B→A） → 排除 → 多项同关系时用二级辨析。三词型：先定前两词关系，再套第三词，造句验证。

关系具体类型
语义近义、反义、象征、比喻、褒贬色彩、程度加深
逻辑全同、包含（是一种）/ 组成（是一部分）、交叉、并列、矛盾、反对、条件、因果、顺承、目的
对应功能、材料、职业+场所、职业+工具、工具、配套、因果
语法主谓、动宾、偏正、主宾

二级辨析顺序：方向一致 → 词性一致 → 感情色彩 → 具体/抽象 → 必然/或然 → 自然/人造 → 程度轻重 → 范围大小 → 时间先后 → 主体人/物。

易错：方向反了；把"组成"当"包含"；忽略感情色彩；用造句硬套违背本义。

四、逻辑判断

4.1 翻译推理

原句翻译口诀
如果 A，那么 B / 只要 A，就 BA → B前推后
只有 A，才 BB → A后推前
除非 A，否则 B非A → B（等价 非B → A）否一推一
除非 A，否则不 BB → A后推前
A 是 B 的必要条件/前提/基础B → A后推前
A 是 B 的充分条件A → B前推后
A 或 B非A → B；非B → A否一推一
推理规则：逆否等价 A→B ⇔ 非B→非A；传递 A→B、B→C ⇒ A→C；肯前必肯后、否后必否前。
德摩根：非(A 且 B) = 非A 或 非B；非(A 或 B) = 非A 且 非B。
A→B 的矛盾是 A 且 非B。
易错：肯后、否前都是错的；"或"命题不能由一支为真否定另一支。

4.2 真假推理

四关系：矛盾（必一真一假）、上反对（所有 vs 所有不，至少一假）、下反对（有的 vs 有的不，至少一真）、从属。

常见矛盾对：所有是 ↔ 有些非；所有非 ↔ 有些是；某个是 ↔ 某个非；A且B ↔ 非A或非B；A或B ↔ 非A且非B；A→B ↔ A且非B。

"一真一假"四步套路：① 找矛盾（一真一假必在其中）→ ② 绕开矛盾看其余命题，由"只有一真/一假"定其余全部真假 → ③ 回代推事实 → ④ 再判矛盾内谁真谁假。

4.3 加强削弱（重点，题量最大）

结构：论据 → 论证过程 → 论点（"因此/可见/表明"之后）。先圈论点，再找论据与论点之间的不同概念（搭桥点）。

  • 加强力度：补充论据/加强论点（最强）> 建立联系（搭桥）> 排除他因 > 举例支持（最弱）
  • 削弱力度：否定论点（最强）> 断开联系（拆桥）≈ 否定论据 ≈ 因果倒置 > 另有他因 > 举例反驳（最弱）
  • 前提假设：搭桥补缺失联系；用"否定代入"验证（否定后论证崩溃 = 必要前提）
陷阱：偷换概念、以偏概全、因果倒置、滑坡谬误；无关选项（主体/话题跑偏）先排。

4.4 日常结论 / 解释评价 / 排序匹配

  • 日常结论：必须能从题干必然或极可能推出；不选过度推断、无中生有；警惕绝对化词，优先选"可能/有些/往往"的弱化表述。
  • 解释评价：先明确矛盾两面，选能同时容纳两面的选项，不能否定任何一方事实。
  • 排序匹配：画表格/数轴，先定唯一确定项；匹配型列二维表打勾打叉；真假型用假设法。

五、口诀汇总

图形：相同看位置，相似看样式，不同看数量，都不行看属性｜点线角面素，面最常考｜一笔画奇点零或二
定义：主体客体目的方式，逐一比对，一不符即排除
类比：包含是一种，组成是一部分｜A 到 B 还是 B 到 A，方向不能反
逻辑：前推后、后推前｜肯前否后，逆否等价｜真假：找矛盾、绕开看
削弱：否论点最强，另有他因中等，举例最弱｜加强：补充论据最强，举例最弱

六步：① 通读抓大意 → ② 标空格前后的关联词与对应词 → ③ 判对应类型 → ④ 推导空格应有含义 → ⑤ 候选词辨差异 → ⑥ 代入复读验证。

关系标志词空格语义示例

五大辨析维度：① 范围大小 ② 程度轻重（不确定选中间档）③ 搭配对象 ④ 感情色彩（褒/贬/中性）⑤ 词性与语体。

固定搭配（错则一票否决）：汇聚/凝聚力量·共识；汇集资料；提高/提升水平；推动/促进发展；维护/捍卫权益；履行/践行承诺；传承/弘扬文化；培育人才、厚植优势；破解难题、化解矛盾；激发活力、释放潜力；筑牢/夯实基础；深化改革、推进改革、推行制度、实施战略、落实政策。
纠错：提高范围→扩大范围；改善缺点→改正缺点；维持水平→保持水平。

典型易混成语：

  • 不以为然（不同意）≠ 不以为意（不在意）
  • 不负众望（褒）≠ 不孚众望（贬）
  • 不刊之论 = 不可更改的言论（褒，非"不能刊登"）
  • 无可非议（完全正确）≠ 无可厚非（有小错可谅）
  • 耸人听闻（夸大）≠ 骇人听闻（真实而可怕）
  • 良莠不齐（好坏混杂）≠ 参差不齐（高低不一）
  • 鱼目混珠（以假乱真）≠ 泥沙俱下（好坏混杂）
  • 不谋而合（想法一致）≠ 殊途同归（方法异、结果同）
  • "多"类限定：汗牛充栋只指书、浩如烟海指文献、洛阳纸贵指著作流传
多空题策略：从最有把握/排除力度最大的那一空入手，不必机械从第一空；两空都成立才选；只剩一词之差时比"搭配对象 + 程度"，不比语感。
易错：被语感带跑（必须找到明示暗示）；只看一空就定答案；望文生义（尤其"不/无"字头）；褒贬误用。

二、片段阅读

2.1 中心理解（题量最大）

识别：主要说明 / 意在强调 / 主旨 / 概括 / 作者观点。

步骤：读文段圈关联词 → 定位重点句 → 提取主题词 → 选含主题词的重点句同义替换。

关系标志词重心
转折但是、然而、却转折后
递进而且、甚至、更递进后
因果因此、所以、因而结果
条件只有…才、只要…就条件
对策应该、必须、需要对策
并列和、同时、此外、既…又无主次，需全面概括
  • 关联词优先级：转折 > 递进 > 因果结论 > 条件 > 对策 > 并列
  • 行文脉络：总分→首句是观点；分总→尾句是结论；转折/因果段→后半为重心；举例、数据、引用一律跳过不算主旨
  • 主题词排除法：不含主题词 → 排除；主题词被扩大/缩小 → 排除
  • 对策类文段：问题+对策 → 优先选对策；只提问题、对策不符或绝对化 → 错
易错：把例子/背景当主旨；被片面选项带走；并列文段只抓其一；忽视"因此/但是"后的真正重心。

2.2 细节判断

识别：下列说法正确的是 / 不符合文意的是。顺序：先看选项圈定位关键词（专有名词、数字、主体）→ 回文段对应 → 逐项逐字比对 → 设陷阱的直接排除。

设错类型说明示例
偷换概念换主体/客体"企业"→"政府"
偷换时态换时间状态"将"→"已"、"正在"→"已经"
偷换范围以偏概全/扩缩"部分"→"全部"
偷换语气绝对化"可能"→"必然/一定"
无中生有文段未提及—
正话反说颠倒黑白"上升"→"下降"
因果倒置因果互换A 导致 B → B 导致 A
绝对化词（一定/必须/所有/都/完全）→ 多为错；弱化词（可能/也许/一些/部分）→ 多为对。

2.3 标题填入 / 词语理解 / 下文推断

  • 标题填入：找中心句 → 提炼主题 → 比对。优先级：主题词 > 概括性 > 吸引力。
  • 词语理解：定位原词所在句 → 上下各看一句 → 抓解释性成分（冒号、"即"、"这指的是"）→ 代入验证。
  • 下文推断：锁定尾句新出现的核心名词 → 顺着往下讲 → 排除前文已讲过的内容。

三、语句表达

3.1 语句排序

流程：看选项定首句 → 找捆绑 → 看尾句 → 串顺序通读验证。

  • 可做首句：引出话题、下定义、宏观背景。不可做首句：代词开头（这/那/其/此）、关联词后半句（但是/所以/而且）、举例（如/例如）、总结句。
  • 捆绑依据：代词+指代对象相邻；关联词配对（虽然…但是）；顺序词（首先…其次…最后）；时间/逻辑顺序（现象→原因→对策→结果）。
  • 尾句特征：总结、对策、展望、结果。

3.2 语句填空（看横线位置）

位置功能
段首总起/引出话题，需概括后文
段中承上启下，前后文话题都要衔接
段尾总结前文 / 得出结论，常带"因此/总之/可见"
易错：只顺承前句不顾后句；填了前后都未涉及的新话题；忽视关联词要求的方向（转折 vs 顺承）。

四、口诀汇总

填空找对应：转折反义、并列近义、递进加深、解释同义
中心找关联：转折后、递进后、结论是重点｜反复出现是主题，答案必含主题词
细节防偷换：概念、时态、范围、语气、有无、正反
排序看首尾：代词不做首，总结做尾句
成语辨析：本义、色彩、程度、对象

五、防回读三条

  • 先看问题再读文段，带着目标读，只读一遍。
  • 跳读 + 精读：例子、数据、年份、引用跳读；关联词、主题词、首尾句精读。
  • 结构读法：读完一段即在脑中标记"这是背景/问题/转折/对策"，避免回原文找。
