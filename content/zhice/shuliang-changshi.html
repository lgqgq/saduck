模块一 · 数量关系

目标用时 6—9 分钟 ｜ 目标正确率 50% ｜ 题量通常 5—10 题（陕西联考 A 类）

A. 整体策略（1 份，最重要）

1数量关系整体策略与取舍

识别标志进入数量关系模块即调用。判断"要不要做这道题"只看三件事：题干是否 ≤2 行、是否属于固定模型、选项是否是具体数值。三个条件占两个才动笔。
思考路径
  1. 扫题分堆（60 秒内）：不计算，只判题型，把题分成 A/B/C 三堆。
    • A 堆（必做）：工程、容斥、年龄、利润、浓度、简单几何
    • B 堆（有余力做）：行程基础、植树方阵、日期周期、鸡兔同笼
    • C 堆（必跳）：排列组合、概率、最值、多阶段行程、题干超 3 行的新情境题
  2. 先做 A 堆：每题硬上限 90 秒，做完 3—4 题立即收手。
  3. 时间有余再挑 1 题 B 堆。
  4. 剩余全部统一蒙同一选项，30 秒涂完。
  5. 绝不回头检查数量关系。
判定标准 · 性价比排序（先做上面，跳过下面）
优先级题型理由目标用时
1 必做工程、容斥、年龄模型最固定，赋值/套公式即可，几乎不翻车50—70 秒
2 优先利润、浓度、简单几何赋成本 100 / 溶质守恒 / 套公式，一步到位70—90 秒
3 选做行程基础与相遇追及、植树方阵、日期周期、鸡兔同笼只需列一次方程90—120 秒
4 慎做排列组合、概率、最值、多次相遇、三集合极值陷阱密、算错率高≥2 分钟
5 必跳题干超 3 行 + 多主体多阶段、"以下正确的是/错误的是"、函数图像、复杂计数时间黑洞，正确率与蒙接近0 秒
选项处理 · 蒙题原则（核心取舍策略）
规则操作
蒙哪个选项数一遍已做题目选了什么，统一蒙"已做答案中出现次数最少"的那个选项。已做 4 题选了 C、A、C、B（C 两次、A/B 各一次、D 零次）→ 剩余题全部蒙 D
为什么统一蒙真题答案 ABCD 分布趋于均匀（各约 25%）。分散蒙与统一蒙期望值相同，但统一蒙有三个红利：吃到分布均匀的补偿效应、省时间、不会涂串行
问"最大/至多"排除选项中最小的那个
问"至少/最少"排除选项中最大的那个
出现"平均/每/人数/个数/整除"答案多为整数或特定倍数，优先蒙整数项
选项成"倍数对"如 12 与 24、30 与 60 → 答案多在此二者之一
算出的数选项里没有90% 是单位或倍数错，别改答案，直接查单位；查不出就蒙，不纠缠
绝对禁止不检查、不验算、不返工、不用最后 2 分钟抢救数量关系
高频陷阱
  • 恋战：一题耗 3 分钟，等于白丢 2 道题的时间。
  • 不做取舍、全蒙：会做的 3 题是"确定分"，放弃等于主动降 30% 正确率。
  • 蒙题分散：自以为"随机一点更准"，实际既费时又无收益。
  • 把数量关系放在最前面做：脑子最清醒时应给资料分析/判断推理。
  • 算完不扫一眼单位与是否需要取整。
示例演示 · 一场 10 题的 7.5 分钟作战
时间动作结果
0:00—1:00扫题分堆。A=工程/容斥/年龄/利润/浓度；B=几何/日期；C=行程/排列/最值—
1:00—2:00做工程（赋值 60）选 C
2:00—2:50做容斥（两集合公式）选 A
2:50—3:50做年龄（年龄差不变）选 C
3:50—5:10做利润（赋成本 100）选 B
5:10—6:30做浓度（溶质守恒）选 C
6:30—7:00已做：C、A、C、B、C → C 三次、A/B 各一次、D 零次 → 剩余 5 题统一蒙 D，涂卡—
结果：实做 5 题（对 4—5），蒙 5 题（命中约 1），共对 5—6 题，正确率 50—60%，耗时 7.5 分钟。这就是数量关系的标准打法。

B. 高频题型（13 份）

2工程问题（含牛吃草）

识别标志"一项工程/任务/水池/文件/收割"；给出各主体单独完成时间、效率比、或人数/机器数；问"几天完成""还需几天""中途加入/离开/休息"。牛吃草（草在长、水池在进水、排队在加人）是它的变种。
思考路径
  1. 判给定的是什么 → 决定赋什么值。
  2. 给定时间型：赋工作总量 = 各时间的最小公倍数（保证效率为整数）。
  3. 给定效率比型：直接赋效率 = 比例值，总量 = 效率和 × 时间。
  4. 给定人数/机器数型：赋每人/每台效率 = 1，总量 = 人 × 天。
  5. 中途加入/退出/休息 → 按时间段切段，各段工作量相加 = 总量。
  6. 效率提高 p% → 新效率 = 原效率 ×(1+p%)。
  7. 交替工作 → 先算一个完整周期的产出，总量 ÷ 周期产出，余数单算。
  8. 牛吃草：草长速度 x = (N₁T₁ − N₂T₂)/(T₁ − T₂) → 原有草量 = N₁T₁ − xT₁ → 天数 = 原草 ÷(N − x)。
判定标准 · 公式清单
公式 / 结论说明
工作总量 = 效率 × 时间核心
合作效率 = 各效率之和合作
两人合作时间 =（甲时 × 乙时）÷（甲时 + 乙时）秒杀公式，12 与 15 → 180/27 ≈ 6.7
新效率 = 原效率 ×(1 ± p%)效率变化
草长速度 =（N₁T₁ − N₂T₂）/（T₁ − T₂）牛吃草
天数 = 原草量 ÷（N − 草长速度）N 必须 > x，否则"永远吃不完"
赋值口诀：时间给最小公倍数，效率给比例，人数给每人效率 1。
选项处理范围夹逼：两人合作时间必介于"最快单独时间的一半"与"最快单独时间"之间。甲 12 乙 15 → 合作时间必在 (6, 12)，选项 <6 或 >12 直接排。也可把选项作天数代入 Σ效率×时间 = 总量 验算。
高频陷阱
  • 中途休息：休息日不产生产出，必须分段。
  • "效率提高 20%" ≠ "总量提高 20%"。
  • "完成了 1/3" 与 "完成了剩下的 1/3" 完全不同。
  • 交替工作最后一个不完整周期要单独算。
  • "第几天完成"要向上取整，"几天完成"可保留分数。
  • 牛吃草中草长速度是每天的量。
示例演示
一项工程甲单独 20 天完成，乙单独 30 天完成。两人合作，中途甲休息 3 天，问从开工到完工共用多少天？
赋总量 = 60（20、30 最小公倍数）→ 甲效率 3，乙效率 2。设共用 T 天，甲实际工作 (T−3) 天：
3(T−3) + 2T = 60 → 5T − 9 = 60 → T = 13.8　答案 = 13.8 天（若问"第几天完工"则答第 14 天）

3行程问题

识别标志路程、速度、时间；"相向/同向""相遇/追上""顺水逆水""往返""第 n 次相遇""上下坡""提前/晚出发"。
思考路径
  1. 画线段图（必做，别心算）。
  2. 统一单位：km/h 与 m/s（1 m/s = 3.6 km/h）、分钟与小时。
  3. 判子题型：相向→相遇（路程和）；同向→追及（路程差）；有水流/电梯→顺逆水；封闭环形→圈数；两端往返第 n 次相遇→共走 (2n−1)S；等距离→调和平均。
  4. 找等量关系（时间相等 / 路程相等 / 路程和差）列方程。
  5. 用比例法提速：路程相同时，速度比 = 时间反比。
判定标准 · 公式清单
公式 / 结论说明
S = v × t核心
相遇：S和 =（v₁+v₂）× t；追及：S差 =（v₁−v₂）× t—
v顺 = v船 + v水；v逆 = v船 − v水流水
v船 =（顺+逆）/2；v水 =（顺−逆）/2流水秒杀
船追落水漂流物：追及时间 = 掉落后到发现的时间相对速度 = 船速，与水流无关
环形第 n 次相遇：同向路程差 = n×周长；相向路程和 = n×周长环形
直线两端往返第 n 次相遇：共走 (2n−1)S第二次相遇共走 3S，不是 2S
等距离平均速度 v = 2v₁v₂/(v₁+v₂)调和平均，必 < 算术平均
选项处理平均速度夹逼：等距离平均速度必介于 v慢 与 (v₁+v₂)/2 之间，超出即排。相遇时间夹逼：相遇时间 < 任一人单独走完全程的时间。先看选项单位是 km/h 还是 m/s，常在这里设错。
高频陷阱
  • 单位不统一（km/h 与 m/s、分钟与小时）。
  • 出发时间不同：先走的那一段要先减掉。
  • "第二次相遇"共走 3S，不是 2S；第 n 次是 (2n−1)S。
  • 平均速度误用算术平均：只有等距离才用调和平均。
  • 追及的初始距离是否识别正确。
示例演示
A、B 两城相距 240 km，甲从 A（60 km/h）、乙从 B（40 km/h）同时相向出发，各自到达对方城市后原路返回。问第二次相遇点距 A 城多少 km？
第二次相遇共走 3S = 720 km → t = 720 ÷ 100 = 7.2 h → 甲共走 60×7.2 = 432 km
甲轨迹：A→B 用掉 240，剩余 192 从 B 往回（朝 A）走 → 距 A = 240 − 192 = 48 km　答案 = 48 km

4利润问题（含分段计费）

识别标志成本/进价、定价/标价、售价、利润、利润率、打折（x 折）、满减、买几送几；以及分段计费（水费、电费、停车费、个税、快递费）。
思考路径
  1. 赋值：涉及利润率 → 赋成本 = 100；涉及折扣 → 赋原价 = 100；求总利润 → 赋销量 = 1 或 10。
  2. 顺推链条：成本 → 定价 → 打折后售价 → 单件利润 → 总利润。
  3. 倒推：定价 = 成本×(1+利润率) ÷ 折扣。
  4. 分段计费：先判断落在第几档，再"前段全额 + 超出部分按本档单价"累加。
  5. 用 售价 = 成本 ×(1+利润率) 作唯一方程。
判定标准 · 公式清单
公式 / 结论说明
利润 = 售价 − 成本定义
利润率 = 利润 ÷ 成本分母是成本（最高频错误点）
售价 = 成本 ×(1+利润率)；成本 = 售价 ÷(1+利润率)互推
打 x 折 = 原价 × x/108 折 = ×0.8
"降价 20%" = ×0.8；"降到 8 折" = ×0.8；"降价 8%" = ×0.92三种说法三种值
买三送一 = 75 折；买四送一 = 8 折促销
先涨 a% 再降 a% → 净变化 = −(a²/100)%涨 10% 降 10% = −1%
总利润 = 单件利润 × 销量—
"A 比 B 贵 20%" → A = 1.2B；"B 比 A 便宜 20%" → B = 0.8A分母不同
选项处理赋 100 后定价应为整齐数，若算出 137.5 之类乱数，多半折扣代反了。问"至多打几折仍能盈利" → 从选项最大的折扣开始代；问"至少打几折" → 从最小开始代。分段计费先用选项反推落在哪一段再验算。
高频陷阱
  • 利润率分母是成本，不是售价。
  • "打 8 折"（×0.8）与"降价 8%"（×0.92）混。
  • "A 比 B 贵 20%" 与 "B 比 A 便宜 20%" 不等价。
  • 分段计费：只有超出部分按高档价，不是全额重算。
  • 问"利润多少元"别答成百分比；问"利润率"别答成金额。
示例演示
某商品按定价的 8 折出售，利润率为 20%。若按定价的 9 折出售，利润率是多少？
赋成本 = 100 → 8 折售价 = 120 → 定价 = 120 ÷ 0.8 = 150 → 9 折售价 = 150×0.9 = 135
利润率 = (135−100)/100 = 35%　答案 = 35%

5排列组合

识别标志"排队""选出""分配""编号""路线""涂色"；问"多少种不同的方法/方案/情况"。
思考路径
  1. 判有序还是无序：交换两个元素是否产生新情况 → 有序用 A，无序用 C。
  2. 判元素相同还是不同：相同物品分配 → 隔板法；不同物品 → 排列。
  3. 判约束类型："必须相邻"→捆绑法；"不能相邻"→插空法；"某人在某位置"→优先安排特殊元素；"至少 1 个"→反向（总数 − 全不满足）。
  4. 分类用加法、分步用乘法：分类要不重不漏，分步要步步相乘。
  5. 先算总数再减不符往往比正面分类更快。
判定标准 · 公式清单
公式 / 结论说明
A(n,m) = n!/(n−m)!；C(n,m) = n!/[m!(n−m)!]基本
C(n,m) = C(n,n−m)对称性
捆绑法：整体全排列 × 内部全排列相邻
插空法：先排其他 → 插入空位（n 个元素有 n+1 个空，含两端）不相邻
环形插空：n 个元素围成圈有 n 个空不相邻
隔板法：n 个相同元素分 m 份，每份 ≥1 → C(n−1, m−1)；每份 ≥0 → C(n+m−1, m−1)相同元素
环形排列：n 人围一圈 = (n−1)!旋转等价
平均分组要除以组数阶乘：6 人平分 3 组 = C(6,2)C(4,2)C(2,2)/3! = 15极易错
错位排列：D₁=0, D₂=1, D₃=2, D₄=9, D₅=44全错排
常用数：C(4,2)=6, C(5,2)=10, C(6,2)=15, C(6,3)=20, C(7,2)=21, C(8,2)=28, C(10,2)=45背下来
选项处理算出的数远大于选项 → 多用了一次 A（该用 C）或漏除了平均分组的 m!。上界排除：5 人选 3 人最多 C(5,3)=10，若选项出现 20 说明题中有序。n ≤ 4 时可手算全排列验证。
高频陷阱
  • 有序/无序搞反（"选出来"用 C，"排成一排"用 A）。
  • 平均分组忘记除以 m!。
  • 插空时漏掉两端空位（n 个元素是 n+1 个空）。
  • 环形排列忘了 (n−1)!。
  • "至少 1 个"正面分类重漏，应用"总数 − 全不满足"。
  • 隔板法前提是"元素相同 + 每份至少 1"。
示例演示
6 人排成一排，其中甲乙必须相邻，丙丁不能相邻，共有多少种排法？
先捆绑甲乙为 X → X、丙、丁、戊、己 共 5 个元素：5! × 2 = 240
减去丙丁也相邻的情况：再捆绑丙丁为 Y → X、Y、戊、己 共 4 个元素：4! × 2 × 2 = 96
240 − 96 = 144　答案 = 144 种

6概率问题

识别标志"概率""可能性""随机抽取""至少……的机会"；摸球、抽签、掷骰子、比赛胜负、约会等待（几何概型）。
思考路径
  1. 判古典概型（有限等可能）还是几何概型（长度/面积/时间比）。
  2. 古典概型：分子 = 满足条件数，分母 = 总情况数，分子分母必须用同一计数口径（都用 C 或都用 A）。
  3. 见"至少" → 1 − 对立事件。
  4. 见"第一次……第二次……" → 分步相乘；分清放回（总数不变）与不放回（总数递减）。
  5. 多次独立试验 → C(n,k)pᵏ(1−p)ⁿ⁻ᵏ。
  6. 几何概型 → 画区域图，求面积（或时间区间长度）比。
判定标准 · 公式清单 P = 满足条件数 ÷ 总情况数 P(Ā) = 1 − P(A) "至少 1 个" = 1 − 全不是 "至少 2 个" = 1 −（0 个 + 1 个） 独立同时发生相乘；互斥至少一个相加 恰好 k 次：C(n,k)pᵏ(1−p)ⁿ⁻ᵏ 不放回抽 n 个：分母 = C(N,n) 几何概型：有利长度(面积) ÷ 总长度(面积)
选项处理先排 >1 或 <0 的选项（必错）。"至少一个"答案通常较大（>0.5），若算出很小，检查是否算成了"恰好"。选项成对出现（1/3 与 2/3、1/7 与 6/7）→ 答案多在其中，值得认真判断。
高频陷阱
  • 放回与不放回混淆。
  • 分子分母计数口径不一致（分子组合、分母排列）。
  • "至少"没用补集，正面算漏。
  • 把"恰好"当成"至少"。
  • 几何概型把面积比算成边长比。
示例演示
袋中有 4 红、3 白、2 黑共 9 球。任取 3 个，恰好三种颜色各 1 个的概率？
总情况数 C(9,3) = 84；满足条件数 C(4,1)×C(3,1)×C(2,1) = 24
P = 24/84 = 2/7　答案 = 2/7

7容斥问题

识别标志"既……又……""至少满足一项""都不""只满足一个""恰好满足两项""至少两项"；常见的"会开车/会游泳/会外语"调查类题目。
思考路径
  1. 判两集合还是三集合。
  2. 判公式类型（关键）：题干给出"同时参加 A 和 B"（含 C 的）→ 标准型；给出"只满足两项""满足三项"→ 非标准型。
  3. 画文氏图，从最里层（三项交集）往外标注。
  4. 套公式求未知量；最后若有"都不"，用"总 − 至少一项"求。
判定标准 · 公式清单
公式说明
A + B − AB = 总 − 都不两集合
AB = A + B −（总 − 都不）；都不 = 总 − A − B + AB求交集 / 求都不
三集合标准型：A+B+C − AB − AC − BC + ABC = 总 − 都不口诀"加三减二加一"
三集合非标准型：A+B+C − 只满足两项 − 2×满足三项 = 总 − 都不注意是减 2 倍
满足至少一项 = 总 − 都不—
至少两项 = 只两项 + 三项（≠ 只两项）高频陷阱
三项都满足的最小值 = max(0, A+B+C − 2(总−都不))求"至少"
三项都满足的最大值 ≤ min(A,B,C)求"至多"
选项处理上界排除：交集不可能大于任一单集合（AB ≤ min(A,B)）。下界排除：AB ≥ A + B − 总。人数/次数必为整数，算出小数说明公式用错。极值题把选项代入"能否构造出其余区域非负"验证。
高频陷阱
  • "只 A" 与 "A" 混淆（A 包含只 A、AB、AC、ABC）。
  • "至少两项" = 只两项 + 三项，不是只两项。
  • 标准型"加 ABC"与非标准型"减 2×ABC"混用。
  • 问"都不"忘记最后用总数减。
  • 题干中"同时参加 AB"是否含 C（一般含，除非写"只"）。
示例演示
某单位 100 人，会开车 60、会游泳 50、会烹饪 40；同时会开车游泳 30、开车烹饪 25、游泳烹饪 20；三种都会 10。问三种都不会的有多少人？
至少会一项 = 60+50+40 − 30−25−20 + 10 = 85　→ 都不会 = 100 − 85 = 15　答案 = 15 人

8最值问题（最不利原则 · 构造数列 · 均值不等式）

识别标志"至少……才能保证""最多/最少""至多""最大/最小""保证""一定"；或"总和固定，第 k 名最多/最少"；或"面积最大/用料最省"。
思考路径
  1. 见 "保证""一定" → 最不利原则（抽屉原理）。
  2. 见 "总和固定 + 某个量最大/最小" → 构造数列：求"第 k 名最多"→ 让其他人尽可能小；求"第 k 名最少"→ 让其他人尽可能大。
  3. 见 "面积最大/周长最小/用料最省" → 均值不等式或二次函数顶点。
  4. 全程注意整数约束：至少→向上取整，至多→向下取整。
判定标准 · 公式清单
公式 / 结论说明
最不利：最少次数 = 最不利情况 + 1保证型核心
n 种物品，保证取到 k 个同种 → n(k−1) + 1抽屉原理
某类总数不足 k 时，该类全部取完（不能取 k−1）高频变体
m 个物品放 n 个抽屉，至少一抽屉有 ⌈m/n⌉ 个抽屉原理
和定最值：设第一 x，其余最多 x−1 → x + (n−1)(x−1) ≥ S向上取整
均值不等式：a + b ≥ 2√(ab)，等号在 a = b 时取到和定积最大、积定和最小
周长固定的矩形中，正方形面积最大—
二次函数顶点 x = −b/2a，取整数需比较两侧整数点—
选项处理问"至少……保证"→ 答案偏大，先排除最小项。构造数列题用代入法最稳：问"第一名至少多少"→ 从最小选项开始代，验证其余能否构造出来。下界排除：第一名至少 ≥ ⌈总分 ÷ 人数⌉。极值题选项常成对（20 与 21），差 1 就是取整方向问题。
高频陷阱
  • "保证"与"可能"混淆（保证 = 最不利；可能 = 最好情况）。
  • 取整方向反了：至少→向上取整，至多→向下取整。
  • 构造数列忽略"互不相同""必须是整数"。
  • 最不利只想到一种"差一步"，遗漏其他情况。
  • 均值不等式忽略取等条件是否可达。
  • 问"第 k 名"还是"前 k 名总和"。
示例演示
袋中有红球 8、黄球 7、蓝球 5、绿球 4。一次至少摸出多少个，才能保证有 6 个球同色？
最不利构造：红取 5、黄取 5、蓝取 5、绿只有 4 个全部取完（不足 6，取不到 5）
最不利总数 = 5+5+5+4 = 19 → 19 + 1 = 20　答案 = 20 个
若误按"4 种颜色 × 5 + 1 = 21"就掉进了"绿球不足 6"的陷阱。

9年龄问题

识别标志"今年/几年前/几年后""是……的几倍""比……大几岁"；涉及生肖、属相、本命年（周期 12）。
思考路径
  1. 首选"年龄差不变"（最快，多数题 30 秒出答案）。
  2. 若"n 年后 A 是 B 的 m 倍" → 那时 B 的年龄 = 年龄差 ÷(m−1)，A = m × B，再倒推回今年。
  3. 三人以上、多个时点 → 列表法或方程法。
  4. 选项简单时直接代入排除（比列方程快）。
  5. 画时间轴：过去减、未来加；n 年前某人可能尚未出生。
判定标准 · 公式清单 年龄差恒定（最核心） m 倍时刻：小的 = 年龄差 ÷(m−1)，大的 = m × 小的 "A 是 B 的 n 倍" → A = nB；"A 比 B 多 n 倍" → A = (n+1)B 三人：n 年后三人年龄和增加 3n 生肖 12 年一轮，同属相年龄差是 12 的倍数
选项处理代入法：把选项当作"几年后"或"今年年龄"代入，看倍数关系成不成立。差值校验：任意两个年龄之差必须等于题干给的年龄差。合理性排除：年龄应在 0—100 之间，算出负数说明时点设反了。
高频陷阱
  • "是 n 倍"与"多 n 倍"（多 n 倍 = 是 n+1 倍）。
  • "几年前"用减、"几年后"用加，方向搞反。
  • 三人问题年龄和：n 年后总长增加 3n，不是 n。
  • 忽略"n 年前某人未出生"（年龄不能为负）。
  • 问"今年"还是"n 年后"。
示例演示
父亲比儿子大 28 岁，4 年后父亲的年龄是儿子的 3 倍。问儿子今年多少岁？
年龄差 28 恒定。4 年后：父亲 = 3×儿子 → 差 = 2×儿子 = 28 → 那时儿子 14 岁
今年儿子 = 14 − 4 = 10 岁（父亲 38 岁）。验算：4 年后 42 与 14，42 = 3×14 ✓　答案 = 10 岁

10浓度问题

识别标志浓度、盐水/酒精/糖水、"加水稀释""蒸发""混合""倒出再加满""反复操作"。
思考路径
  1. 抓溶质守恒：加水/蒸发时溶质不变 → 原溶液×原浓度 = 新溶液×新浓度。
  2. 混合：C混 = 总溶质 ÷ 总溶液。
  3. 两溶液混合求配比 → 十字交叉法。
  4. 反复倒出再加满 → 每次浓度 ×(V−a)/V，n 次后 × [(V−a)/V]ⁿ。
  5. 加纯溶质/纯水 → 视作浓度 100%/0% 的溶液，仍可用十字交叉。
判定标准 · 公式清单
公式 / 结论说明
浓度 = 溶质 ÷ 溶液 ×100%；溶液 = 溶质 + 溶剂定义
加水/蒸发：溶质不变守恒核心
C混 =（m₁C₁ + m₂C₂）÷（m₁ + m₂）混合
十字交叉：高浓度份数 : 低浓度份数 =（C混 − C低）:（C高 − C混）交叉相减，横看比例
反复倒出 a 再加满水，n 次后浓度 = 原浓度 × [(V−a)/V]ⁿ秒杀公式
混合浓度必介于两原浓度之间校验用
选项处理区间排除：混合浓度必在两原浓度之间。反复操作题答案常是"原浓度 × 整齐分数的幂"，选项中找等比衰减的一组（如 48% → 36% → 27%，每次 ×3/4）。验算用"溶质 = 溶液 × 浓度"回代。
高频陷阱
  • "倒出再加满水" 与 "倒出后不加水" 完全不同。
  • 加溶质时溶液质量也增加。
  • 十字交叉得到的是质量比，给体积需换算。
  • 白酒度数是体积分数。
  • 蒸发量：先由"溶质 ÷ 新浓度"得新溶液，差值才是蒸发的水。
示例演示
500 g 浓度 20% 的盐水。先倒出 100 g，加满水；再倒出 100 g，加满水。求最终浓度。
每次"倒出 100 g 再加满水"，浓度变为原来的 (500−100)/500 = 0.8
操作两次：20% × 0.8² = 20% × 0.64 = 12.8%　答案 = 12.8%

11几何问题

识别标志长度、角度、周长、面积、表面积、体积；图形折叠与展开、"蚂蚁爬行最短路径"、相似、内切外接、在图形上种树/铺砖/刷漆。
思考路径
  1. 无图必画草图，标出全部已知量。
  2. 找等量关系：等底等高、等体积、相似、勾股。
  3. 缺条件 → 找隐藏条件：直径所对圆周角 90°、正方形对角线 = √2×边长、正三角形高 = √3/2×边长。
  4. 最短路径：展开成平面 → 两点之间直线最短（要比较多种展开方式取最小）。
  5. 不规则图形 → 割补法。相似：边长比 k → 面积比 k² → 体积比 k³。
判定标准 · 公式与常用结论
图形周长 / 表面积面积 / 体积
正方形4aa²
长方形2(a+b)ab
三角形a+b+c底×高/2
梯形四边和(上底+下底)×高/2
圆2πrπr²
扇形2r + 弧长nπr²/360 = ½×弧长×r
正方体6a²a³
长方体2(ab+bc+ac)abc
圆柱2πr² + 2πrhπr²h
圆锥πr² + πrlπr²h/3（别忘 ÷3）
球4πr²4πr³/3
常用结论：勾股数 3-4-5、6-8-10、5-12-13、8-15-17、7-24-25；30° 直角三边比 1:√3:2，45° 为 1:1:√2；三角形三边 |a−b| < c < a+b；圆柱侧面展开 = 长方形（长 2πr、宽 h）；圆锥侧面展开 = 扇形（弧长 = 2πr、半径 = 母线 l）；正方体展开图共 11 种；相似比 k → 面积 k²、体积 k³。
选项处理先判断是否含 π：题中数据若能约掉 π，答案不含 π → 排除含 π 项。夹逼估算：不规则图形用外接矩形/内接图形估上下界。最短路径必须算出 2—3 种展开方式再取最小。
高频陷阱
  • 单位不统一（cm 与 m、面积与体积）。
  • "表面积" vs "侧面积"（无盖水箱、只刷四周）。
  • 三角形三边关系未验证。
  • 相似比方向搞反。
  • 圆锥/球体积忘记 ÷3 或 4/3；"增加 1 倍" = ×2。
示例演示
圆柱形容器底面半径 3 dm、高 10 dm，装水深 6 dm。将底面半径 2 dm、高 5 dm 的圆柱铁块竖直沉入水底，问水面上升多少 dm？
水体积 = π×3²×6 = 54π。先判断铁块是否被淹没：若水面 h ≤ 5，水占据底面积 = 9π − 4π = 5π，5πh = 54π → h = 10.8 > 5 矛盾 → 铁块被完全淹没
淹没时：54π + π×2²×5 = π×3²×H → 74 = 9H → H = 74/9 ≈ 8.22
上升 = 74/9 − 6 = 20/9 ≈ 2.22 dm　答案 = 20/9 dm
若忽略"是否被淹没"，直接用"排水体积 ÷ 底面积"会得 4 dm 的错误答案。

12周期与日期问题

识别标志"星期几""闰年/平年""每隔几天""第 n 个是什么""轮流值日/值班""生肖/属相""循环往复"。
思考路径
  1. 找周期 T（星期 7，生肖 12，甲乙丙轮流 3，干支 60）。
  2. 算"经过天数"，注意算头不算尾（第 1 天到第 n 天经过了 n−1 天）。
  3. 天数 mod T，余数对应位置（余 0 取周期最后一个）。
  4. 跨年推算星期：平年 +1，闰年 +2；判断依据是"期间是否跨过 2 月 29 日"。
  5. 循环问题：总量 ÷ 周期，看余数定位。
判定标准 · 公式清单
公式 / 结论说明
平年 365 = 52×7+1 → 同日期下一年星期 +1；闰年 +2—
闰年判断：能被 4 整除但不能被 100 整除，或能被 400 整除1900 非闰年，2000 是闰年，2024 是、2025/2026 不是
跨年推算：期间跨过 2 月 29 日才 +2，否则 +1不是"整年就 +2"
n 天后星期 =（原星期 + n）mod 7—
"每隔 n 天" = 每 n+1 天一次 → 周期是 n+1高频陷阱
第 n 个 = 周期中第（n mod T）个，余 0 取第 T 个循环
月天数：1、3、5、7、8、10、12 月 31 天；4、6、9、11 月 30 天—
选项处理星期答案只有 7 种，先做首尾夹逼估算大致周几。若两个选项相差 7 天（日期题）或相差一周（星期题），答案多在其中之一。代入法：把选项日期代回算天数差，验证 mod 7 的余数。
高频陷阱
  • "每隔 3 天" = 每 4 天一次（周期是 4 不是 3）。
  • 闰年判断：世纪年必须被 400 整除。
  • 跨年 +1 还是 +2：看有没有跨过 2 月 29 日。
  • "第 n 天"与"过了 n 天"差 1。
  • 循环题的起始基准点搞错。
示例演示
已知 2026 年 6 月 1 日是星期一，问 2026 年 10 月 1 日是星期几？
6/1→7/1 经 30 天；7/1→8/1 经 31 天；8/1→9/1 经 31 天；9/1→10/1 经 30 天 → 共 122 天
122 ÷ 7 = 17 余 3 → 星期一 + 3 = 星期四

13植树与方阵问题

识别标志种树、装路灯、立旗杆、车队长度、队伍长度；锯木头、爬楼梯、敲钟（同属"间隔模型"）；队列方阵、方阵最外层、空心方阵。
思考路径
  1. 判线形 / 环形 / 楼间（两端有建筑）。
  2. 判两端：都栽 / 一端栽 / 两端都不栽。
  3. 棵数 = 间距数 +1 / 间距数 / 间距数 −1。
  4. 间隔模型变形：锯木头、爬楼梯、敲钟统一用"次数 = 段数 − 1"。
  5. 方阵：先求边长 n，再套最外层 4n−4、总数 n²。
判定标准 · 公式清单
公式 / 结论说明
线形两端都栽：棵 = 段 + 1 = 总长÷间距 + 1—
环形 / 一端栽：棵 = 段 = 总长÷间距封闭不加 1
两端都不栽（楼间）：棵 = 段 − 1—
每边 n 棵的正方形四周：总数 = 4n − 4四角重复
方阵总人数 = n²；最外层 = 4n − 4—
次外层 = 4n − 12；相邻两层相差 8实心方阵
空心方阵总数 = 外边长² − 内空心边长²—
锯木头：锯成 n 段需锯 n−1 次间隔模型
爬楼梯：1 楼到 n 楼走了 n−1 层间隔模型
敲钟：敲 n 下有 n−1 个间隔间隔模型
选项处理整数校验：总长 ÷ 间距 必须为整数，不整除说明模型判断错了。方阵题用整除性秒杀：总人数必为完全平方数；最外层人数必能被 4 整除 → 可直接排除 2—3 个选项。爬楼梯题选项常成对差 1，注意"1 楼到 6 楼"是 5 层。
高频陷阱
  • 环形 vs 线形混淆（环形不加 1）。
  • 两端有建筑物/已有树 → 两端都不栽。
  • 锯木头/敲钟/爬楼的"次数 = 段数 − 1"。
  • 最外层 = 4n − 4 而非 4n。
  • 空心方阵内层边长 = 外层边长 − 2×层数。
示例演示
正方形操场四周种树，每边都种 11 棵，四个角都必须种。一共要种多少棵？
四边共 11 × 4 = 44 棵，但四角的树各被相邻两边数了 2 次，重复 4 棵 → 44 − 4 = 40
（或用公式 4n − 4 = 4×11 − 4 = 40）　答案 = 40 棵

14不定方程与和差倍比（含鸡兔同笼）

识别标志两个未知量但只有一个等量关系；"共花多少元、各买了多少"；鸡兔同笼、答题得分、门票；题干只给比例/分数、没给具体数值（→ 赋值）。
思考路径
  1. 列出 ax + by = c（x、y 为正整数）。
  2. 尾数法：ax 的尾数 + by 的尾数 = c 的尾数 → 锁定可能的尾数组合。
  3. 整除特性：(c − by) 必须能被 a 整除 → 枚举 y。
  4. 奇偶性快速缩小 y 的范围。
  5. 范围限定：x ≥ 1、y ≥ 1，x ≤ c/a、y ≤ c/b → 大幅减少枚举量。
  6. 求"最多/最少" → 从边界开始枚举。
  7. 和差倍比：见比例就设份数，多个比例要先统一不变量。
判定标准 · 公式清单
公式 / 结论说明
鸡兔同笼：兔 =（总脚 − 2×总头）/2；鸡 = 总头 − 兔假设全鸡
通用：A 数 =（总值 − 小值×总数）÷（大值 − 小值）通用公式
得分题：答对 =（实得分 + 扣分×总题）÷（对得分 + 扣分）假设全错
不定方程解法优先级：代入选项 > 尾数 > 整除 > 奇偶实战顺序
整除判定：被 2/5 看末位；4/25 看末两位；8/125 看末三位；3/9 看各位数字和；11 看奇偶位差—
和差问题：大数 =(和+差)/2，小数 =(和−差)/2—
"甲比乙多 1/3" → 甲 = 4/3 乙 → 甲:乙 = 4:3高频
比例统一：甲:乙 = 2:3、乙:丙 = 4:5 → 乙统一为 12 → 8:12:15—
选项处理直接代入选项最快：把选项作 x，求 y 看是否为整数、是否满足约束。问"x 最大"→ 从最大选项开始代。整除排除：答案必是某数的倍数 → 先排除非倍数项。尾数法只看个位数即可锁定，5 秒出结果。
高频陷阱
  • "多 1/3" 与 "是 1/3" 混淆（多 1/3 = 是 4/3）。
  • 鸡兔同笼假设法后忘记用总数减。
  • 不定方程忽略"正整数"约束导致多解。
  • 整除特性用错（被 6 整除需同时被 2 和 3 整除）。
  • 赋值法赋错对象（应赋不变量）。
示例演示
买 3 元的笔记本和 5 元的钢笔，共花 61 元，两种都买且笔记本多于钢笔。问笔记本最多买多少本？
3x + 5y = 61，x > y ≥ 1，求 x 最大 → 需 61 − 5y 被 3 整除
y=2 → x=17（17>2 ✓）；y=5 → x=12；y=8 → x=7（7<8 ✗）；y=11 → x=2（✗）
y=1、4、7、10 时 61−5y 不被 3 整除 → 答案 = 17 本

15常识判断整体策略

识别标志进入常识模块即调用。常识是典型的"会就会、不会就不会"模块：20 秒内没思路的题，再给 2 分钟也对不了。
思考路径
  1. 位置选择：可放开考第一模块（按卷面顺序，趁清醒快速过），也可放最后。关键是严格卡时间。推荐按卷面顺序做，设 7 分钟闹钟。
  2. 单题标准流程（≤20 秒）：读题干 → 圈出"正确 / 不正确"（最关键一步）→ 圈限定词（主体、时间、范围、"最""首"）→ 扫 4 个选项，能排除几个排几个 → 剩 1—2 个立即选，不回想。
  3. 三不原则：不苦思回忆、不过度推理、不回头检查。
  4. 不会就蒙：立刻选一个，绝不空题。
  5. 涂卡时对齐题号（常识题量最大，最容易串行）。
判定标准 · 会 / 半会 / 不会的判据
状态判据处理用时
会看到选项立刻能确认（10 秒内）直接选≤10 秒
半会能排除 2 个，剩 2 个摇摆排除法 + 温和表述优先，选一个≤20 秒
不会只能排除 0—1 个立即蒙，不纠结≤10 秒
选项处理 · 蒙题与排除法原则
原则操作
绝对化排除含"一定/所有/都/必须/唯一/完全/永远/绝不"的选项多为错

统一蒙剩余题统一蒙"已确定答案中出现最少"的选项
"以上都是"三项中有一项能确认错 → 排除；三项均无法排除 → 选它的概率高

高频陷阱
  • 把"不正确"看成"正确"（必须圈出来，最高频失误）。
  • 在不熟的选项上纠结 1—2 分钟，等于白丢 3—5 道题的时间。
  • 反复改答案（第一直觉更准）。
  • 常识超时挤占资料分析/判断推理（常识提分天花板最低）。
  • 涂卡串行。
示例演示
下列说法正确的是：A. 我国地势东高西低，呈三级阶梯分布　B. 我国最大的淡水湖是鄱阳湖　C. 长江是我国最长的内流河　D. 黄河发源于巴颜喀拉山，注入黄海
圈"正确" → A"东高西低"应为西高东低 ✗（2 秒）→ B 保留 → C 长江注入东海是外流河，最长内流河是塔里木河 ✗ → D 黄河注入渤海不是黄海 ✗
答案 = B（用时约 15 秒。C 与 D 是典型的"方位/归属错位"设错方式）

16政治 / 时政类

识别标志出现"会议""全会""文件""规划""指出/强调/提出""首次""核心""根本""坚持以……为中心"；选项为长句表述或 ①②③④ 组合型。
思考路径
  1. 先看问法（正确 / 错误），圈出来。
  2. 拆主谓宾：谁提出的？哪个会议通过的？哪个文件部署的？→ 查"主体—文件—内容"三者是否匹配。
  3. 查时间线：会议/文件的年份与内容是否对得上。
  4. 查程度词："首次""最""唯一""彻底""已经完成" → 高度警惕。
  5. 查概念：近义词是否被偷换（"基本实现"↔"全面实现"，"建设"↔"建成"）。
  6. 不会 → 排除法，温和表述优先。
判定标准 · 常见设错方式（只记设错套路）
设错方式表现破解
时间错位把 A 会议的内容安到 B 会议记"时间—会议—关键词"三元组
主体张冠李戴把某理论/战略归于错误的会议或文件查主体与内容是否匹配
程度拔高"首次""最""唯一""彻底""已经全面完成"绝对化多为错
范围扩大/缩小"所有""一律""只能""仅"扩大化多为错

因果倒置把"手段"说成"目的"通读一遍逻辑关系
阶段混淆战略目标的时间节点错位记阶段划分的年份锚点
数字口径增长率、比重、年份数字被改动数字是最常被改的设错点
新旧表述用已被替代的旧提法关注"最新表述"
选项处理 · 组合型选项是排除法效率最高的题型只要能确定任意一个小项错，就排除所有含它的选项，通常一步锁定答案。"以上都对"：先找明显错项，找不到则选它概率较高。两个表述几乎相同 → 二者多都错；两个完全矛盾 → 答案必在其一。
时政备考口径（记什么、怎么更新） 记每个时政点只需四个要素：① 时间（年、月）② 会议/文件全称 ③ 一句话核心关键词 ④ 地位表述（第几次 / 首次 / 里程碑）。
自查清单（用考前 3 个月内的官方发布更新，避免背过时版本）：党中央重要全会（全称、时间、通过的决定名称）｜全国两会与政府工作报告（年度主要预期目标数据）｜中央一号文件（当年主题）｜五年规划相关部署｜新制定/修订的重要法律（通过日期 与 施行日期，两者常不同，高频考点）｜重大科技成就｜重要主场外交与国际会议｜陕西省情（省内重要会议与政策、历史文化、地理区位、经济数据——陕西事业单位必考）。
时政条目更新快，本框架只提供判定口径与设错识别方法，不填充具体表述，请对照上表用官方渠道（政府网、新华社、人民日报）在考前 3 个月内更新。
高频陷阱
  • 记混会议届次（几中全会、第几次）→ 只记关键词，不背长句。
  • "已经实现/全面完成" 与 "正在推进/基本实现" 阶段混淆。
  • 把"战略目标"与"具体举措"混为一谈。
  • 组合型选项漏看小项。
  • 法律的"通过日期"与"施行日期"混淆（二者常相差数月）。
示例演示
关于我国重要法律的施行时间，正确的是：A. 《民法典》自 2020 年 5 月 28 日起施行　B. 自 2021 年 1 月 1 日起施行　C. 自 2020 年 10 月 1 日起施行　D. 自 2021 年 7 月 1 日起施行
四项互斥，属"必居其一"型，值得判。《民法典》于 2020 年 5 月 28 日通过，2021 年 1 月 1 日施行
A 把"通过日"当成"施行日" → 错（最高频设错方式）　答案 = B

17法律类

识别标志"根据《XX 法》，下列说法正确的是"；出现"应当承担/有权/无权""属于/不属于""应当/可以"；涉及年龄、时限、期限、责任形式、权利归属。
思考路径
  1. 先锁定部门法（最关键）：宪法 / 民法 / 刑法 / 行政法 / 劳动法 / 诉讼法 —— 不同部门法规则完全不同，混用是最常见设错方式。
  2. 再锁定考点类型：主体资格（年龄/身份）、时限（诉讼时效/复议期限/起诉期限）、责任形式、权利归属。
  3. 用倾向性原则辅助：民法/劳动法倾向保护弱势方；刑法坚持罪刑法定（法无明文不为罪）。
  4. 数字优先记：年龄节点、时限天数（性价比最高的考点）。
  5. 无法确认 → 排除绝对化、排除部门法混用项。
判定标准 · 高频考点与判定口径 宪法：根本大法，最高法律效力；全国人大是最高国家权力机关、行使立法权，国务院是最高行政机关；宪法修改需全国人大全体代表 2/3 以上多数通过，法律和其他议案过半数；国家宪法日 12 月 4 日。
民法典：完全民事行为能力 ≥18（或 16 周岁以上以劳动收入为主要生活来源视为完全）；限制 8 ≤ x < 18；无 < 8。普通诉讼时效 3 年（最长 20 年）。不动产登记生效；居住权登记设立（用益物权）。结婚年龄男 ≥22、女 ≥20；离婚冷静期 30 日。继承第一顺序：配偶、子女、父母；公证遗嘱不再优先，以最后的遗嘱为准。无过错责任适用于产品责任、环境污染、高度危险作业、饲养动物损害。胎儿涉及遗产继承、接受赠与等视为具有民事权利能力。
刑法：三原则（罪刑法定、适用法律人人平等、罪责刑相适应）。刑事责任年龄：≥16 完全负刑责；14 ≤ x < 16 对故意杀人、故意伤害致人重伤或死亡、强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质 8 类重罪负刑责；12 ≤ x < 14 特定情形经最高检核准追诉的负刑责。主刑：管制、拘役、有期徒刑、无期徒刑、死刑；附加刑：罚金、剥夺政治权利、没收财产、驱逐出境。正当防卫明显超过必要限度造成重大损害 = 防卫过当（应负刑责但应减轻或免除）。
行政法：行政处罚种类含警告、通报批评、罚款、没收、暂扣或吊销许可证件、限制开展生产经营活动、责令停产停业、行政拘留等；处罚时效 2 年（涉及公民生命健康安全、金融安全且有危害后果的为 5 年）；行政复议 60 日内申请；行政诉讼 6 个月内起诉，举证责任主要由被告（行政机关）承担；行政强制措施（限制人身自由、查封、扣押、冻结）与行政强制执行（加处罚款、划拨、拍卖）不同。
选项处理 · 常见设错方式
设错方式典型表现
部门法混淆把"罚金"（刑罚，法院判）说成"罚款"（行政处罚）
年龄节点错把 8 周岁记成 10 周岁；16 与 18 混
时限混淆行政复议 60 日 vs 行政诉讼 6 个月 vs 诉讼时效 3 年

  • "罚金"与"罚款"（刑法 vs 行政法）—— 出现频率极高。
  • "行政处罚"与"行政处分"（外部行政行为 vs 内部人事处理）。
  • 诉讼时效起算点（知道或应当知道权利受损及义务人之日）。
  • 正当防卫与紧急避险混淆（避险损害的是第三方合法权益）。

示例演示
下列说法正确的是：A. 8 周岁的小明独自购买 5000 元手机，该行为有效　B. 15 周岁的小红签订的买卖合同一律无效　C. 17 周岁的小刚以劳动收入为主要生活来源，视为完全民事行为能力人　D. 不能完全辨认自己行为的成年人属无民事行为能力人
A：8 周岁属限制民事行为能力人，大额交易效力待定，非"有效" ✗｜B：限制行为能力人订立的合同是效力待定，不是"一律无效"（纯获利益的有效）✗｜C：16 周岁以上以劳动收入为主要生活来源 → 视为完全民事行为能力人 ✓｜D：不能完全辨认 → 限制；完全不能辨认才是无民事行为能力 ✗
答案 = C

18经济 / 科技 / 人文 / 地理速判与排除法

识别标志跨四个小模块，覆盖面最广。共同特征：大量"配对题"和"之最题" —— 这正是排除法的用武之地。
思考路径
  1. 分层处理：不追求全覆盖，每个模块只记"锚点 + 排除规则"。
  2. 排序题（朝代、事件先后）→ 先定首尾，通常能排掉 2 个选项。
  3. 配对题（人物—作品、国家—首都、朝代—事件、诗句—节日）→ 找最确定的那一个配对，从它突破：违反它的全排。
  4. "之最"题 → 死盯限定词：最大 vs 最长 vs 最深、中国 vs 世界、淡水湖 vs 湖泊、内流河 vs 外流河。
  5. 原理题（物理化学生物）→ 用生活经验判，违背直觉的直接排。
判定标准 · 四模块锚点清单 经济：GDP 按地域（国内）、GNP 按国民；CPI 居民消费价格（上涨 = 通胀）、PPI 工业生产者出厂价格；恩格尔系数 = 食品支出÷总消费支出，越低越富裕；基尼系数 0—1，0.4 为国际警戒线；财政政策 = 税收、政府支出、国债；货币政策 = 利率、存款准备金率、公开市场业务、再贴现（最高频设错点）；经济过热/通胀 → 紧缩，衰退/通缩 → 扩张；本币升值 → 利进口、不利出口。 科技：光——反射（镜面、倒影）、折射（筷子弯折、海市蜃楼、透镜）、色散（彩虹、三棱镜）、直线传播（影子、日食、小孔成像）；声——音调 = 频率、响度 = 振幅、音色 = 发声体材料结构，真空不能传声；物态——升华（干冰、樟脑丸变小、冰冻衣服变干）、凝华（霜、雾凇、窗花）、液化（露、"白气"）；"白气"是液化形成的小水滴，不是水蒸气（水蒸气不可见）；燃烧三要素——可燃物、助燃物、温度达着火点，油锅着火用锅盖隔绝氧气不能用水；酸雨 pH < 5.6；温室气体 CO₂、甲烷；臭氧层破坏（氟利昂）；抗生素只对细菌有效，对病毒无效；成就归属——神舟（载人飞船）、嫦娥（探月）、天问（火星）、北斗（导航）、天宫（空间站）、羲和/夸父（太阳）、蛟龙号/深海勇士/奋斗者号（深潜）、C919（大飞机）、神威·太湖之光/天河（超算）、九章/祖冲之号（量子计算）、墨子号（量子通信卫星）。 人文：朝代顺序——夏商与西周，东周分两段，一统秦两汉，三分魏蜀吴，二晋前后延，南北朝并立，隋唐五代传，宋元明清后；《史记》司马迁·纪传体通史·第一部，《资治通鉴》司马光·编年体，《汉书》班固·第一部纪传体断代史；四大发明——造纸（东汉蔡伦改进）、印刷（隋唐雕版、北宋毕昇活字）、火药（唐）、指南针（战国司南、北宋用于航海）；唐宋八大家——韩愈、柳宗元、欧阳修、苏洵、苏轼、苏辙、王安石、曾巩（无李白杜甫）；诗人别称——李白诗仙、杜甫诗圣、王维诗佛、白居易诗魔、李贺诗鬼、刘禹锡诗豪；四书——大学、中庸、论语、孟子，五经——诗、书、礼、易、春秋；二十四节气——春雨惊春清谷天，夏满芒夏暑相连，秋处露秋寒霜降，冬雪雪冬小大寒；清明是唯一既是节气又是节日；端午（屈原）、重阳（登高、插茱萸、敬老）、中秋（赏月）。 地理：地势西高东低三级阶梯（一二级界线：昆仑山—祁连山—横断山；二三级：大兴安岭—太行山—巫山—雪峰山）；四大高原——青藏（最高·世界屋脊）、内蒙古（最平坦）、黄土（千沟万壑）、云贵（喀斯特）；秦岭—淮河：南北方分界、1 月 0℃ 等温线、800 mm 等降水量线、亚热带与暖温带分界（超高频）；长江（最长，发源唐古拉山，注入东海）、黄河（发源巴颜喀拉山，注入渤海，下游"地上河"）、塔里木河是最长内流河；青海湖 = 最大湖泊、最大咸水湖；鄱阳湖 = 最大淡水湖；五岳——东岳泰山（山东）、西岳华山（陕西）、南岳衡山（湖南）、北岳恒山（山西）、中岳嵩山（河南）；陕西本地——省会西安（十三朝古都）、秦岭横贯、陕北黄土高原—关中平原（八百里秦川）—陕南秦巴山地、黄河流经陕北、壶口瀑布、兵马俑、华山、法门寺、大雁塔。
选项处理（通用）排序题先定首尾 → 排除 2 项 → 剩下 2 项只比较中间两项。配对题从最确定的配对切入。之最题死盯限定词。两项互相矛盾 → 答案必在其一。"以上都是" → 先找明显错项。数字/年份题：过于精确或罕见的多为错。
高频陷阱
  • 把"错误/不正确"看成"正确"（常识第一大失误）。
  • "最大的湖泊"（青海湖）与"最大的淡水湖"（鄱阳湖）混淆。
  • 财政政策与货币政策混用（"降低存款准备金率"是货币，不是财政）。
  • "白气是水蒸气" → 错，是液化小水滴。
  • 朝代 / 人物 / 作品错配。
  • "抗生素能治病毒性感冒" → 错。
  • 地理方位记反（"东高西低""长江注入黄海"）。
  • 科技成就张冠李戴（嫦娥说成火星、天问说成探月）。
