模块 · 资料分析

目标用时 18—22 分钟 ｜ 目标正确率 85—90% ｜ 题量通常 15—20 题（3—4 篇材料，每篇 5 题）

A. 材料层面（1 份）

1材料速读标准动作（文字 / 表格 / 图形 / 综合）

识别标志看到题本上一整块数据信息，在读题之前执行，全程限时 60—90 秒
思考路径（六步，顺序不可乱）
  1. 扫单位：表头括号里、图右上角、文字材料里的"亿元/万吨/‰"。单位先定，后面量级不会翻车。
  2. 扫时间：圈出所有时间词——年份、"1—5月"、"一季度"、"比上年同期"、同比/环比，并标"现期 = ？年"。
  3. 标节奏点：文字材料每段首句写 2 字索引（工业、投资、消费、外贸）；表格在左标目旁写行号 ①②③；图形给每条线编号。
  4. 标结构：找"整体—部分"链条（总量 = 各分项和；进出口 = 出口 + 进口）。凡出现"占""其中"，立刻画分界线。
  5. 标陷阱：出现"累计""其中""剔除""可比价""名义"就地打三角。
  6. 不读数字：只读结构与单位，具体数字留到做题时定位。先读数字必然要重读一遍。
判定标准 · 四类材料速读口诀
材料口诀一眼要抓到
文字型一段一主体，首句定全段段落顺序通常 = 出题顺序
表格型横看主体，竖看时间，交叉点取数合计列、备注行、"其中"行；累计 ≠ 当期
柱状图看高度差 + 看标签纵轴是否被截断（非 0 起点时视觉比例失真）
折线图看斜率 + 看拐点斜率 = 增长量趋势，不是增长率（最常见读图错）
饼图看扇形 + 看占比标注12 点方向起顺时针；各扇区之和 = 100%，可验证
综合型总在多处出现 = 交叉定位锚同一"总计"在两表都出现 → 串联两表的钥匙
选项处理速读阶段不看选项、不做计算。读完立刻在草稿纸写一行锚点信息：现期年 = 2025｜单位 = 亿元/万吨｜整体 = XX｜部分 = XX。做题时定位超 15 秒未找到 → 跳过，最后回头。
高频陷阱
  • 累计 vs 当期：把"1—5月累计"当成"5月当月"。
  • 单位不统一：文字用"万吨"、表格用"吨"；金额一处美元一处人民币。
  • 图轴起点非 0：柱高差 2 倍但实际比值 1.2 倍。
  • 不看注脚："注：自本年口径调整"直接影响所有比较题。
  • "其中"只列部分项：把"其中"几项相加当成整体合计，漏了未列项。
示例演示 材料："2025 年 H 省粮食播种面积 4523 千公顷，比上年增加 38 千公顷；粮食产量 2865 万吨，同比增长 1.8%。其中，夏粮 1421 万吨（+2.3%），秋粮 1382 万吨（−0.6%）……"
→ 单位扫描：千公顷 / 万吨（两套，别混）；现期 2025；索引【粮食】【肉】；验算：1421 + 1382 = 2803 ≠ 2865 → 存在 62 万吨未说明 → 草稿纸记 ⚠，后续任何"除粮食外"型题都要小心。

B. 核心题型（9 份）

2基期量（含基期求和、基期比较、隔年基期）

识别标志关键词"上年""同期""2024年""比上年……之前"；题干时间比材料年份早一年。变形问法：多个主体基期相加（基期求和）、比较谁去年更大（基期比较）、跨两年往前推（隔年基期）。
思考路径
  1. 确定已知什么：给现期 A + 增长率 R？还是 A + 增长量 X？
  2. 给 A + R → B = A/(1+R)，用截位直除；R 在 5%—25% 且选项差距小时用假设分配法。
  3. 给 A + X → B = A − X，直接减；下降时 B = A + |X|。
  4. 下降情形先定界：1+R = 1−|R| 分母变小 → 基期必然大于现期。
  5. 基期求和：两个 R 接近（差 <3 个百分点）可用"先合后除"(A₁+A₂)/(1+R̄)；R 差异大必须分开算。
  6. 基期比较：先试定性排除（A 大且 R 小者必大），不行再用分数比较。
  7. 隔年基期：先算隔年增长率 R隔 = r₁ + r₂ + r₁r₂，再一次除 B₂ = A/(1+R隔)。
  8. 算出必回乘：B×(1+R) ≈ A。
判定标准 · 公式清单
情形公式速技法
已知 A、RB = A/(1+R)截位直除
已知 A、XB = A − X（下降 A+|X|）直减
R < 10% 速估B ≈ A×(1−R)化除为乘
隔年增长R隔 = r₁ + r₂ + r₁r₂两率相加再加乘积
隔年基期B₂ = A/[(1+r₁)(1+r₂)]等价于 ÷(1+R隔)
放缩锚：1/1.1≈0.909、1/1.2≈0.833、1/1.05≈0.952、1/0.95≈1.053、1/1.15≈0.87
选项处理先看选项再定截位：首位不同 → 分母截 2 位；首位同第二位不同 → 截 3 位。下降题用定界：R = −22.9% → B = 8872/0.771，因分母 <1 答案必 >8872，直接砍掉所有小于材料的选项。
高频陷阱
  • 下降当成增长：把"同比下降 6.1%"算成 A/1.061，正确是 A/0.939。判据：下降 → 基期比现期大；增长 → 基期比现期小。
  • 时间退错一年：问"两年前"只退了一年。
  • 百分点 vs 百分比："增速比上年回落 3 个百分点" → 上年增速是 r + 3%，不是 r×1.03。
  • 基期求和先加现期再除：两个主体的增速是加权结果，不能随便拿一个 R 代。
  • 量级：算完检查方向，增长时 B 必须小于 A，若反了说明除乘搞反。
示例演示
2025 年某省规上工业增加值 12345 亿元，同比增长 8.5%。问 2024 年约为多少亿元？
A. 11260　B. 11380　C. 11500　D. 12100
① 识别：给现期 + 率求基期 → B = A/(1+R)
② 定界：增长 → 基期 < 12345，四项都满足，需计算
③ 看选项截位：选项首位均为 1，第二位有差异 → 截 3 位
④ 计算：12345/1.085 ≈ 12345/1.09 ≈ 11326；回乘验证 11380×1.085 = 11380+967.3 = 12347.3，与 12345 差 0.02%
⑤ 量级：11380 与 12345 同量级且略小 ✓　答案 = B
隔年延伸：若 2024 年同比 +8%，求 2023 年 → R隔 = 8.5%+8%+0.68% = 17.18%，12345/1.1718 ≈ 10535。

3现期量（含追赶 / 假设增长）+ 假设分配法

识别标志"按此速度""照此增长趋势""预计明年""到 2027 年将是""翻番到"；题干时间在材料年份之后。追赶快问法："乙保持此增速，几年后能超过甲？"
思考路径
  1. 判断基数是哪一个：从哪年往后推，就把哪年当作 B。
  2. 单期推：A = B×(1+R)，用乘法不用除法。
  3. 多期推：Aₙ = B×(1+R)ⁿ；n ≤ 3 逐年乘，n ≥ 4 用 1+nR 粗估再修正。
  4. 追赶/追平：逐年列账，每年记录甲值、乙值、差值直到变号，不要列方程。
  5. 假设增长型（"增速与 2023—2024 年均值持平"）：先算平均增速再代入。
  6. 分段增速：Aₙ = B×(1+r₁)^a×(1+r₂)^b。
判定标准 · 假设分配法（两套） 乘法版（求现期）：① 设基期 100 份 → 每份 = B/100；② 现期份数 = 100+R（下降 100−|R|）；③ A = 每份 ×(100+R)。
反向版（求基期，R 在 5%—25% 最准）：① 假设 B₀ = A；② 假设增量 X₀ = A×R；③ 真实增量 X = X₀/(1+R)；④ B = A − X。
R > 50% 时误差大，改用截位直除。
复利速查：1.1²=1.21, 1.1³=1.331, 1.1⁴=1.464, 1.1⁵=1.611；1.2²=1.44, 1.2³=1.728, 1.2⁴=2.074
72 法则：翻番年数 ≈ 72 ÷ R的百分数（R=10% → 约 7.2 年）
选项处理单期推选项差距通常很大，乘到两位有效数字即可。多期推先算 (1+R)ⁿ 整体倍数再乘 B，减少中间舍入误差。追赶题选项多是"第 N 年"，逐年做差即可，做出现实答案再对照。
高频陷阱
  • n 数错：2024 年底到 2027 年底是 3 年（2025、2026、2027），不是 4 年。
  • 用除法代替乘法：B/(1+R) 结果偏小。自检：往后推必然变大。
  • 追赶题用全期平均增长：绝对差距逐年不同，必须逐年算。
  • "增速不变" ≠ "增量不变"：默认"保持增速"用等比，明确说"保持增量"才用等差。
  • 量级：份数法漏掉百分位（写成 ×1.15 而非 ×115）→ 答案缩水 100 倍。
示例演示
2025 年甲企业营收 1200 万，乙 900 万。此后甲每年 +8%，乙每年 +20%。问乙第几年超过甲？
A. 第2年　B. 第3年　C. 第4年　D. 第5年
年甲 1200×1.08ⁿ乙 900×1.2ⁿ甲−乙
01200900+300
112961080+216
21399.71296+103.7
31511.71555.2−43.5
第 3 年差值由正转负 → 答案 = B。量级校验：两者同量级 ✓，乙增速更快终将超出 ✓。
份数法单期演示：某县 2024 年一般公共预算收入 86.4 亿元，2025 预计 +12.5% → 每份 = 0.864，现期 = 0.864 × 112.5 = 97.2 亿元；回乘 97.2/1.125 = 86.4 ✓

4增长率（一般增长率 · 比较 · 隔年 · 同比环比）

识别标志"增长/下降…%""增速""增幅""同比/环比"；答案单位一定是 %。若问"增长了多少亿元"则是增长量。比较问法："增速最快/最慢的是"。
思考路径
  1. 先锁定分子分母：R = X/B = (A−B)/B。分母永远是基期，不是现期（第 1 号错误源）。
  2. 已知 A、B → R = A/B − 1，比较时直接比 A/B 即可。
  3. 已知 A、X → R = X/(A−X)；已知 B、X → R = X/B。
  4. 增长率比较：分母量级差 10 倍以上时先统一量级再比。
  5. 隔年增长率：R隔 = r₁ + r₂ + r₁r₂。
  6. 同比 = 与上年同期；环比 = 与上一个相邻统计期。材料未给上月数据 → 环比算不出，别硬套。
判定标准 · 公式清单
类型公式
一般增长率R = (A−B)/B = A/B − 1 = X/B
已知 A、XR = X/(A−X)
隔年增长率R隔 = r₁ + r₂ + r₁·r₂
环比推同比(1+r₁)(1+r₂)… − 1
负增长注意：A < B 则 R < 0。比较"增速"时带符号比大小；比较"降幅"时看绝对值。
选项处理选项是百分数且首位不同 → 截 2 位一步出结果。增速比较题先扫一眼有没有明显量级差，分子小分母大者直接排除。隔年增长率常设计"两率相加"和"再加乘积"两个版本，若 r₁r₂ < 1% 且选项差 >1 个百分点可忽略。
高频陷阱
  • 分母用错基期：用现期 A 做分母。永远除以较早那个。
  • 下降率写成正数：算出 0.88 写成"增长 12%"，实为"下降 12%"。
  • 隔年方向倒反：把"2025 较 2023"当成"2023 较 2025"。
  • 比较时不看负号：−5% 与 +3%，增速是 +3% 大；但降幅是 5% 更大。
  • 量级：X 与 B 单位不同（一个万元一个亿）未换算 → 差 10 的幂次。
示例演示
2025 年某市社零总额 7560 亿元，2024 年 6800 亿元。问 2025 年同比增速约为？
A. 10.2%　B. 11.2%　C. 12.4%　D. 13.6%
① X = 7560 − 6800 = 760　② 760/6800 = 76/680 = 0.1118 = 11.18%　③ 回代 6800×1.112 = 7561.6 ≈ 7560 ✓　答案 = B
隔年延伸：若 2024 较 2023 增长 8% → 2025 较 2023：R隔 = 11.18% + 8% + 0.89% ≈ 20.1%。验证 6800/1.08 = 6296，7560/6296 = 1.2008 ✓

5年均增长率 · 混合增长率 · 拉动与贡献率

识别标志
年均："年均增长""平均每年增长 XX%""2018—2023 年间年平均增速""十三五期间"
混合：两个部分 + 一个整体，已知各部分增速问整体增速（典型：进出口、城乡收入、一二三产、男女、上下半年）
拉动/贡献："拉动……增长 X 个百分点""对整体增长的贡献率为"
思考路径 年均增长率：① 确定 n = 末期年份 − 初期年份（年份差）；② 求倍数 A末/A初；③ 代入选项开方验算——把选项最中间的值代入 (1+r)ⁿ，看是否接近目标倍数。比较型题 n 相同时只比 末期/初期 即可。
混合增长率（十字交叉，权重是基期量）：① 确认"整体 = 部分₁ + 部分₂"；② 先定界：混合增速必介于 min(r₁,r₂) 与 max(r₁,r₂) 之间 → 直接排除区间外选项；③ 再定偏向：偏向基期量较大的一方；④ 精算用 (R混−r₂)/(r₁−R混) = B₁/B₂。
拉动/贡献率：拉动 = 部分X / 整体B（除整体基期）；贡献率 = 部分X / 整体X；关系式 拉动 = 贡献率 × 整体R。
判定标准 · 公式与 n 值速判
类型公式速判
年均增长率(1+R年)ⁿ = A末/A初代入选项开方验证
年均增长量(A末 − A初)/n直接减后除
混合增长率R混 ∈ (min r, max r)先定区间再定偏向
十字交叉B₁/B₂ = (R混−r₂)/(r₁−R混)权重必须是基期量
拉动增长率部分X / 整体B单位：百分点
贡献率部分X / 整体X单位：%
n 值速判：2018—2023 年 → 5；"十三五"（2016—2020）→ 5；"近 5 年" → 5；2020 年较 2015 年 → 5。口诀：n = 年份差 = 大减小。
选项处理年均增长率优先代入选项中值，比大小后决定往大调还是往小调。混合增长率可跳过选项直接定区间：若只有一项落在 (min,max) 内，一秒出答案；有两项落在区间内才用基期量之比定偏向。
高频陷阱
  • n 多算一年：2018—2023 的 n = 5 不是 6。
  • 年均增速 ≠ 增速之和÷n：要开方。
  • 混合定错参照：忘了确认"整体 = 部分之和"。
  • 权重用现期而非基期：会系统偏向量小一侧，差 0.3—1 个百分点，正好踩进陷阱选项。
  • 量级：拉动增长率单位是百分点，贡献率才是 %，两者混用会差 100 倍。
示例演示
2025 年某市出口 8600 亿元（+12%），进口 5400 亿元（+4%）。问进出口总额增速约为？
A. 6.5%　B. 7.4%　C. 8.8%　D. 9.6%
① 定区间：(4%, 12%)，四项都在，需定偏向
② 定基期权重：出口基期 8600/1.12 ≈ 7679；进口基期 5400/1.04 ≈ 5192 → 出口基期更大，偏向 12%
③ 精算：整体增量 = 8600×0.12/1.12 + 5400×0.04/1.04 = 921.4 + 207.7 = 1129.1；整体基期 = 12871；R混 = 1129.1/12871 = 8.77%
④ 校验：8.77% 在区间内且偏向 12% 一侧（中点 8% < 8.77%）✓　答案 = C
年均延伸：若 2019 年 8000 亿、2024 年 12600 亿，n = 5，倍数 1.575；代入 9.5%：1.095⁵ ≈ 1.574 → 年均约 9.5%。

6增长量（一般增长量 · 比较 · 年均 · 倍数）

识别标志"增加了多少""净增""同比增加 X 亿元/万吨""增量"；正确答案是带单位的绝对数，不是百分数。比较问法："增长最多的是""增量超过 X 的有几个"。
思考路径
  1. 看给了什么：给 A + R → 415 份数法（先除后乘）；给 B + R → X = B×R 直接乘；给 A + B → X = A − B。
  2. 增长量比较三步：① 先用"大大则大"秒定；② 若一者 A 大 R 小，用 X = A×R/(1+R)——R 接近看 A，A 接近看 R；③ 不要全算，只算疑似最大的两项。
  3. 年均增长量：X̄ = (A末 − A初)/n，n 同样为年份差。
  4. 增长量倍数：各自求 X 再相除，别直接用现期比。
  5. 算完自检：A − X 应等于基期；X 一般不大于 A 的一半（除非增速 >50%）。
判定标准 · "大大则大"判定表
条件结论
A₁ > A₂ 且 R₁ > R₂X₁ > X₂（不需计算）
A₁ > A₂ 且 R₁ = R₂X₁ > X₂
A₁ = A₂ 且 R₁ > R₂X₁ > X₂
A₁ > A₂ 但 R₁ < R₂必须计算，比较 A·R/(1+R)
核心公式：X = A×R/(1+R)　　X̄ = (A末 − A初)/n
选项处理选项差距大 → 415 每份可截 2 位；差距小 → 保留 3 位。比较/排序题先把四项的 A 与 R 抄成两列，用"大大则大"打叉淘汰，一般能淘汰一半。带"约"字可放胆估算；带"超过/不足 X"用定界估算（只需判断是否越过门槛）。
高频陷阱
  • 用 A×R 直接当增长量：忘了除以 (1+R)，结果偏大，而偏大的量正好是常见陷阱选项。
  • 误用"大大则大"：两项都不严格偏优时用了此法，选反。
  • 年均增长量的 n 数错：同年均增长率。
  • 把增长率当增长量：题干"提高了 XX%"选了带单位的答案。
  • 量级：415 法把 A/(100+R) 写成 A/100，或份数小数点移错 → 10 倍偏差。每份算完必须回乘 每份×(100+R) ≈ A 才算过关。
示例演示
2025 年 H 省 GDP 48810 亿元，同比增长 4.6%。问同比增长约多少亿元？
A. 1950　B. 2150　C. 2240　D. 2440
① 415 份数法：现期 : 增量 = 104.6 : 4.6
② 每份 = 48810/104.6 ≈ 48810/105 ≈ 465（选项第二位不同，截 3 位安全）
③ 增量 = 465 × 4.6 ≈ 2139；精算 48810×0.046/1.046 = 2245.3/1.046 ≈ 2147
④ 量级：2147 约为现期的 4.4%，与 4.6% 一致 ✓　答案 = B
陷阱对照：若直接算 48810 × 4.6% = 2245 → 正好对应选项 C，这是命题人准备的"没除以 1+R"陷阱。

7比重（现期 · 基期 · 两期比重差 · 趋势）

识别标志"占……的比重""占比""其中……所占比例""……率"（城镇化率、利润率、恩格尔系数）。必有部分—整体关系。两期比重："比上年上升/下降了 X 个百分点"。
思考路径
  1. 先认整体：带"全""总""该类合计"的那个量。比重 ≤ 100%（"完成率"可 >100%，但那叫率不叫比重）。
  2. 现期比重：W₁ = 部分A / 整体A，截位直除。
  3. 基期比重：W₀ = W₁ ×(1+R整体)/(1+R部分)。记忆：整体率在分子上。
  4. 比重趋势（定性，不算）：R部分 > R整体 → 上升；< → 下降；= → 不变。
  5. 两期比重差：ΔW = W₁ ×(R部分 − R整体)/(1+R部分)，单位百分点。
  6. 速算：先算 W₁（一个除法），再乘率差（一个乘法），两步出结果，绝不套原始分式。
判定标准 · 公式清单
求什么公式
现期比重W₁ = 部分/整体
基期比重W₀ = W₁×(1+R整体)/(1+R部分)
两期比重差ΔW = W₁×(R部分 − R整体)/(1+R部分)（百分点）
比重趋势比较 R部分 与 R整体
比重差上界|ΔW| < |R部分 − R整体|，也 < W₁　← 秒排除用
选项处理趋势题先看 A、D（上升/下降各一），用定性判据砍掉一半。定量阶段看剩余两项差距：若一为 0.4、一为 4，只需估 W₁×率差 的数量级（30% × 1.4% ≈ 0.42 个百分点）即可秒出。常设"忘记乘 W₁"的陷阱选项。
高频陷阱
  • 基期比重公式写反：(1+R部分)/(1+R整体) 是错的。分子永远是整体的率。
  • 比重差写成百分比：比重差 = 百分点，不是 %。
  • 部分/整体张冠李戴：把"私营占规上工业"倒过来算。
  • 忽略 (1+R部分)：R=25% 时误差达 25%。
  • 量级：32% × 1.4% 算成 44.8% —— 正确是 0.32×0.014 = 0.00448 = 0.448 个百分点。每次乘百分数前先把 % 写成小数。
示例演示
2025 年全国规上工业企业营收 159.4 万亿元（+1.1%），其中私营企业 51.2 万亿元（+2.5%）。问私营占比比上年：
A. 上升约 0.4 个百分点　B. 下降约 0.4 个百分点　C. 上升约 4 个百分点　D. 下降约 4 个百分点
① 定性：R部分 2.5% > R整体 1.1% → 上升 → 排除 B、D
② W₁ = 51.2/159.4 ≈ 0.321 = 32.1%；率差 = 1.4 个百分点
③ ΔW = 32.1% × 1.4%/(1+2.5%) = 0.321 × 0.014/1.025 = 0.00438 = 0.44 个百分点
④ 定界：0.44 < 1.4 ✓ 且 < 32.1% ✓　答案 = A

8平均数（现期 · 基期 · 增长率 · 变化量）

识别标志"平均""每""人均""单位面积产量""月均""场均""单产""客单价""亩产"。本质是"比重"的变形，但分母是数量（人数、面积、场次、月数）。变形问法："比上年平均每 X 增加/减少了多少"（变化量）、"同比增长百分之几"（增长率）。
思考路径
  1. 先定谁是总量谁是份数：分子 = 被分的量（产值、收入、产量），分母 = 分的数量（人数、面积、月数）。
  2. 现期平均：M₁ = 总量/份数，注意单位合成（亿元/万人 = 万元/人）。
  3. 基期平均：M₀ = M₁ ×(1+R份数)/(1+R总量) —— 注意分子率是份数的率，与比重公式恰好互补。
  4. 平均数增长率：RM = (R总量 − R份数)/(1+R份数)。
  5. 定性：R总量 > R份数 → 平均数上升。
  6. 变化量：ΔM = M₁ − M₀（直接用减法最稳），或 M₀ × RM。
判定标准 · 极易混的对照表（务必对照背）
基期公式变化公式单位
比重W₀ = W₁×(1+R整体)/(1+R部分)ΔW = W₁×(R部分−R整体)/(1+R部分)百分点
平均数M₀ = M₁×(1+R份数)/(1+R总量)RM = (R总量−R份数)/(1+R份数)%
记忆法：比重"整体率在分子"，平均数"份数率在分母"；比重差减法是"部分−整体"，平均数增长率是"总量−份数"。
选项处理求 RM 时选项常被设计成"总量率 − 份数率"的原值（忘记除以 1+R份数）——若 R份数 <5%，两者接近，需看选项精度。求 ΔM 时选项是带单位数值，别把增长率当答案。定界：|RM| < |R总量 − R份数|（当 R份数 >0）。
高频陷阱
  • 分子分母颠倒：写成"人数/收入"，答案成原值倒数，恰好常是某个选项。
  • 公式分子分母写反：(R份数−R总量)/(1+R总量) 是错的。
  • 单位未换算：亿元/万人 → 万元/人，答"8.9"（错）vs"8.9 万元/人"（对）。
  • 把"月均"当成"全年"：份数是 12。
  • 量级：份数用"万人"总量用"元" → 结果差 10⁴ 倍。先写"答案单位 = 总量单位 ÷ 份数单位"再动笔。
示例演示
2025 年某市接待游客 8600 万人次（+12%），旅游收入 1032 亿元（+20%）。问人均旅游消费同比增长约？
A. 6.4%　B. 7.1%　C. 8.0%　D. 20%
① 人均 = 收入/人次 → 平均数增长率
② RM = (20% − 12%)/(1+12%) = 8%/1.12 = 7.14%
③ 定界：7.14% < 8% ✓　答案 = B
延伸 · 变化量：M₁ = 1032亿/8600万 = 1200 元；M₀ = 1200×1.12/1.2 = 1120 元；ΔM = 80 元。交叉校验 1120 × 7.14% = 80 ✓

9倍数与比值（现期 · 基期 · 翻番 · 比较）

识别标志"是……的多少倍""相当于""多几倍""倍数为""翻了几番""与之比是多少"。"是几倍" = A/B，"多几倍" = A/B − 1，两者差 1 是命题高频点。时间倒退为去年 → 基期倍数。
思考路径
  1. 分清比较双方："A 是 B 的几倍" → A/B。
  2. "多几倍" → 算出比值后减 1。
  3. 基期倍数：K₀ = K₁ ×(1+R_B)/(1+R_A)（与基期比重同构：A 是"部分位"，B 是"整体位"）。
  4. 翻番：翻 n 番 = 2ⁿ 倍。翻一番 = 2 倍（+100%），翻两番 = 4 倍（+300%）。
  5. 倍数与增长的关系：A/B = 1 + R（跨一期时）。"增长 60%" = "是基期的 1.6 倍" = "多 0.6 倍"。
判定标准 · 公式清单 现期倍数 K₁ = A/B 多几倍 K₁ − 1 基期倍数 K₀ = K₁×(1+R_B)/(1+R_A) 翻 n 番 = 2ⁿ 倍 72 法则：翻番年数 ≈ 72/R百分数
选项处理选项常并列 2.4 和 1.4 → 先判断题干是"是几倍"还是"多几倍"。基期倍数用定性先排一半：分子增速 > 分母增速 → 基期倍数 < 现期倍数（与比重逻辑完全一致）。回乘 B × 所选倍数 ≈ A。
高频陷阱
  • "是几倍"与"多几倍"混：正确答案差 1。读题时在"多"字下划线。
  • 基期倍数方向搞反。
  • 翻番与翻倍混淆：翻两番 = 4 倍，不是 2 倍也不是 3 倍。
  • A 与 B 位置颠倒：得到倒数。
  • 量级：一方"万人"一方"亿人"未统一 → 差 10⁴ 倍。
示例演示
2025 年甲公司营收 3600 万元（+20%），乙公司 1200 万元（+10%）。问 2024 年甲公司营收约是乙公司的多少倍？
A. 2.45　B. 2.75　C. 2.95　D. 3.15
① K₁ = 3600/1200 = 3　② K₀ = 3 × 1.10/1.20 = 3 × 0.9167 = 2.75
③ 定性校验：甲增速 20% > 乙 10%，甲相对乙在变大 → 基期倍数应 < 现期 3 ✓
④ 精算校验：甲基期 3000，乙基期 1090.9，3000/1090.9 = 2.75 ✓　答案 = B
翻番延伸：甲按 20% 增速，72/20 = 3.6 → 取 4 年（1.2⁴ = 2.07 > 2 ✓）

10简单计算与查找（找数 · 排序 · 计数 · 顺逆差）

识别标志"超过 X 的有几个""从大到小排序正确的是""最高/最低的是""顺差/逆差为多少""差额是多少""合计为多少"。看似不用算，但极易因漏项、错单位、错时间丢分。
思考路径
  1. 先明确三项：统计范围（哪些行参与）、时间（哪一期/哪一列）、单位。
  2. 直接找数：定位 → 比对，注意"同年不同列"（本期值 vs 同比增速列）。
  3. 排序题：不必全排，只比较相邻两项的相对关系，用"首两项 + 末两项"验证即可拆掉 2 个选项。
  4. 计数题：逐项打勾 ✓/✗，把"边界值"（刚好等于门槛的）单独标 ⚠。
  5. 差额类：明确谁减谁。顺差 = 出口 − 进口。
  6. 合计类：先换成同一单位再相加，警惕"其中"项之外的隐藏项。
  7. 别忘了看材料"注"。
判定标准 · 门槛词对照
表述含义
超过>
不足 / 低于<
不低于 / 达到≥
顺差出口 − 进口（>0 顺差，<0 逆差）
增速差r₁ − r₂，单位百分点
选项处理排序题先看四项首两位，只比较摇摆的两项。计数题务必把等于门槛的数值标 ⚠（"超过"≠"达到"）。差额类选项常含"反号"和"减反"两个陷阱值（如 ±4400 都出现），先定方向再选。
高频陷阱
  • "超过"与"不低于"：> vs ≥，一个数字之差即丢分。
  • 排序单位不统一：同一列中某行是"万元"、其他是"亿元"。
  • 漏看"其中"项。
  • 顺逆差方向反：记牢"顺差 = 出口多"。
  • 量级：4200万吨 + 3.2亿吨 未统一单位 → 差 10 倍。
示例演示
六个口岸进出口（亿元）：甲 6800，乙 5230，丙 4980，丁 3750，戊 5020，己 2150。超过 5000 亿元的有几个？
门槛"超过"→ > 5000（等于 5000 不算）。甲 6800 ✓；乙 5230 ✓；丙 4980 ✗（最接近，易误判）；丁 3750 ✗；戊 5020 ✓；己 2150 ✗ → 答案 = 3 个
顺逆差延伸：出口 18600、进口 14200 → 顺差 18600 − 14200 = 4400 亿元；算成 −4400 说明方向搞反。

11综合分析题（"下列说法正确的是/错误的是"）

识别标志每篇材料最后一题："能够从上述资料中推出的是""以下说法正确的是/错误的是""正确的有几个"。四个选项分别指向不同考点。
思考路径 · 核心是验证优先级
  1. 第一步（10 秒）：确定是找"唯一正确"还是"唯一错误"，这决定收手条件。
  2. 第二步（20 秒）：浏览四选项，标记计算量等级：0 = 直接读材料、1 = 一步比较、2 = 一步除法、3 = 两步以上或跨段。
  3. 第三步：按下表顺序验证
顺序先验证次优先再其次最后
验什么① 能直接读材料/看符号判的
② 含"逐年""均""所有""一定"等绝对词（多半错，先砍）
③ 只看大小/方向不需算的		④ 一步比较类，用放缩定界⑤ 一步除法类（比重、倍数、平均数）⑥ 跨段/多步/求基期再求比重
限时<20 秒<30 秒<40 秒<60 秒
  1. 收手规则：问"能推出/正确的" → 验出第一个对的立即选，其余不验；问"不能推出/错误的" → 验出第一个错的立即选；问"正确的有几个" → 必须四项全判，优先做 0/1 级。
  2. 应急：验完 3 个仍无结论 → 第 4 个即答案，不再计算。
判定标准 · 表述与含义 超过 = >不足 = <不低于/达到 = ≥约/左右 = 允许 ±5%逐年递增/均 = 有一反例即错首次超过 = 需逐年查证月均 = ÷12 或实际月数
选项处理用放缩法替代精算：判断"超过 8%"只需算是否 >8%，不需算真实值。每个选项设 40 秒硬上限，超时立即标记往下走。若两个选项互相矛盾（一说升、一说降），答案多半在两者之一，优先验这两个。定位失败（找不到数据）→ 该项大概率"不能推出"。
高频陷阱
  • 时间与口径不符：选项说"2024 年"但材料只有"2025 年 1—5 月"。
  • "高于上年"缺数据：材料没给上年增速 → 无法判断，属"不能推出"。
  • 绝对化词："逐年""均""全部" → 优先当错误项验证。
  • 单位/范围偷换：把"占工业的比重"说成"占 GDP 的比重"。
  • 量级：四选项常有一个"10 倍偏差值"藏在需计算的选项里，一旦估算落在两个相差 10 倍的数值附近，用回乘确认。
示例演示
2025 年某市 GDP 8600 亿元（+7.5%）。一产 430 亿（+3.2%），二产 3698 亿（+6.8%），三产 4472 亿（+8.6%）。能推出的是：
A. 一产占比超过 5%　B. 二产同比增长超过 250 亿元　C. 2024 年 GDP 低于 8000 亿元　D. 三产占比比上年上升
定级：A = 2 级，B = 3 级，C = 3 级，D = 1 级（定性比较率） → 先验 D
验 D：三产增速 8.6% > GDP 增速 7.5% → 比重上升 ✓ → 问"能推出" → 立即选 D
（核对）A：430/8600 = 5.0%，恰好等于 5%，"超过 5%" ✗；B：3698×6.8%/1.068 ≈ 235 < 250 ✗；C：8600/1.075 = 8000，恰好等于，"低于" ✗
三项全错、D 正确，逻辑自洽。　答案 = D（考场上验完 D 即可收手）

C. 三大速算与量级校验（3 份）

12截位直除（含"看选项差距定截几位"判定表）

识别标志凡是出现一步除法的场合：求比重、倍数、平均数、基期、增长率。只要列式是"分子 ÷ 分母"就该用。
思考路径
  1. 先写列式，别急着算。
  2. 统一单位/量级：分子分母同乘除 10ⁿ 化为易读形式。
  3. 看选项定截位（关键第一步，必须先看完选项再截）。
  4. 截分母：四舍五入到指定有效位数；对被舍去部分记 (+)/(−) 以便判断结果偏向。
  5. 分子尽量不截（分子小尤其不截）。
  6. 估商首位 → 补齐小数/百分位 → 对齐选项。
  7. 回乘校验：商 × 分母 ≈ 分子。
判定标准 · 截位档位表（核心）
选项特征截位档示例
首位数字不同分母截 2 位13% / 24% / 35% / 46%
首位相同，第二位不同分母截 3 位12.1% / 12.5% / 12.8% / 13.2%
前两位相同，第三位不同分母截 4 位 或差分法12.11 / 12.15 / 12.18
只需定界（"超过 X 吗"）放缩法：往有利于结论的方向截一端—
分母首位为 1 或 2多截一位（1 开头误差最敏感）19xxx → 至少截 3 位
分母接近整十/整百/1凑整：998→1000，1.03→1—
口诀：选项差距看首位，不同截二同截三，1 开头再多截一位。
选项处理若截 2 位得到的商落在两选项中间 → 立即补截一位重算，不要"取最靠近的"。有"最接近"字眼 → 允许粗估；要求精确值 → 3 位保底。算完把结果乘以分母，量级和首位都对才算完成（3 秒，能救很多分）。
高频陷阱
  • 分子分母同时粗截导致误差叠加：只截分母，分子保留。
  • 截错方向：四舍五入时看错后一位。
  • 忘记负增长：/(1−8%) 变成 /(1+8%)。
  • 分母是小数时生硬截位：先同 ×1000 化为整数（8872/0.771 = 8872000/771）。
  • 量级：4287/32456 写成 43/325 后忘了 ×10⁻²。每步以"首数量级"自检：4287 约为 32456 的 1/8 ≈ 12.5%，是"十几 percent"，不是 1.3% 也不是 130%。
示例演示
4287 ÷ 32456 = ?　A. 13.2%　B. 15.6%　C. 18.4%　D. 21.1%
① 选项首位均不同 → 截 2 位　② 分母 32456 → 32000
③ 商 4287/32000 = 4287/32 ×10⁻³ = 133.97×10⁻³ = 13.4%
④ 精一档：分母实际比 32000 大 1.4% → 商应小 0.19 个百分点 → 13.2%
⑤ 回乘 32456 × 13.2% = 4284 ≈ 4287 ✓　答案 = A

13415 份数法（增长量专用）

识别标志给了现期量 A 与增长率 R，求增长量 X（或求基期 B 再变形）。看到"今年 XX，同比增长 Y%，问增加了多少" → 直接调用。
思考路径
  1. 写下 R。
  2. 写份数比：基期 : 增长量 : 现期 = 100 : R : (100+R)。下降时 100 : |R| : (100−|R|)。
  3. 能化简就化简：110:10 → 11:1、125:25 → 5:1、133:33 → 4:1。
  4. 每份 = A ÷ (100+R)（除法用截位直除，看选项截位）。
  5. X = 每份 × R；求基期则 B = 每份 × 100 或 B = A − X。
  6. 校验：每份 ×(100+R) ≈ A。
判定标准 · 常见 R 的份数速查表（背熟，省一半时间）
R现期 : 增量化简增量 = 现期 ÷
5%105 : 521 : 121
10%110 : 1011 : 111

通用结论：R = 1/n 时增量 = 现期 ÷(n+1)；下降 1/n 时减少量 = 现期 ÷(n−1)。
例：R = 12.5% = 1/8 → 增量 = 现期 ÷ 9；R = −12.5% → 减量 = 现期 ÷ 7。
选项处理选项差距大 → 每份截 2 位；差距小 → 保留 3 位。每份算完立刻回乘 每份×(100+R) ≈ A，不等就重算。R 不是表中整齐值时，可先按最接近的整齐值估出量级，再微调。
高频陷阱
  • 忘记除以 (1+R)：直接用 A×R，结果偏大，正好是陷阱选项。
  • 下降时用错分母：现期对应 (100−|R|) 份，不是 (100+|R|)。
  • 份数与现期对应错：现期 = 100+R 份，不是 100 份。
  • 量级：每份算成 8.2 而实际是 82 → 增量差 10 倍。用"估算锚点"定每首位：如 5430÷7，想 7×700=4900、7×800=5600 → 商在 700~800。
示例演示
某商品销售额 5430 万元，同比下降 12.5%。问同比减少约多少万元？
① R = −12.5% = −1/8 → 下降 1/8 → 减少量 = 现期 ÷(8−1) = 5430 ÷ 7
② 估算锚点：7×700 = 4900、7×800 = 5600 → 商在 700~800
③ 精算 5430/7 = 775.7
④ 回乘检验：775.7 × 7 = 5430 ✓　答案 ≈ 776 万元
若算出 77，立即回乘 77×7 = 539 ≠ 5430 → 差 10 倍，必错。这就是"回乘检验"的价值。

14估算与量级校验（针对"商差 10 倍"的专项纠错）

识别标志任何除法算完之后立即执行，不需要题目触发。如果你曾经出现过"答案和正确值差 10 倍"的错误，这一篇必须每次都用。
思考路径 · 三道防线
  1. 防线一 · 动手前先估量级：列完式先问自己"答案大概是多少、几位数"。如 8680 ÷ 1.084 → 分母略大于 1 → 商略小于 8680，是四位数八千多。若算出 37.7，量级明显不对，根本不该写下去。
  2. 防线二 · 估算锚点定首位：用整十整百夹逼。5430÷7 → 7×700=4900、7×800=5600 → 商在 700~800，首位是 7。
  3. 防线三 · 算完必回乘：商 × 除数 = 被除数。77×7 = 539，与 5430 差 10 倍 → 立刻发现错误。
判定标准 · 常见量级锚点
列式量级判断答案应是
A ÷ (1+R)，R > 0分母 >1小于 A，与 A 同量级
A ÷ (1−|R|)，下降分母 <1大于 A，与 A 同量级
A × R（R 为百分数）乘的是小数约 A 的百分之几，比 A 小两个数量级
X = A×R/(1+R)小于 A×R约为 A 的 R 成（略小）
比重 W部分 / 整体小数形式（0.32）或百分数（32%）
平均数（亿元/万人）1亿 = 10⁴万万元/人，数值不变
选项处理如果算出的数在四个选项里都找不到：先怀疑量级（10 倍），回乘检验一次；回乘通过再怀疑单位（万元/亿元、%/百分点）。绝不因为"算出来没有"就去改方法或硬凑选项。
高频陷阱（你的三类典型错误复盘）
  • 8680，+8.4%，求基期：你答 37.7，正确 ≈ 8000 左右。8680/1.084 商应为八千多，你算成了 8 点多 → 漏了两位。
  • 7280，−6.4%，求基期：你答 721，正确 ≈ 7778。7280/0.936，分母 <1 → 结果应大于 7280。
  • 5430，−12.5%，求减少量：你答 77，正确 ≈ 776。5430÷7，回乘 77×7 = 539 ≠ 5430 立刻现形。
共同根因：没有在动笔前先估量级，也没有算完回乘。对策：把"估量级 → 算 → 回乘"练成三步一体的肌肉记忆。
示例演示 · 五道纯量级估算小题（只估不精算，练手指感）
① 8680 ÷ 1.084 ≈ ？　→ 想 1.084×8000 = 8672 → ≈ 8000（八千多）
② 7280 ÷ 0.936 ≈ ？　→ 分母 <1，结果 >7280；0.936×7800 = 7300 → ≈ 7780
③ 5430 ÷ 7 ≈ ？　→ 7×700=4900、7×800=5600 → ≈ 776

⑤ 159.4万亿 ÷ 51.2万亿 ≈ ？　→ 同单位可直接比，51.2×3 = 153.6、51.2×3.2 = 163.8 → ≈ 3.1 倍
