公文写作的核心逻辑：申论看"内容质量"，公文看"格式 + 内容 + 语气"三件套。格式分是白给的——标题、称谓、正文、落款四项齐全就有分；内容分在材料里，把材料的关键词抄准抄全；语气分靠身份判断，你是"谁"决定了你用什么口吻说话。

第一组 · 公文写作总论

先掌握"骨架"，再往里面填"肉"。所有文种都共用这一套格式规范。

1公文通用格式与规范（必先掌握）

识别标志题目出现"请起草/拟写/撰写一份××"、"请以××名义写一份××"、"根据给定材料写一份××"。凡是要写"成文"的题，先套这一套骨架。
思考路径 · 四步搭骨架
  1. 先定文种：题目说"通知"就是通知，说"倡议书"就是倡议书。不要自作聪明换文种。
  2. 再定身份与受文对象：我是谁（发文机关）？写给谁（主送机关）？这两个确定了，语气就定了。
  3. 搭四段正文：开头（缘由/背景/目的）→ 主体（事项/措施/要求，分条列）→ 结尾（号召/要求/请示语）→ 落款（机关名 + 日期）。
  4. 最后填内容：从材料里找要点，逐条填进主体段。
判定标准 · 格式要素齐全表（照着检查）
要素写法是否必写
标题发文机关 + 事由 + 文种（如"××市××局关于开展××工作的通知"）；题目未给机关名可省略为"关于开展××工作的通知"必写
主送机关（称谓）顶格写，后加冒号。如"各有关单位：""各位居民朋友："通知/通报/报告/请示/函 必写；倡议书/宣传稿 必写
正文开头写缘由、目的、依据。常用句式见下方句式库必写
正文主体分条列点："一、……。二、……。三、……。"或"1. …… 2. ……"必写
正文结尾不同文种不同结尾语（见各文种框架）绝大多数必写
落款机关右下角。发文机关全称或规范化简称正式公文必写；讲话稿/倡议书视情况
成文日期右下角，机关名下方。用"×年×月×日"占位，不要编具体日期正式公文必写
格式占位惯例：题目没给具体单位名、日期时，直接写"××市××局""×年×月×日"，不要编造真实名称，阅卷老师看的就是你会不会占位。
要点处理 · 常用句式模板库
段落可套用句式
开头·目的式为深入贯彻落实××精神，进一步加强××工作，切实解决××问题，现就有关事项通知如下：
开头·背景式近期，××问题日益凸显，给群众生产生活带来不便。为切实回应群众关切，现提出如下倡议：
开头·依据式根据《××××》有关要求，结合我单位实际，现将××情况报告如下：
主体·分条一、加强××。具体做法是……　二、完善××。重点做好……　三、落实××。明确××责任
结尾·要求式请各单位高度重视，认真组织实施，确保各项措施落到实处。
结尾·号召式让我们携起手来，从自身做起、从小事做起，共同为××贡献力量！
结尾·请示式以上请示，妥否，请批示。（请示专用）
结尾·函复式特此函复。（答复函专用）　特此函达。（商洽函专用）
结尾·报告式特此报告。
高频陷阱 · 公文八大扣分项
  • 漏格式：忘写标题 / 忘写落款日期 → 直接扣格式分（最冤的失分）。
  • 身份错位：以个人身份写公文，或越权承诺（基层单位承诺上级才能定的事）。
  • 称谓不符：对内用"贵单位"，对外用"你单位"，搞反。
  • 语体不对：公文写成散文、抒情体；或口语化太重。
  • 不分条：正文写成一整段，阅卷老师找不到采分点。
  • 要点头重脚轻：开头铺垫写了 200 字，主体措施只有 50 字。
  • 编造具体数字/人名/地名：没有依据的细节不要写。
  • 文种混用：把"请示"写成"报告"（请示要批复、报告不要批复，两者不能混）。
示例演示 · 通用骨架速记

记住这张骨架，所有文种都是往里填内容。

第二组 · 法定公文（5 份）

通知、通报、报告、请示、函 —— 这五个是公文写作的核心，格式最严、语气最正式。

法定公文

2通知（布置工作 / 传达事项 / 印发文件）

识别标志"请拟写一份关于开展××活动的通知"、"就××工作作出部署，请写一份通知"、"请以××局名义印发××的通知"。关键提示词：部署、开展、组织、印发、传达。
思考路径
  1. 定通知类型：布置工作型（最常见）/ 传达事项型 / 印发型 / 会议通知型。
  2. 定发文机关与受文对象：谁发的？发给谁？（通常是"各有关单位""各部门""各县（区）××局"）
  3. 从材料里找三样东西：为什么做（背景/依据）、做什么（任务事项）、怎么做（具体要求）。
  4. 主体部分把"做什么"分条列，每条写成"动宾短语 + 具体展开"。
  5. 结尾提出执行要求（提高认识、加强领导、落实责任、及时反馈）。
判定标准 · 格式模板（可照抄）
关于××××工作的通知 各有关单位： 开头段：【缘由 + 目的】为深入贯彻落实××精神／针对近期××问题，进一步做好××工作，现将有关事项通知如下： 一、【任务一】××××。要求……（写清做什么、谁负责、什么标准） 二、【任务二】××××。要求…… 三、【任务三】××××。要求…… （一般 3—5 条，具体条款数看材料） 结尾段：【执行要求】请各单位高度重视，明确责任分工，抓好贯彻落实，于×月×日前将工作情况报送××部门。 　　　　　　　　　　　　　　××市××局 　　　　　　　　　　　　　　×年×月×日
要点处理 语体：正式、命令式但不生硬 人称：第三人称，不用"我" 主体占全文 60—70% 每条 30—60 字 总量 400—600 字 主体写作公式：动词（加强/完善/规范/落实/开展/建立）+ 对象（××工作）+ 具体措施（怎么做）+ 标准/时限。
高频陷阱
  • 漏写主送机关（"各有关单位："这行最容易被忘）。
  • 只写"要重视""要加强"，没有具体动作 —— 通知最忌空话，每条必须有可执行的动作。
  • 任务条目数量不对：材料里给了 4 项工作，只写 2 项 → 漏采分点。
  • 把通知写成倡议书（语气太软，通知是要求执行、不是呼吁参与）。
  • 结尾忘记提"反馈时限"。
示例演示
【题目】某市近期电信网络诈骗案件多发，市民财产损失较大。请以市××局名义，写一份关于开展反诈宣传工作的通知。不超过 500 字。
关于开展防范电信网络诈骗宣传工作的通知 各有关单位： 近期，我市电信网络诈骗案件多发，群众财产损失较大，社会反映强烈。为切实提高群众防骗意识，有效遏制案件高发态势，现就开展反诈宣传工作通知如下： 一、广泛开展宣传发动。各单位要组织工作人员深入社区、学校、企业，通过发放宣传手册、张贴海报、播放短视频等方式，向群众普及常见诈骗手法和识别技巧。 二、突出重点人群防范。针对老年人、学生等易受骗群体，开展"面对面"讲解，帮助其安装注册国家反诈中心APP，讲解典型案例。 三、畅通举报反馈渠道。公布本单位反诈咨询电话，安排专人值守，接到群众咨询或线索后及时核实处理并上报。 四、压实工作责任。各单位要明确一名负责人牵头，建立工作台账，确保宣传活动覆盖到位，并于××月××日前将工作开展情况报送市××局。 请各单位高度重视，确保各项措施落到实处。 　　　　　　　　　　　　　　××市××局 　　　　　　　　　　　　　　×年×月×日

3通报（表彰先进 / 批评错误 / 传达情况）

识别标志"请就××事件写一份通报"、"对××予以表彰，请拟写通报"、"针对××违规问题予以通报"。关键提示词：表彰、批评、通报、予以、警示。
思考路径
  1. 先判类型（决定全文基调）：表彰性（褒扬+号召学习）/ 批评性（指出问题+提出整改）/ 情况通报（陈述事实+提出要求）。
  2. 写清"三要素"：什么事（事实经过）、怎么看（评价定性）、怎么办（要求或号召）。
  3. 表彰性：重点写事迹 + 意义 + 学习号召。
  4. 批评性：重点写问题事实 + 危害分析 + 处理决定 + 整改要求，注意措辞严肃但不辱骂。
判定标准 · 格式模板
【表彰性通报】 关于表彰××同志的通报 各××： 近期，××同志在××工作中，××××（简述事迹）。其行为…… 为表彰先进、弘扬正气，经研究决定，对××同志予以通报表扬。 希望全体干部职工以××同志为榜样，学习他××××的精神，在今后的工作中…… 　　　　　　　　　　　　　　××单位 　　　　　　　　　　　　　　×年×月×日 【批评性通报】 关于××问题的通报 各××： 近期，经核查发现，××存在××问题（陈述事实）。 上述问题反映出××××（分析原因/危害），性质较为严重，造成了不良影响。 为严肃纪律、汲取教训，现提出如下要求：一、……　二、……　三、各单位要引以为戒，认真开展自查自纠，防止类似问题再次发生。 　　　　　　　　　　　　　　××单位 　　　　　　　　　　　　　　×年×月×日
要点处理 表彰性：褒扬语气，多用"值得学习""充分体现" 批评性：严肃但不情绪化，用"反映出""暴露出""应当" 情况通报：客观陈述，不褒不贬 总量 400—500 字
高频陷阱
  • 类型判断错：材料是批评性质，却用表彰的语气写。
  • 表彰性通报只写事迹不写号召（末尾必须有"希望……学习"）。
  • 批评性通报点名过于具体，或反之过于含糊。按材料给的信息写，不编造。
  • 把通报写成通知：通知重"布置任务"，通报重"褒贬定性"。
  • 漏写"经研究决定"这类程序性表述。
示例演示
【题目】某单位职工李××在上班途中发现一居民楼起火，及时报警并协助疏散居民，避免了重大伤亡。请写一份表彰通报。不超过 400 字。
关于表彰李××同志的通报 各部门： 近日，我单位职工李××在上班途中发现某居民楼发生火情，他第一时间拨打火警电话，并主动逐户敲门提醒，协助疏散居民二十余人，为救援争取了宝贵时间，避免了人员伤亡。 李××同志临危不乱、见义勇为的行为，充分体现了强烈的社会责任感和良好的精神风貌，为单位赢得了荣誉。 为表彰先进、弘扬正气，经研究决定，对李××同志予以通报表扬。 希望全体干部职工以李××同志为榜样，学习他见义勇为、勇于担当的优秀品质，在今后的工作和生活中积极传递正能量，为营造和谐安全的社会环境贡献力量。 　　　　　　　　　　　　　　××单位 　　　　　　　　　　　　　　×年×月×日

4报告（工作报告 / 情况报告 / 答复询问报告）

识别标志"请就××工作情况写一份报告"、"请将××情况向上级报告"、"写一份关于××的自查报告"。关键提示词：汇报、报告、情况说明、上报。
思考路径
  1. 报告是上行文（写给上级），语气要汇报性，不要命令式。
  2. 主体按"基本情况 → 主要做法 → 存在问题 → 下步打算"四段展开（这个结构最万能）。
  3. 若题目只要求"情况报告"，则写"基本情况 + 已采取措施 + 下步安排"。
  4. 报告不要求批复，结尾用"特此报告"，绝不能写"请批示"。
判定标准 · 格式模板
关于××××工作情况的报告 ××××（上级机关）： 根据××要求／按照××部署，我单位高度重视，认真组织开展了××工作。现将有关情况报告如下： 一、基本情况。××××（时间、范围、总体成效，可用材料的核心数据） 二、主要做法。（1）××××；（2）××××；（3）××××。 三、存在问题。一是……；二是……。 四、下步打算。下一步，我单位将××××。 特此报告。 　　　　　　　　　　　　　　××单位 　　　　　　　　　　　　　　×年×月×日
要点处理 语气：汇报、谦逊，用"我单位""现将……报告如下" 主线：做法要分条，最好用"一是……二是……" 数据：能引用材料数据就引用，体现真实性 总量 500—700 字
高频陷阱
  • 报告里写"请批示" —— 报告与请示最大的区别，报告不需要批复。写了直接扣分。
  • 只写成绩不写问题：报告一般要有"存在问题 + 下步打算"，否则显得不客观。
  • 语气太硬：用"必须""务必"这类词去命令上级。
  • 把自己写成上级：报告是向上报，不能写"要求各单位……"。
  • 漏写"特此报告"。
示例演示
【题目】某街道办开展了为期一个月的环境整治专项行动，取得了初步成效但仍有不足。请以街道办名义向区政府写一份情况报告，不超过 600 字。
关于环境整治专项行动情况的报告 ××区人民政府： 按照区政府关于提升人居环境的工作部署，我街道于××月××日至××月××日集中开展了环境整治专项行动。现将有关情况报告如下： 一、基本情况。行动期间，累计清理各类垃圾××吨，整治乱堆乱放点位××处，规范店外经营××家，辖区环境面貌明显改善。 二、主要做法。一是强化组织发动。成立专项工作小组，明确职责分工，实行网格化管理。二是聚焦重点突破。针对背街小巷、老旧小区、集贸市场等重点区域集中攻坚。三是广泛宣传引导。通过张贴公告、上门告知等方式，动员居民和商户主动参与。 三、存在问题。一是部分居民环保意识不强，乱倒乱堆现象仍有反弹；二是长效管护机制不够健全，整治成果巩固难度较大。 四、下步打算。下一步，我街道将健全日常巡查和考核机制，加大宣传力度，引导群众养成良好习惯，持续推进环境整治常态化长效化。 特此报告。 　　　　　　　　　　　　　　××街道办事处 　　　　　　　　　　　　　　×年×月×日

5请示（请求指示 / 请求批准 / 请求解决）

识别标志"因××事项，需向上级请示，请拟写一份请示"、"请就××问题请求上级审批"。关键提示词：请求批准、请求指示、拨付、审批、同意。
思考路径
  1. 请示是上行文，必须"一文一事"——只请求一件事，不要夹带多个诉求。
  2. 结构：请示缘由（为什么）→ 请示事项（求什么）→ 请示语（请批示）。
  3. 缘由要写足：说明困难、必要性、紧迫性，让上级有批复的理由。
  4. 事项要具体：要多少钱、批什么、办什么，写清楚数额或范围。
  5. 结尾必须是"以上请示，妥否，请批示"或"以上请示，请予批准"。
判定标准 · 格式模板
关于××××的请示 ××××（上级机关）： 【缘由】近年来，××××（客观情况）。由于××××（原因分析），现有××已不能满足××需要，影响了××工作正常开展。 【事项】为切实解决上述问题，拟××××（具体请求：申请经费××万元／申请批准××事项／请求指导××工作）。 【说明】我单位已就××进行充分论证／已落实配套资金××，具备实施条件。 以上请示，妥否，请批示。 　　　　　　　　　　　　　　××单位 　　　　　　　　　　　　　　×年×月×日
要点处理 一文一事（最重要） 缘由：占 40%，写足必要性 事项：占 40%，写清具体内容 语气：恳请、恭敬，用"拟""恳请""妥否" 总量 300—450 字（请示宜短）
高频陷阱
  • 一文多事：在一份请示里请示两件以上的事 → 严重错误。

6函（商洽函 / 请求函 / 答复函）

识别标志"××单位拟就××事宜与××单位协商，请写一份函"、"就××咨询/请求××单位协助，写一份函"。关键提示词：商洽、协商、协助、复函、答复。
思考路径
  1. 函是平行文（同级机关之间、或无隶属关系单位之间），语气要平等、客气。
  2. 判类型：商洽函（商量一起做事）/ 请求函（请对方帮忙、咨询）/ 答复函（回复对方）。
  3. 称谓用"贵单位"（客气），不要用"你单位"（略生硬）。
  4. 结构：缘由 → 事项 → 期望回复 → "特此函达"/"特此函复"。
判定标准 · 格式模板
【商洽函 / 请求函】 关于××××的函 ××××（对方单位）： 【缘由】为××××，我单位拟××××。 【事项】现商请贵单位××××（具体请求：协助提供××／共同举办××／给予技术指导）。具体安排建议为……（可给简要方案）。 【期望】如贵单位同意，请于×月×日前与我单位××科联系（联系人：××，电话：××××）。 特此函达，盼予复函。 　　　　　　　　　　　　　　××单位 　　　　　　　　　　　　　　×年×月×日 【答复函】 关于××××的复函 ××××（对方单位）： 贵单位《关于××××的函》收悉。经研究，现答复如下： 一、××××（逐条答复对方请求的事项）。 二、××××。 感谢贵单位对××工作的关注与支持。 特此函复。 　　　　　　　　　　　　　　××单位 　　　　　　　　　　　　　　×年×月×日
要点处理 语气：平等、客气、协商性 称谓："贵单位" 结尾："特此函达"/"特此函复" 答复函要逐条回应对方请求，不可遗漏 总量 300—450 字

  • 语气写成上下级：函是平级，不能命令对方。
  • 答复函漏答：对方问了 3 件事，只答了 2 件。
  • 称谓用错："贵单位"用于对方，"我单位"用于自己。
  • 漏写联系方式（商洽函里常见采分点）。
  • 把函写成通知的格式和语气。

7倡议书（号召参与 / 共同行动）

思考路径
  1. 对象是群众/全体成员，语气要诚恳、有感染力，可以有情感色彩（这是与通知最大的区别）。
  2. 结构：背景缘由（为什么倡议）→ 具体内容（倡议什么，分条）→ 号召（一起行动）。
  3. 倡议内容分条时，用"第一，从我做起……第二，……"或"一、……。二、……"。
  4. 结尾必须有强有力的号召句，这是倡议书的"标配"。
判定标准 · 格式模板
关于××××的倡议书 广大市民朋友们（或：全体干部职工）： 【背景】××××（现状描述，点出问题或契机）。 【意义】××××（这样做有什么好处，唤起认同）。 为此，我们发出如下倡议： 一、××××。××××××（具体做什么，用行动动词）。 二、××××。××××××。 三、××××。××××××。 【号召】市民朋友们，××需要你我共同参与。让我们携起手来，从现在做起、从自身做起，为××××贡献自己的一份力量！ 　　　　　　　　　　　　　　××单位 　　　　　　　　　　　　　　×年×月×日
要点处理 语气：诚恳、有感染力，可用排比与呼告 称谓：面向群众用"广大市民朋友们" 主体：3—4 条，每条要"可做" 结尾：必须有号召句 总量 400—600 字
高频陷阱
  • 语气太硬，写成命令式通知（"必须""严禁"用错场合）。
  • 没有号召结尾 —— 倡议书少了号召，就像人少了魂。
  • 倡议内容太虚："要提高认识"→ 应改为"主动学习垃圾分类知识，按标准分类投放"。
  • 称谓缺失或写成"各位领导"（对象错）。
  • 落款写成"××单位全体职工"（除非题目如此要求，否则用单位或倡议发起方）。

8宣传稿 / 宣讲稿

识别标志"请写一份宣传稿/宣传材料"、"为推广××，撰写一份宣传稿"、"请写一篇宣讲稿向群众介绍××政策"。关键提示词：宣传、推广、介绍、宣讲、普及。
思考路径
  1. 先定受众：面向群众（通俗、接地气）、面向企业（务实、讲政策红利）、面向同行（专业、讲做法）。
  2. 结构：引出话题（为什么值得关注）→ 核心内容（是什么、有什么好处、怎么做）→ 呼吁行动。
  3. 政策宣传类：突出"群众能得到什么"，多用"你""您"拉近距离。
  4. 做法宣传类：突出"我们是怎么做的、效果如何"，可举材料里的例子。
判定标准 · 格式模板
【宣传稿（面向群众）】 ××××，您了解吗？ 【引】开头用一个现象、一句问话或一点背景，把读者的注意力引过来。 【释】××××是什么／为什么要××××。（用通俗的语言解释，少用专业术语） 【利】参与××××，您可以／能够××××。（讲对群众的好处） 【行】具体怎么做：①……②……③……（给出清晰、简单的操作步骤） 【呼】××××，从现在开始！让我们共同××××。 【落款】××单位　×年×月×日（面向内部时写；面向媒体投稿可不写）
要点处理 语言：通俗、生动，可设问、可排比 人称：面向群众多用"您""我们" 重点：讲清"对群众有什么好处" 总量 500—700 字
高频陷阱
  • 写成公文通知，全是"要××""应××"的行政口吻，群众不爱看。
  • 专业术语堆砌，不解释，受众看不懂。
  • 只讲政策不讲好处 → 群众没有参与动力。
  • 漏掉"怎么做" → 宣传稿必须给可操作的指引。
  • 标题平淡无吸引力（宣传稿标题可以生动些，但要点明主题）。

9讲话稿 / 发言稿

识别标志"请为××领导拟写一份在××会议上的讲话稿"、"作为××代表，请写一份发言稿"、"在某活动上的致辞"。关键提示词：讲话、发言、致辞、开场、动员。
思考路径
  1. 定身份与场合：领导工作部署会（务实、有要求）／经验交流会（介绍做法）／动员会（鼓舞士气）／表彰会（褒扬+号召）。
  2. 结构（万能四段）：开场问候 → 回顾/背景 → 主体内容（做法/要求/部署，分条）→ 结语（希望/号召/感谢）。

  • 漏称呼语或漏结尾"谢谢大家"。
  • 身份错位：以普通员工身份写领导部署讲话，口气太大；或反之。
  • 通篇喊口号，没有实质内容（讲话稿也要有材料支撑）。

  • 主体不分条，一大段念完听众抓不住重点。

高频陷阱 · 表述越界警示
  • 不要编造具体数据（"据统计，全国有××%的人……"）。要用就用材料给的数据。
  • 不要编造具体人名、地名、单位名，需要例子时用"某地""某位基层干部"。
  • 不要引用不确定的领导人讲话原文，可用"有关部署明确要求"这类稳妥表述。
  • 不要使用过时提法，政策表述随时间更新，拿不准就换成通用表述。
  • 不要出现消极、吐槽、抱怨式表达（如"基层太难了""群众就是不配合"）。
  • 不要越权承诺（"我单位决定给予补贴"——基层无权先定这类事）。
