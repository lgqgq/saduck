# 历年真题与解析

**真题是最好的练习题**——每年考点高度重复，做透真题比做任何模拟题都有效。本模块收录国考、陕西省考、事业编三大考试的历年真题与解析，帮你摸清出题套路。

## 为什么真题如此重要

> [!key] 真题的三重价值
> 1. **考点风向标**：近 3 年考什么、怎么考，就是今年最可能的考法。每年重复率极高。
> 2. **命题规律**：干扰项怎么设置、正确项什么特征，只有真题能体现。
> 3. **真实难度**：模拟题常偏难/偏易，真题难度最接近考场，用于估分最准。

## 刷题基本原则

| 原则 | 说明 |
| --- | --- |
| 先分模块、后整套 | 第一轮按模块刷专项，第二轮才整套计时 |
| 真题 > 模拟题 | 优先做近年真题（近 3—5 年最佳），模拟题只做补充 |
| 做完必复盘 | 对答案只是开始，解析错因、标注考点才是提分关键 |
| 至少二刷 | 第一遍熟悉题型，第二遍练速度，第三遍查漏 |
| 留 2 套模考 | 考前留最近 2 套真题全真模考，别提前做完 |

## 本模块使用建议

- 每一道题**先遮住答案自己做**，再看解析；不要直接读解析。
- 申论大作文**自己先写**再对照立意，只读不写没效果。
- 结合各模块的专项页面使用效果更好：[国考行测](../guokao/xingce.html)、[省考行测](../shengkao/xingce.html)、[申论五大题型](../shenlun/tixing.html)。
