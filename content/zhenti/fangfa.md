# 历年真题使用方法

真题人人都买，但**会刷的人提分快**。本页教你如何科学利用真题，避免「刷了十套却原地踏步」。

## 第一阶段：分模块专项（考前 2—3 个月）

**目标**：熟悉题型、掌握考点，不求速度。

- 按模块刷：言语 → 判断 → 资料 → 数量 → 常识（申论按题型：概括 → 分析 → 对策 → 应用文 → 大作文）。
- 每模块完成后**归类考点**：这道题考的是「主旨概括」「削弱加强」还是「增长率」？在题旁标注。
- 这一阶段**可以查资料、看解析**，重点理解「为什么对、为什么错」。

> [!note] 关键动作：建立错题本
> 每道错题记录四要素：① 题目来源；② 考点；③ 我当时的思路；④ 正确思路。每周复盘一次错题本，把重复错的考点单拎出来专项攻破。

## 第二阶段：整套计时（考前 1 个月）

**目标**：练速度、练取舍、固定答题顺序。

- 每 2—3 天一套完整行测真题，**严格按考试时间**（国考 120 分钟、省考 120 分钟、职测 90 分钟）。
- 行测做不完很正常，重点练「**时间分配和取舍**」：三大保分模块（言语/判断/资料）优先保证正确率，数量留到最后。
- 每套题记录：各模块用时 + 正确率，对比前一套看进步。

| 模块 | 国考建议用时 | 目标正确率 |
| --- | --- | --- |
| 常识+政治理论 | 10—15 分钟 | 60% |
| 言语理解 | 30—35 分钟 | 75% |
| 判断推理 | 30—35 分钟 | 75% |
| 资料分析 | 25—30 分钟 | 90% |
| 数量关系 | 剩余时间 | 50%（挑会做的） |

## 第三阶段：冲刺模考（考前 1—2 周）

- 用**最近 2 年没做过的真题**全真模考（严格计时、涂卡、不中断）。
- 模考后重点看**错因分布**：是知识点不会，还是审题粗心，还是时间不够？针对性调整。
- 考前 3 天不再做新题，只看错题本 + 背高频公式/时政。

## 申论真题怎么刷

| 动作 | 说明 |
| --- | --- |
| 读材料 | 先快速通读标段落主题，再精读划关键词 |
| 独立作答 | **手写**，按考试时间限制每题 |
| 对答案 | 对比参考要点，找遗漏点和表述差距 |
| 复盘 | 归纳概括：漏点了还是超字数？大作文：立意偏了吗？ |
| 重写 | 大作文至少重写 1 遍，练到结构清晰 |

## 常见误区（避坑）

> [!warn] 四个「无效刷题」陷阱
> 1. **只对答案不复盘**：刷了 10 套，错的还是错。
> 2. **一上来就整套**：没学方法先计时，纯浪费真题。
> 3. **沉迷题量**：一天 300 道不如精做 30 道。
> 4. **提前做完最近真题**：考前想模考时没有题可用。

## 真题选择建议

- **优先近 3 年**：考点最贴近当前命题趋势。
- **省考看陕西**：省考行测/申论有地域差异（陕西申论分三类卷），尽量用陕西真题，参考国考和联考真题补充。
- **事业编分 A/D/E**：职测/综应按自己报考类别刷对应真题。

:::tip
把本模块的真题当作「拆弹练习」——每一道都拆开看考点和思路，做一题会一类，比盲目刷十题强得多。
:::
