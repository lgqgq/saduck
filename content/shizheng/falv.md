# 常识判断·法律高频考点

法律常识是常识判断里**性价比最高的板块**——考点高度集中、规律性强，背熟本页内容就能稳拿大部分法律题。

## 宪法核心考点

### 国家性质与制度（必背）

- **国体**（国家性质）：**人民民主专政**
- **政体**（根本政治制度）：**人民代表大会制度**
- **根本制度**：**社会主义制度**
- 一切权力属于人民（宪法第 2 条）
- 国家尊重和保障人权（宪法第 33 条）

### 公民基本权利（常考）

| 权利 | 要点 |
| --- | --- |
| 选举权 | 须年满 **18 周岁**且未被依法剥夺政治权利 |
| 平等权 | 法律面前人人平等 |
| 政治自由 | 言论、出版、集会、结社、游行、示威 |
| 人身自由 | 非经法定程序不受逮捕、搜查 |
| 物质帮助权 | 年老、疾病、丧失劳动能力时获得 |
| **劳动和教育** | **既是权利也是义务**（易错） |

### 国家机构（常考对应关系）

- **全国人大**：最高国家权力机关；修改宪法须全体代表 **2/3 以上**多数通过
- **国务院**：最高行政机关，有权制定**行政法规**
- **法院**：审判机关；**检察院**：法律监督机关
- **监察委**：**2018 年修宪新增**的国家监察机关

:::note
现行宪法是 **1982 年宪法**，先后经 1988、1993、1999、2004、**2018** 年五次修正。每次修正的核心内容（88 私营经济、93 市场经济、99 依法治国、04 人权入宪、18 监察委与习近平新时代思想）是常识题高频。
:::

## 民法典核心考点

### 民事行为能力（必背年龄线）

| 年龄 | 行为能力 |
| --- | --- |
| 不满 8 周岁 | **无**民事行为能力 |
| 8 周岁—18 周岁（含不能完全辨认的成年人） | **限制**民事行为能力 |
| 16—18 周岁以自己劳动收入为主要生活来源 | 视为**完全**民事行为能力 |
| 18 周岁以上 | **完全**民事行为能力 |

### 诉讼时效（常考）

- 普通诉讼时效：**3 年**
- 最长权利保护期：**20 年**

### 婚姻家庭（高频）

- **离婚冷静期 30 天仅适用协议离婚**，不适用诉讼离婚；冷静期届满后 30 日内未领证视为撤回
- 女方怀孕期间、分娩后 1 年内、终止妊娠后 6 个月内，男方不得提出离婚

### 继承（高频）

- 继承自被继承人死亡时开始
- **数份遗嘱以最后一份为准**（公证遗嘱不再优先，2021 年民法典新规）
- 代位继承限直系晚辈血亲
- 死亡赔偿金**不属于**遗产（易错）

### 其他亮点

- 新设**居住权**（用益物权，须登记设立，不得转让、继承）
- 高空抛物：由侵权人担责；难以确定侵权人的，由可能加害的建筑物使用人补偿

## 刑法核心考点

### 刑事责任年龄（必背三档）

| 年龄 | 刑事责任 |
| --- | --- |
| 不满 12 周岁 | 不负刑事责任 |
| 12—14 周岁 | 故意杀人、故意伤害致人死亡等**情节恶劣**，经最高检核准可追诉 |
| 14—16 周岁 | 仅对**故意杀人、故意伤害致人重伤或死亡、抢劫、强奸、贩卖毒品、放火、爆炸、投放危险物质**等重罪负责（8 类） |
| 16 周岁以上 | 完全负刑事责任 |

### 正当防卫 vs 紧急避险

- **正当防卫**：针对**正在进行**的不法侵害人
- **紧急避险**：通过损害**较小**合法权益保全**较大**合法权益
- **特殊防卫**：对行凶、杀人、抢劫、强奸、绑架等严重危及人身安全的暴力犯罪，防卫致其死伤不负刑责

### 刑罚种类

- **主刑（5 种）**：管制、拘役、有期徒刑、无期徒刑、死刑
- **附加刑（4 种）**：罚金、剥夺政治权利、没收财产、驱逐出境
- 易错：**罚金**是刑罚，**罚款**是行政处罚

### 易混罪名（必考区分）

| 罪名 | 关键特征 |
| --- | --- |
| 盗窃 | 秘密窃取 |
| 抢劫 | 暴力、胁迫或其他手段（当场取财） |
| 抢夺 | 公然夺取，无暴力 |
| 诈骗 | 虚构事实，被害人**主动交付** |

## 行政法核心考点

- **行政处罚**：一事不再罚；较大数额罚款、吊销证照等适用听证；当场收缴罚款一般限 **100 元以下**
- **行政复议**（上级机关审查）vs **行政诉讼**（法院审查）
- 对**行政拘留**不服，可**直接提起行政诉讼**，无需先复议
- 行政复议一般 60 日内申请；行政诉讼 6 个月内起诉
- 公务员对内部处分不服，走内部申诉程序，不属于行政诉讼受案范围

> [!tip] 记忆方法
> 法律题重「数字 + 区分」：年龄（8/16/18、刑事责任 12/14/16）、时效（3 年/20 年）、刑罚（罚金 vs 罚款）、罪名（盗抢夺诈）。把本页表格反复背，做 50 道法律专项题即可固化。

:::key
**最高频的 3 个易错点**：① 劳动和教育是权利也是义务；② 罚金是刑罚、罚款是处罚；③ 诈骗罪的被害人是主动交付财物。
:::
