# 陕西省考概览

**省考**，全称「陕西省统一考试录用公务员」，由 **陕西省公务员局** 组织，招录**省、市、县、乡四级机关**的公务员，编制为**陕西省地方公务员**。

对想留在陕西（西安及各市县）工作的考生来说，省考是**最主要的战场**——2026 年陕西省考招录 **5272 人**，远超国考在陕西的 961 人。

## 关键信息速览

| 事项 | 说明 |
| --- | --- |
| 组织机关 | 陕西省公务员局 |
| 公告发布 | 每年 1 月底—2 月初（2026 年为 1 月 26 日） |
| 报名网站 | 陕西人事考试网 [www.sxrsks.cn](http://www.sxrsks.cn) |
| 公共科目满分 | 行测 150 分、申论 150 分 |
| 笔试时间 | 每年 3 月中旬（2026 年为 3 月 14 日） |
| 面试形式 | 结构化为主（3 题 12 分钟） |

## 什么是「多省联考」？

陕西参加的省考是**多省（区、市）联考**：多省在同一周末、使用**统一命题库**组织公共科目笔试。这带来两个重要特点：

1. **题目基本一致**：陕西卷与参加联考的河南、河北、甘肃、宁夏等省公共科目题目高度相似（个别省份有本土题目），所以刷**联考历年真题**非常有效。
2. **时间集中**：全国联考笔试集中在 3 月的一个周末，意味着你只能选择**一个省份**参加省考笔试，不能多省同时报（考试时间冲突）。

:::note
陕西近年在联考中属于**命题相对规范、难度适中**的省份。行测满分 150 分，题量、难度与国考不同，有自己的命题风格（下文详述）。
:::

## 陕西省考特点

1. **招录规模大**：每年 5000 人左右，基层岗位（县乡级）占大头，机会多。
2. **申论三类分卷**：省市级、县乡级、行政执法三类职位，分别命制申论试题。
3. **分数构成特殊**：行测、申论各 **150 分**（不是国考的 100 分），总分 300 分，面试成绩按 40% 计入总成绩。
4. **服务基层项目倾斜**：设面向村（社区）干部、三支一扶、大学生村官、退役士兵的专门职位。
5. **公安加试**：公安类职位加试《公安专业科目》100 分。

## 陕西省考 vs 国考

| 维度 | 国考 | 陕西省考 |
| --- | --- | --- |
| 招录主体 | 中央机关及直属机构 | 省、市、县、乡四级机关 |
| 陕西招录 | 约 961 人（2026） | **5272 人**（2026） |
| 岗位分布 | 税务、金融监管等垂直系统 | 全省各地党政机关、政法、乡镇 |
| 编制 | 国家公务员 | 陕西省公务员 |
| 行测/申论满分 | 各 100 分 | 各 **150 分** |
| 笔试时间 | 11 月底 | 3 月中旬 |
| 难度 | 更高、竞争更激烈 | 相对友好、基层岗多 |

:::tip
**备考思路**：把国考当「练兵」，把省考当「主战场」。两场考试公共科目能力相通，国考 11 月考完，正好用 3 个月全力冲刺次年 3 月的省考。
:::

## 陕西省考职位类别

省考职位分为三大类，对应不同的申论试卷与能力要求：

| 类别 | 面向职位 | 申论侧重点 |
| --- | --- | --- |
| **省市级职位** | 省级、市级机关及直属机构 | 综合分析、宏观治理、文字表达要求高 |
| **县乡级职位** | 县级、乡镇机关 | 基层治理、群众工作、解决问题 |
| **行政执法职位** | 公安、司法、市场监管、生态环境等执法岗 | 依法行政、依法办事、公共服务 |

## 常见问题

**陕西人只能考陕西省考吗？**
> 不是。联考只能选一省笔试，但你可以选择任何参加联考的省份（只要符合报考条件）。不过工作地点在陕西的话，通常考陕西省考最合适。

**省考和国考能同时备考吗？**
> 完全可以，且**强烈建议**。二者考点高度重合，先国考后省考，两次考试一次备考。详见[备考计划](beikao.html)。

**陕西省考难吗？**
> 比国考友好，但竞争依旧激烈。西安城区热门岗报录比常达 100:1 以上，而偏远县乡岗位竞争比低、进面分低。选岗是省考胜负手，详见[考情与职位](shaanxi.html)。
