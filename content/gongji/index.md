# 公共基础知识专题

**公共基础知识（公基）**是陕西事业编部分岗位的笔试科目，也是国考/省考行测常识模块的直接来源。公基范围虽广，但**考点高度集中**——背熟本专题，大部分高频考点都能覆盖。

## 模块内容导航

:::cards
:::card
**宪法高频考点** — 国体政体、公民权利、国家机构
人民民主专政、人民代表大会制度、劳动教育双义务、监察委、1982 宪法五次修正。
:::
:::card
**民法典高频考点** — 年龄、时效、婚姻继承
民事行为能力三档、诉讼时效 3 年、离婚冷静期、遗嘱新规、居住权。
:::
:::card
**刑法高频考点** — 责任年龄、正当防卫、易混罪名
12/14/16 三档、特殊防卫、罚金 vs 罚款、盗抢夺诈区分。
:::
:::card
**行政法高频考点** — 处罚、复议、诉讼
一事不再罚、100 元当场收缴、复议 vs 诉讼、行政拘留直诉。
:::
:::card
**政治与经济常识** — 马哲、宏观经济
唯物辩证法核心、中国式现代化五特征、GDP/CPI、货币政策财政政策。
:::
:::card
**公文写作要点** — 15 种法定公文
通知/通报/报告/请示/函的适用、格式要素、一文一事。
:::
:::card
**科技人文常识** — 四大发明、名著节气
四大发明、医圣、史学双璧、四书五经、二十四节气、朝代顺序。
:::
:::card
**党史与时政常识** — 里程碑、全会精神
一大、遵义、十一届三中全会、二十大、二十届三中全会「七个聚焦」。
:::
:::

## 公基怎么考、怎么备

| 考试场景 | 公基地位 |
| --- | --- |
| 陕西事业编部分岗位 | **独立笔试科目**（或并入综应），直接考 |
| 国考/省考行测 | 融合进「常识判断」板块 |
| 事业编职测 | 常识部分考查 |
| 面试 | 政策、法律常识是答题素材 |

### 备考优先级

> [!key] 公基「四三二一」法则
> - **四**大法律（宪法、民法典、刑法、行政法）——分值占比最高，**重点背**。
> - **三**大常识（政治经济、公文、科技人文）——高频且稳定，**按表格背**。
> - **二**个结合（党史 + 时政）——与时政热点联动，**考前突击**。
> - **一**句话：**抓大放小，不追求全会**——冷门偏题果断放弃。
