# 公基 · 宪法高频考点

宪法是公基法律部分**占比最重的板块**，以识记为主。本页把高频考点系统化。

## 国家性质与制度（必背）

| 概念 | 内容 |
| --- | --- |
| **国体**（国家性质） | **人民民主专政** |
| **政体**（根本政治制度） | **人民代表大会制度** |
| **根本制度** | **社会主义制度** |
| 根本任务 | 沿着中国特色社会主义道路，集中力量进行社会主义现代化建设 |
| 权力来源 | 一切权力属于人民（宪法第 2 条） |
| 人权保障 | 国家尊重和保障人权（宪法第 33 条） |

## 公民基本权利（常考）

### 基本权利清单

- **平等权**：法律面前人人平等
- **政治权利与自由**：选举权和被选举权、言论出版集会结社游行示威自由
- **人身自由**：生命权、人身自由不受侵犯、人格尊严、住宅、通信自由
- **宗教信仰自由**
- **经济文化权利**：财产权、劳动权、受教育权、物质帮助权

### 易错点

- **选举权**：须年满 **18 周岁**，且未被依法剥夺政治权利
- **物质帮助权**：年老、疾病、丧失劳动能力时
- **劳动和受教育**：**既是权利也是义务**（高频易错）

## 国家机构（常考对应）

| 机构 | 性质 | 要点 |
| --- | --- | --- |
| **全国人民代表大会** | 最高国家权力机关 | 修改宪法须全体代表 **2/3 以上**多数通过；制定基本法律 |
| **全国人大常委会** | 全国人大常设机关 | 解释宪法法律 |
| **国务院** | 最高国家行政机关 | 制定**行政法规** |
| **国家监察委** | 国家监察机关 | **2018 年修宪新增**；监察公职人员 |
| **人民法院** | 审判机关 | 独立行使审判权 |
| **人民检察院** | 法律监督机关 | 独立行使检察权 |

## 宪法修正（必背时间线）

现行宪法为 **1982 年宪法**，先后五次修正：

| 年份 | 修正核心内容 |
| --- | --- |
| 1988 | 私营经济合法地位 |
| 1993 | 社会主义市场经济 |
| 1999 | 依法治国、基本经济制度 |
| 2004 | **人权入宪**、"三个代表"入宪 |
| 2018 | 设立**监察委员会**、习近平新时代中国特色社会主义思想入宪 |

:::key
**最高频考点**：① 政体是人民代表大会制度（不是多党合作制）；② 劳动和受教育既是权利也是义务；③ 监察委 2018 年入宪；④ 修改宪法须 2/3 以上多数通过。
:::

> [!tip] 记忆法
> 用「一、二、三」串记：**一**个根本政治制度（人大制度）；**二**项权利义务（劳动+受教育）；**三**个 2/3 相关（修宪 2/3、罢免等特殊表决）。机构对应关系画一张树状图最好记。
