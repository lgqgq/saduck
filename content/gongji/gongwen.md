# 公基 · 公文写作要点

公文写作是公基与申论（贯彻执行题）的共通考点。依据《**党政机关公文处理工作条例**》（中办发〔2012〕14 号）。

## 15 种法定公文（必背）

**决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要**

> [!note] 记忆法
> 十五种法定公文：议决定命令公（议、决、定、命令、公[报]）、通通通意（通知、通报、通告、意见）、报请批（报告、请示、批复）、函纪要。平时考试爱考「下列属于法定公文的是」。

## 高频文种适用（必考）

| 文种 | 适用情形 | 关键特征 |
| --- | --- | --- |
| **通知** | 发布、传达要求下级执行的事项；批转、转发公文 | 最常用，下行文 |
| **通报** | 表彰先进、批评错误、传达重要精神、告知重要情况 | 重「教育性」 |
| **报告** | 向上级**汇报**工作、反映情况、回复上级询问 | **不要求批复** |
| **请示** | 向上级**请求**指示、批准 | **一文一事、需批复** |
| **函** | 不相隶属机关之间商洽工作、询问答复问题 | **平行文** |
| **批复** | 答复下级机关的请示 | 针对性 |
| **意见** | 对重要问题提出见解和处理办法 | 可上行/下行/平行 |
| **公告** | 向**国内外**宣布重要事项 | 范围最广 |
| **通告** | 在一定范围内公布应当遵守或周知的事项 | 范围较窄 |

:::key
**最高频易错**：① **报告不要求批复，请示需批复**；② 请示要**一文一事**；③ 函是**平行文**（不相隶属机关之间）；④ 公告范围>通告范围。
:::

## 公文格式要素

### 版头部分

- **发文字号**：机关代字 + 〔年份〕 + 序号（如「陕政发〔2026〕1 号」）
- 密级（绝密/机密/秘密）、紧急程度（特急/加急）、发文机关标志

### 主体部分

- **标题**：发文机关 + 事由 + 文种（如《陕西省人民政府关于××的通知》）
- **主送机关**：受文机关名称
- **正文**：开头（缘由）→主体（事项）→结尾（结语）
- 附件说明、发文机关署名、成文日期、印章

### 版记部分

- 抄送机关、印发机关和印发日期

> [!warn] 易错细节
> ① 标题中除法规、规章名称加书名号外，一般不标点；② 成文日期用阿拉伯数字（如 2026 年 8 月 20 日）；③ 公文应当加盖发文机关印章。

## 常见文种写作要点

### 请示（最常见考题）

```
标题：×××关于××的请示
主送机关：×××
正文：请示缘由 → 请示事项（一文一事、具体明确）→ 结语（妥否，请批示）
落款：发文机关署名 + 成文日期 + 印章
```

### 通知（最常用）

```
标题：×××关于印发××的通知 / 关于开展××工作的通知
正文：发文缘由 → 通知事项（分条列项）→ 执行要求
```

### 函

```
标题：×××关于××的函
正文：商洽/询问/答复事项，用语谦和
结语：请复函 / 特此函复
```

> [!tip] 与申论贯彻执行题的关系
> 申论「贯彻执行」题常考写通知、倡议书、调研报告提纲等，公文格式就是得分要点。可结合[申论贯彻执行](../shenlun/guanche.html)学习。

:::warn
公文规范依据《党政机关公文处理工作条例》，更新至 2026 年 8 月。
:::
