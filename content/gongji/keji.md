# 公基 · 科技人文常识

科技与人文是公基的「背多分」板块——范围广但考点集中，本页梳理高频内容。

## 中国古代科技成就

### 四大发明（必背）

| 发明 | 时间线 |
| --- | --- |
| 造纸术 | **西汉**发明，**东汉蔡伦**改进 |
| 印刷术 | 隋唐**雕版**印刷，**北宋毕昇**发明活字印刷 |
| 指南针 | 战国**司南**，北宋用于航海 |
| 火药 | **唐中期**发明，唐末用于军事 |

### 天文数学

- **张衡**：地动仪
- **祖冲之**：《大明历》，把圆周率精确到**小数点后第七位**
- **郭守敬**（元代）：《授时历》一年 365.2425 日，比现行公历早约 300 年

### 医学（人物-著作对应）

| 人物 | 成就 |
| --- | --- |
| **扁鹊** | 四诊法（望闻问切） |
| **张仲景** | 《伤寒杂病论》，「医圣」 |
| **华佗** | 麻沸散（外科麻醉） |
| **孙思邈** | 《千金方》，「药王」 |

### 综合著作

- **《天工开物》**（宋应星）：中国第一部农业和手工业生产技术综合著作，「中国 17 世纪的工艺百科全书」
- **《梦溪笔谈》**（沈括）：综合性笔记体著作，「中国科学史上的里程碑」

## 文学与史学常识

### 史学双璧

- **司马迁**《史记》：第一部**纪传体**通史
- **司马光**《资治通鉴》：**编年体**通史

### 四书五经

- **四书**：《大学》《中庸》《论语》《孟子》
- **五经**：《诗》《书》《礼》《易》《春秋》

### 古代文学（常考）

- 《诗经》：我国第一部诗歌总集，现实主义源头
- 《楚辞》/屈原：《离骚》，浪漫主义源头
- 唐诗宋词：李白（诗仙）、杜甫（诗圣）、苏轼、辛弃疾等

## 二十四节气（口诀必背）

> **春雨惊春清谷天，夏满芒夏暑相连，秋处露秋寒霜降，冬雪雪冬小大寒。**

- 2016 年列入联合国教科文组织**人类非物质文化遗产代表作名录**。
- 常见考法：判断节气所属季节、与农事/节日的对应（清明扫墓、冬至吃饺子等）。

## 朝代顺序（必背）

**夏 → 商 → 周（西周/东周）→ 秦 → 汉（西汉/东汉）→ 三国 → 两晋（西晋/东晋）→ 南北朝 → 隋 → 唐 → 五代十国 → 宋（北宋/南宋）→ 元 → 明 → 清**

:::key
**最高频考点**：① 造纸西汉发明、东汉蔡伦改进；② 活字印刷是北宋毕昇；③ 医圣张仲景《伤寒杂病论》；④ 淝水之战→草木皆兵；⑤ 二十四节气口诀；⑥ 朝代顺序排序题。
:::
