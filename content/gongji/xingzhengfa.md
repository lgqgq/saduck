# 公基 · 行政法高频考点

行政法考点集中在**行政处罚、行政复议 vs 行政诉讼**两大块，理解「上级审查 vs 法院审查」是关键。

## 行政处罚（高频）

| 考点 | 要点 |
| --- | --- |
| 一事不再罚 | 对同一违法行为不得给予**两次以上罚款**的行政处罚 |
| 处罚种类 | 警告、罚款、没收违法所得、责令停产停业、暂扣/吊销许可证件、行政拘留等 |
| 听证程序 | 适用**吊销证照、较大数额罚款**等较重处罚，当事人可申请听证（不收费） |
| 当场收缴罚款 | 一般限 **100 元以下**（2021 年新行政处罚法） |
| 处罚时效 | 违法行为在 **2 年内**未被发现的不再处罚（涉生命健康、金融安全等延长至 5 年） |

> [!warn] 易错
> ① 一事不再罚指「不再罚**款**」，不是不能叠加其他处罚；② 听证是**依申请**启动，不是主动。

## 行政许可

- 设定原则：可以设定行政许可的事项包括**直接涉及国家安全、公共安全**，有限自然资源开发利用，公共资源配置等。
- 许可程序：申请→审查→决定；延续申请应在届满**30 日前**提出。

## 行政复议 vs 行政诉讼（核心对比）

| 对比项 | 行政复议 | 行政诉讼 |
| --- | --- | --- |
| 审查机关 | **上级行政机关** | **人民法院** |
| 性质 | 行政内部救济 | 司法救济 |
| 申请期限 | 知道具体行政行为之日起 **60 日**内 | 6 个月内起诉 |
| 是否收费 | 不收费 | 诉讼费（部分减免） |
| 审查范围 | 合法性与合理性 | 合法性为主 |

### 关键规则

- 对**行政拘留**不服，可**直接提起行政诉讼**，无需先申请复议（拘留是最重的人身罚）。
- 属于复议前置的（如部分自然资源确权案件），须先复议再诉讼。
- **公务员对内部处分（如警告、记过、降级）不服**，走**内部申诉**程序，不属于行政诉讼受案范围。

:::key
**最高频考点**：① 复议是「上级审查」、诉讼是「法院审查」；② 行政拘留可直接起诉；③ 公务员内部处分不能起诉；④ 复议 60 日、诉讼 6 个月。
:::

## 行政行为类型（常识补充）

| 类型 | 例子 |
| --- | --- |
| 抽象行政行为 | 制定法规、规章（不能直接起诉） |
| 具体行政行为 | 处罚、许可、强制（可复议可诉讼） |
| 行政强制措施 | 查封、扣押、冻结、限制人身自由 |
| 行政强制执行 | 代履行、加处罚款、申请法院执行 |

> [!tip] 记忆法
> 一句话串记：**「复议找上级、诉讼找法院；拘留直接诉、处分只申诉。」**
