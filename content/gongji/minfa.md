# 公基 · 民法典高频考点

民法典是公基法律中**案例题最多**的部分。考点集中在年龄线、时效、婚姻家庭、继承四大块。

## 民事行为能力（必背年龄线）

| 年龄段 | 行为能力 |
| --- | --- |
| 不满 **8 周岁** | **无**民事行为能力 |
| **8—18 周岁**（含不能完全辨认自己行为的成年人） | **限制**民事行为能力 |
| **16—18 周岁**，以自己的劳动收入为主要生活来源 | 视为**完全**民事行为能力 |
| **18 周岁以上** | **完全**民事行为能力 |

> [!note]
> 限制民事行为能力人可独立实施**纯获利益**（受赠、获奖）或与年龄智力相适应的行为。

## 诉讼时效（常考）

| 类型 | 期间 |
| --- | --- |
| 普通诉讼时效 | **3 年** |
| 特殊诉讼时效（国际货物买卖等） | 4 年 |
| 最长权利保护期间 | **20 年**（自权利被侵害之日起算，不中断中止） |

## 婚姻家庭（高频）

- **离婚冷静期**：**30 天，仅适用协议离婚**，不适用诉讼离婚；冷静期届满后 30 日内未领证视为撤回。
- **男方离婚限制**：女方怀孕期间、分娩后 1 年内、终止妊娠后 6 个月内，男方不得提出离婚（女方提出或法院认为确有必要除外）。
- **共同财产**：婚姻关系存续期间的工资、奖金、生产经营收益等；个人财产（婚前财产、专用生活用品等）归个人。

## 继承（高频）

| 考点 | 要点 |
| --- | --- |
| 继承开始 | 自被继承人**死亡时**开始 |
| 遗嘱效力 | **数份遗嘱以最后一份为准**（公证遗嘱**不再优先**，2021 年民法典新规） |
| 法定继承顺序 | 第一顺序：配偶、子女、父母；第二顺序：兄弟姐妹、祖父母、外祖父母 |
| 代位继承 | 限直系晚辈血亲（子女先于被继承人死亡，其晚辈直系血亲代位继承） |
| 非遗产 | **死亡赔偿金不属于遗产**（易错）；抚恤金原则上不属于 |
| 遗嘱形式 | 自书、代书、打印、录音录像、口头、公证 |

## 物权与合同（亮点）

- 物权的变动：**不动产物权以登记**为生效要件；**动产物权以交付**为生效要件。
- 新设**居住权**：用益物权，须**登记设立**，不得转让、继承。
- 高空抛物：由**侵权人**承担侵权责任；难以确定侵权人的，由可能加害的建筑物使用人给予**补偿**（后有权追偿）；物业服务企业承担安全保障义务。
- 买卖不破租赁：租赁期间所有权变动的，租赁合同对买受人有效。

:::key
**最高频易错点**
1. 离婚冷静期 **30 天只适用于协议离婚**；
2. 数份遗嘱**以最后一份为准**（不是公证遗嘱优先）；
3. **死亡赔偿金不属于遗产**；
4. 不动产物权看**登记**、动产物权看**交付**。
:::

> [!tip] 记忆法
> 年龄线记「8、16、18」：8 岁无、16 岁劳动独立视为完全、18 岁成年。时效记「3 年普通、20 年最长」。婚姻继承记住 4 个易错点即可拿分。
