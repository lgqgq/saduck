# 公基 · 刑法高频考点

刑法考点集中在**刑事责任年龄、正当防卫、刑罚种类、易混罪名**四块，重记忆、爱考区分。

## 刑事责任年龄（必背三档）

| 年龄 | 刑事责任 |
| --- | --- |
| 不满 **12 周岁** | 不负刑事责任 |
| **12—14 周岁** | 犯故意杀人、故意伤害罪，致人死亡或以特别残忍手段致人重伤造成严重残疾，情节恶劣，经**最高人民检察院核准追诉**的，应负刑事责任 |
| **14—16 周岁** | 仅对 **8 种重罪**负责：故意杀人、故意伤害致人重伤或死亡、**强奸、抢劫、贩卖毒品、放火、爆炸、投放危险物质** |
| **16 周岁以上** | 完全负刑事责任（不满 18 周岁应从轻或减轻处罚，不适用死刑） |

> [!note]
> 「14—16 周岁只对 8 类重罪负责」是最高频考点。注意是**贩卖毒品**（不是走私/运输/制造全部），且**盗窃、诈骗、交通肇事**等 14—16 岁不负责。

## 正当防卫 vs 紧急避险（必考）

| 对比项 | 正当防卫 | 紧急避险 |
| --- | --- | --- |
| 侵害来源 | 人的不法侵害 | 自然、动物或人的侵害 |
| 对象 | **不法侵害人** | 第三人的合法权益 |
| 限度 | 制止侵害所必需 | 损害较小利益保全较大利益 |
| 责任 | 不负刑事责任 | 不负刑事责任（超过必要限度造成不应有损害的除外） |

### 特殊防卫（无限防卫）

对**行凶、杀人、抢劫、强奸、绑架**以及其他严重危及人身安全的**暴力犯罪**，采取防卫行为造成不法侵害人伤亡的，**不负刑事责任**。

## 刑罚种类（必背）

### 主刑（5 种）

**管制** → **拘役** → **有期徒刑** → **无期徒刑** → **死刑**

- 管制：不关押，限制自由
- 拘役：短期剥夺自由，就近执行
- 死刑：只适用于罪行极其严重的犯罪分子；审判时怀孕的妇女、犯罪时不满 18 周岁的人**不适用死刑**

### 附加刑（4 种）

**罚金、剥夺政治权利、没收财产、驱逐出境**（驱逐出境适用于外国人）

> [!warn] 高频易错
> **罚金**是刑罚（刑法中的附加刑）；**罚款**是行政处罚。两者别混淆。剥夺政治权利包括选举权被选举权、言论出版集会结社游行示威自由等。

## 易混罪名区分（必考）

| 罪名 | 关键特征 |
| --- | --- |
| 盗窃罪 | **秘密窃取**他人财物 |
| 抢劫罪 | **暴力/胁迫/其他方法**，当场强行劫取财物 |
| 抢夺罪 | **公然夺取**，不使用暴力 |
| 诈骗罪 | **虚构事实、隐瞒真相**，被害人**自愿交付**财物 |
| 敲诈勒索罪 | 威胁、要挟，被害人基于恐惧交付 |

:::key
**一句话区分**：盗窃是「偷偷拿」，抢劫是「强抢」，抢夺是「趁你不备拿」，诈骗是「骗你主动给」。看「被害人是否自愿交付」判断诈骗。
:::

## 其他常考制度

- **追诉时效**：按法定最高刑分 **5 / 10 / 15 / 20 年**四档；最高刑为无期/死刑的，追诉 20 年后如认为必须追诉，报最高检核准。
- **累犯**：被判处有期徒刑以上刑罚，刑罚执行完毕后 5 年内再犯应判处有期徒刑以上之罪的，从重处罚（过失犯罪除外）。
- **共同犯罪**：二人以上共同故意犯罪。
- **犯罪未遂**：已经着手实行犯罪，由于意志以外的原因未得逞。
- **犯罪中止**：自动放弃犯罪或自动有效防止犯罪结果发生。

> [!tip] 记忆法
> 刑事责任年龄记「12、14、16」三档；特殊防卫记「行凶、杀人、抢劫、强奸、绑架」五类暴力犯罪；易混罪名按「被害人主动不主动」判断。
