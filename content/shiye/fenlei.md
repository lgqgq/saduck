# 事业单位岗位类别 A–E

事业单位公开招聘岗位按**考试类别**分为 A/B/C/D/E 五类（陕西联考通常开考 A/D/E 三类，B/C 类多出现在全国联考或部分地区单独招聘）。报考时岗位表中会标注类别，**类别决定你的笔试试卷**。

## 五大类别一览

| 类别 | 全称 | 典型岗位 | 笔试科目 |
| --- | --- | --- | --- |
| **A 类** | 综合管理类 | 机关所属事业单位的管理岗、文职岗 | 职测 A + 综应 A |
| **B 类** | 社会科学专技类 | 经济、法律、新闻、出版、翻译、会计等专技岗 | 职测 B + 综应 B |
| **C 类** | 自然科学专技类 | 工程、农业、统计、计算机、地质等专技岗 | 职测 C + 综应 C |
| **D 类** | 中小学教师类 | 中小学、幼儿园、中等职业学校教师 | 职测 D + 综应 D |
| **E 类** | 医疗卫生类 | 医院、疾控、基层卫生院的医护岗 | 职测 E + 综应 E |

## 各类别综应特点

| 类别 | 综应核心 | 题型特点 |
| --- | --- | --- |
| **A 类** | 办文办会办事能力 | 归纳概括、提出对策、公文/应用文，偶有议论文 |
| **B 类** | 社会科学研究、写作能力 | 概念分析、论证评价、文章写作（小作文） |
| **C 类** | 科学思维、实验设计、数理能力 | 科技文献阅读、论证评价、科技实务 |
| **D 类** | 教育知识与教学能力 | 辨析、案例分析、教育方案设计 |
| **E 类** | 医学知识与卫生实务 | 案例分析、实务题（分临床/护理/药剂等） |

:::key
**报考时看清类别再备考**。A 类最接近公务员申论；D 类要有教育学心理学基础；E 类要有医学背景。跨类别备考代价很高，选岗时先确认自己能应付哪套试卷。
:::

## 陕西考生的常见选择

| 背景 | 推荐类别 | 原因 |
| --- | --- | --- |
| 非师范、非医学专业 | **A 类** | 无专业门槛，综应好上手 |
| 师范 / 有教师资格证 | **D 类** | 专业对口，竞争相对可控 |
| 医学相关专业 | **E 类** | 专业壁垒高，竞争较小 |
| 会计、法学、新闻等文科专技 | **B 类**（若有） | 专业对口，综应考写作 |
| 理工科、工程类 | **C 类**（若有） | 专业对口，考科学思维 |

## 选岗建议

1. **先看类别、再看单位**：类别决定试卷，备考前必须确定。
2. **专业对口优先**：有专业壁垒的岗位，报考人数远少于「三不限」，上岸概率高。
3. **注意资格证书**：D 类要教师资格证、E 类要执业资格，先确认自己是否持证。
4. **城市 vs 基层**：西安城区岗位竞争激烈；县区、乡镇事业单位岗位竞争温和，且有基层补贴。

:::warn
陕西事业单位联考**各地市岗位类别不完全相同**，同一类别的试卷由全省统一命制、统一阅卷，但各地市独立发布公告、独立组织。报名时以岗位表标注的类别为准。
:::

## 常见问题

**B/C 类在陕西有吗？**
> 陕西联考近年主要开考 A/D/E 三类。B/C 类岗位（社科、自然专技）多由各单位单独招聘，或并入 A 类管理岗招录。想报 B/C 类要关注**单独招聘公告**。

**「参公事业单位」和「事业单位」有区别吗？**
> 有。**参公单位**（参照公务员法管理的事业单位）人员按公务员管理、待遇参照公务员；**一般事业单位**按事业编管理。报考时注意岗位表标注。

**D 类教师岗竞争大吗？**
> 中小学教师岗报考人数多，但**岗位也多**（陕西教师招聘规模大）。有教师资格证的考生，D 类是性价比很高的选择。
