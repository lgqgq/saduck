# 综合应用能力（综应）

**综合应用能力（综应）** 是事业单位联考笔试第二科，**满分 150 分、时长 120 分钟**。它是主观性试题，常被比作「事业单位版申论」，但差异其实很大。

## 综应 vs 申论

| 维度 | 公务员申论 | 事业编综应 |
| --- | --- | --- |
| 满分 | 100 / 150 分 | 150 分 |
| 时长 | 180 分钟 | **120 分钟** |
| 考察核心 | 阅读理解 + 文字表达 | **实际工作能力 + 岗位情境** |
| 材料风格 | 宏观政策、社会议题 | **具体工作场景、管理情境** |
| 大作文 | 有（1000 字+） | A 类有议论文，D/E 类多为情境题，无大作文 |

:::key
**综应更「实务」**：它模拟你作为事业单位工作人员**办一件事**的全过程——看通知、理问题、定方案、写讲话、做汇报。材料常给你一个具体单位、具体场景，让你解决实际问题。
:::

## A 类综应（综合管理）

- 给定材料：一个事业单位具体工作的**情境材料**（如某服务中心收到投诉、某项活动需要组织）。
- 题型：**归纳概括 + 提出对策 + 公文写作 + 应用文**，偶尔有**议论文**。
- 侧重：办文办会办事能力、应急处理、组织协调、文字功底。

**典型题型**：
1. 概括材料中存在的问题或原因；
2. 针对问题提出改进建议/解决措施；
3. 撰写一份工作方案、通知、请示、讲话稿；
4. 对某个情境作分析评价或提出处理意见。

## D 类综应（中小学教师）

- 给定材料：**教育情境**（课堂教学、班级管理、家校沟通、学生心理）。
- 题型：辨析题、案例分析题、教育方案设计题。
- 侧重：教育学、心理学原理在教育实践中的应用、班级管理、教育机智。

**典型题型**：
1. 辨析一段教育观点或做法（正误 + 理由）；
2. 分析一个教育案例（如学生上课玩手机），提出处理对策；
3. 设计一节班会课方案 / 教育专题活动方案。

## E 类综应（医疗卫生）

- 给定材料：**医疗场景**（问诊、突发公共卫生事件、医患沟通、感染控制）。
- 题型：案例分析题、实务题（分岗位：西医临床、中医、护理、药剂等）。
- 侧重：医学知识应用、卫生应急、职业防护、医患沟通。

**典型题型**：
1. 分析一个病例的诊疗要点 / 用药问题；
2. 处理突发公共卫生事件（如疫情处置流程）；
3. 医患沟通情境的处理。

:::note
D 类、E 类综应**专业性较强**，需要具备教育/医学的专业基础。跨专业裸考 D/E 类综应，得分会比较困难。综合管理类（A 类）相对更适合非师范、非医学背景考生。
:::

## 作答要点

1. **审清角色**：材料会让你以「某单位工作人员」「班主任」「值班医生」身份作答，答题视角要对。
2. **答案要有「落地感」**：对策要具体可操作（谁来做、做什么、怎么做），避免空话套话。
3. **格式规范**：公文题注意标题、称谓、正文、落款格式。
4. **分条作答**：条理清晰，要点前置。
5. **控制时间**：120 分钟写 1500—2000 字，同样要限时训练。

## 备考建议

1. **A 类**：以「问题 + 对策 + 应用文」为核心，多练方案、通知、讲话稿写作。
2. **D 类**：系统过一遍教育学、心理学基础，积累班级管理、家校沟通案例。
3. **E 类**：按自己报考的专业方向（临床/护理/药剂等）复习专业知识 + 卫生法规。
4. **真题优先**：刷陕西事业单位联考综应真题 + 全国联考真题。
5. **对比申论**：有申论基础的考生，重点体会综应的「岗位情境」和「方案型题目」差异。

:::tip
**考事业编前先想清楚报哪类**：A 类（综合管理）最通用，适合大部分考生；D/E 类有专业门槛，但竞争相对小、入编后专业对口。选择直接影响综应备考方向。
:::

## 常见问题

**综应和申论能一起复习吗？**
> 申论基础（归纳概括、提出对策、公文格式）对综应 A 类帮助很大，可以共享方法。但综应的**情境题、方案题**需要单独练习。D/E 类与申论差异更大。

**A 类综应会考大作文吗？**
> 部分地区会考。陕西 A 类综应可能含一篇议论文（类似申论大作文），占比 50 分左右。不能完全放弃大作文，但重心在情境题。
