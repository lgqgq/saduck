# 公共基础知识（公基）

**公共基础知识（公基）** 是部分事业单位（以及一些国企、社区工作者、三支一扶）招聘笔试的科目。陕西省属联考 A/D/E 类不直接考公基，但**部分单独招聘**（尤其是县区事业单位、卫生系统、基层社区岗位）仍会考公基。

:::note
考事业单位前先看**报考公告的笔试科目**：联考一般考「职测 + 综应」；单独招聘可能考「公基」或「公基 + 专业知识」。科目不同，备考方向完全不同。
:::

## 公基 vs 职测常识判断

| 维度 | 职测·常识判断 | 公共基础知识 |
| --- | --- | --- |
| 题量 | 约 20 题（整卷一部分） | **一整科**，几十到上百题 |
| 广度 | 广而浅 | 广而深，要求系统掌握 |
| 侧重 | 时政、法律、人文 | 政治理论、法律、经济、公文、时政 |
| 出题方式 | 单选为主 | 单选 + 多选 + 判断，多选题难 |

:::key
**公基是「背多分」科目**——知识面广、深度要求高，但规律性强，短期突击能明显提分。相比行测的「能力测试」，公基更像「知识测试」。
:::

## 公基十大模块

| 模块 | 考察内容 | 重要性 |
| --- | --- | --- |
| **政治理论** | 习近平新时代中国特色社会主义思想、党史党建、时政 | ★★★★★ 绝对重点 |
| **法律** | 宪法、民法、刑法、行政法、民法典 | ★★★★★ |
| **经济** | 马克思主义政治经济学、宏观经济、微观经济 | ★★★★ |
| **公文写作与处理** | 公文种类、格式、行文规则 | ★★★★ |
| **管理学** | 管理原理、行政管理 | ★★★ |
| **人文历史** | 中国古代史、近现代史、文化常识 | ★★★ |
| **科技常识** | 前沿科技、生活科技 | ★★★ |
| **地理国情** | 中国地理、**陕西省情** | ★★★ |
| **事业单位制度** | 事业单位人事管理、聘用合同 | ★★★ |
| **道德与礼仪** | 公民道德、职业道德、礼仪 | ★★ |

## 高频考点提醒

1. **政治理论是半壁江山**：二十大、二十届三中全会、政府工作报告、中央经济工作会议，务必吃透。
2. **法律重点**：民法典（民事行为能力、合同、侵权责任）、刑法（犯罪构成、刑罚）、宪法（公民权利义务、国家机关）、行政法（行政许可、处罚、复议、诉讼）。
3. **公文**：15 种公文文种的适用范围、格式要素（标题、主送机关、成文日期）、行文规则。
4. **陕西省情**：陕西的地形地貌（陕北高原、关中平原、陕南秦巴山区）、关中平原城市群、秦创原、秦岭生态保护、历史文化（长安、延安、黄帝陵）等，常考。
5. **事业单位制度**：聘用合同期限、岗位设置（管理/专技/工勤）、考核制度、职称评聘。

## 备考建议

1. **先搭框架再填充**：按模块画思维导图，把散知识点串成体系。
2. **时政滚动积累**：公基时政考到考前 1—2 个月，考前集中背最新时政。
3. **多选是分水岭**：多选题少选得部分分、错选不得分，平时专门练多选的「保守策略」。
4. **刷题 + 记忆结合**：公基靠刷题加深印象，错题反复看。
5. **针对性复习省情**：报考陕西单位，务必掌握陕西版块的省情考点。

## 常见问题

**陕西事业单位联考考不考公基？**
> 联考统一笔试科目是「职测 + 综应」，**不直接考公基**（但职测常识判断中会涉及公基内容）。单独招聘才可能考公基，看岗位公告。

**公基和申论/综应冲突吗？**
> 不冲突。公基是**客观题知识测试**，综应是**主观题能力测试**，两者备考方法不同。同时备考公基和综应的考生不多，一般是一主一辅。

**三支一扶考公基吗？**
> 陕西三支一扶招募笔试通常考「公基 + 专业知识」或「职业能力倾向测验」，以当年公告为准。
