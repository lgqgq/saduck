# 综合分析题

**综合分析** 是申论中**难度最高**的小题——要点分散、需要多角度思考、对逻辑要求高。但掌握「**是什么—为什么—怎么办**」的总思路，它也能稳定拿分。

## 题型识别

| 类型 | 问法 | 例子 |
| --- | --- | --- |
| **解释分析** | 谈谈对……的理解/含义 | 「谈谈你对『一根扁担两头挑』的理解」 |
| **评论分析** | 谈谈对……的看法/评价 | 「对网络直播带货这一现象，谈谈你的看法」 |
| **比较分析** | 比较……的异同 | 「比较 A 村与 B 村发展模式的异同」 |
| **启示分析** | 谈谈……的启示 | 「分析先进典型对基层治理的启示」 |

## 总思路：是什么—为什么—怎么办

无论哪种分析题，都围绕这个主线组织答案：

1. **是什么**：亮明观点/解释含义（一句话）。
2. **为什么**：分析原因、影响、意义、问题（多角度展开）。
3. **怎么办**：提出对策或谈借鉴（简要）。

## 四类题型的具体结构

### 1. 解释分析

**结构（总分总）**：
1. **解释内涵**：用通俗语言解释题干句子的含义；
2. **分析论证**：从材料中找依据，说明为什么这样说（现状、问题、原因、影响）；
3. **总结升华**：点明启示或对策。

> 作答示例框架：
> 「这句话的含义是……（解释）。
> 其背后反映的是……（现状/问题）；之所以如此，是因为……（原因）；这带来了……（影响）。
> 因此，需要……（对策/启示）。」

### 2. 评论分析

**结构（总分总）**：
1. **亮明观点**：支持/反对/辩证看待（**观点要明确，不能模棱两可**）；
2. **论证分析**：陈述理由（积极的方面 + 存在的问题）；
3. **给出对策**：扬长避短、完善改进。

### 3. 比较分析

**结构（总分总）**：
1. **总述**：说明比较的意义或结论；
2. **分项比较**：从目标、方式、成效、适用条件等维度逐项对比；
3. **总结启示**：优劣取舍、借鉴方向。

### 4. 启示分析

**结构（总分）**：
1. **总述**：指出启示的核心方向；
2. **分条启示**：从材料中的做法提炼「我们应该怎么做」。
- **注意**：启示题不重述材料，只写「行动启示」（我们应该……）。

## 综合分析两大要求

1. **多角度思考**：从不同视角找到与分析对象相关的**问题、原因、影响、对策**等要点——同一件事，既看正面也看负面，既看当下也看长远，既看内部也看外部。
2. **逻辑清晰**：解释、评论、比较类按「**总分总**」，启示类按「**总分**」。不要想到哪写到哪。

## 常见丢分点

| 问题 | 对策 |
| --- | --- |
| 观点不明确 | 首句直接表态，用「值得肯定」「存在问题」「应辩证看待」等 |
| 分析就事论事 | 上升到制度、机制、理念层面分析 |
| 只分析不落地 | 结尾补一条对策/启示 |
| 逻辑混乱 | 严格按「是什么—为什么—怎么办」展开 |

## 关键词与表达积累

| 场景 | 规范表达 |
| --- | --- |
| 亮观点 | 值得肯定 / 利大于弊 / 应辩证看待 / 出发点值得肯定，但落实存在问题 |
| 析原因 | 一方面……另一方面……；深层次原因是…… |
| 谈影响 | 有利于……；制约了……；如果处理不当，将…… |
| 提对策 | 应加强……；须完善……；要建立健全…… |

## 示例（解释分析）

> 题目：「给定资料提到『慢生活也是一种生产力』，请谈谈你对这句话的理解。」
>
> **作答要点结构**：
> 1. **解释**：「慢生活」并非低效，而是通过优化节奏、提升品质，反哺经济与社会发展；
> 2. **分析**：当下生活节奏过快、焦虑蔓延，透支了健康与创造力（原因）；适度「慢下来」能促进消费升级、带动文旅康养、激发创新潜能（影响/意义）；
> 3. **总结**：应统筹快与慢，完善公共服务，让群众在快节奏中也有慢的获得感。

:::tip
综合分析题**答题逻辑比字数更重要**。先列提纲（观点 → 2—3 个分析维度 → 对策），再动笔，条理清晰就是高分。
:::
