# 贯彻执行题（公文 / 应用文）

**贯彻执行** 是「归纳概括 + 格式 + 身份语气」的组合题——内容从材料里找，格式按文种来，语气贴合身份。它是申论小题中的「重头戏」，分值和字数都高。

## 题型识别

- 写一份**倡议书 / 通知 / 报告 / 请示 / 讲话稿 / 宣传稿 / 调研报告 / 工作方案 / 简报** 等。
- 问法通常给定**文种、身份、目的**：如「假如你是某市文旅局工作人员，请拟写一份关于开展文明旅游宣传的倡议书」。

## 公文格式四要素

| 要素 | 格式要求 |
| --- | --- |
| **标题** | 居中书写，形式一般为「**发文机关 + 事由 + 文种**」，如《XX 市关于开展文明旅游宣传的倡议书》 |
| **发文对象（称谓）** | 另起一行**左顶格**书写，后加冒号，如「广大市民朋友们：」 |
| **正文** | 由**开头（发文事由）、主体（内容要点）、结语（号召/要求）** 组成，每段开头空两格 |
| **落款** | **发文单位 + 发文日期**，靠右书写 |

:::key
**格式是硬分**。标题居中、称谓顶格、落款靠右——格式错了会明显扣分。考前把常见文种格式背熟，考场不慌。
:::

## 常见文种速查

| 文种 | 用途 | 结构特点 |
| --- | --- | --- |
| **倡议书** | 面向公众发起倡导 | 背景目的 + 具体倡议（分条）+ 呼吁号召 |
| **通知** | 布置工作、告知事项 | 通知缘由 + 具体事项（分条）+ 执行要求 |
| **报告** | 向上级汇报 | 工作情况 + 成效问题 + 下步打算 |
| **请示** | 向上级请求批准 | 请示缘由 + 请示事项 + 恳请批复 |
| **讲话稿** | 会议发言 | 开场问候 + 主体内容 + 结尾号召 |
| **宣传稿/新闻稿** | 宣传报道 | 导语（时间地点事件）+ 主体 + 意义 |
| **调研报告** | 反映调查研究成果 | 背景目的 + 现状问题 + 原因分析 + 对策建议 |
| **工作方案** | 部署安排工作 | 目标 + 任务分工 + 实施步骤 + 保障措施 |
| **工作汇报/总结** | 总结工作 | 成绩做法 + 问题不足 + 下一步计划 |
| **简报** | 内部信息交流 | 标题 + 开头概述 + 分条内容 |

## 作答三步骤

### 第一步：审清题意
明确**文种**（决定格式）、**身份**（决定语气）、**对象**（发给谁）、**目的**（要解决什么）。

### 第二步：理清内容
按「**发文事由 → 主体内容 → 结语**」从材料中提炼要点：
- **发文事由**：背景、依据、目的、意义（简写）；
- **主体内容**：本题得分重心，要点分条展开（对策、倡议、事项等）；
- **结语**：号召、要求或恳请（视文种）。

### 第三步：规范落笔
格式正确 + 内容踩点 + 语言符合身份（下级对上级用请示语气、面向群众用亲切语气）。

## 示例框架（倡议书）

```
                文明旅游倡议书

广大游客朋友们：

    旅游是展示文明的窗口。当前正值旅游旺季，为营造文明有序
的旅游环境，特发出如下倡议：
    一、遵守秩序，文明游览，爱护公共设施；
    二、保护生态，不乱扔垃圾，不损坏文物古迹；
    三、理性消费，尊重当地风俗，维护合法权益。
    让我们共同携手，从我做起，争做文明游客！

                                ××市文化和旅游局
                                2026 年 × 月 × 日
```

## 常见丢分点

| 问题 | 对策 |
| --- | --- |
| 格式缺失（标题/称谓/落款） | 先写格式骨架，再填内容 |
| 只有套话没内容 | 内容从材料提炼，格式是壳、内容是核 |
| 语气不符身份 | 明确「我是谁、写给谁」，调整措辞 |
| 主体内容遗漏要点 | 主体部分按要点分条，宁多勿漏 |
| 字数不够/超太多 | 主体详略得当，发文事由、结语从简 |

## 备考建议

1. **格式背诵表**：把常见文种的格式差异整理成表（标题、称谓、正文、落款是否齐全），考前过一遍。
2. **内容优先**：格式只占一小部分分，**踩点内容占大头**——别为了格式丢了内容。
3. **多练真题**：贯彻执行真题几乎年年必考，练熟 5—10 篇就有手感。
4. **积累规范词**：方案的「保障措施」、报告的「存在不足」、请示的「妥否，请批示」等固定表达要会用。

:::tip
贯彻执行题的实质是「**先确定格式骨架，再把归纳概括的要点装进去**」。内容用得上归纳概括的能力，格式靠背诵——两者结合就能拿高分。
:::
