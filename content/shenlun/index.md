# 申论总览

**申论** 是测查从事机关工作应当具备的基本能力的考试科目，全部为**主观性试题**，由注意事项、给定资料、作答要求三部分组成。它是公务员（国考/省考）和事业单位（综应）笔试共同的核心科目，也是**拉开分差、决定上限**的科目。

## 为什么申论是「胜负手」

1. **行测决定下限、申论决定上限**：行测靠长期积累、短期难有大突破；申论方法到位 + 素材到位，短期内即可明显提分。
2. **多数人放弃申论**：考生普遍「重行测、轻申论」，你只要认真练申论，就能超过一大批对手。
3. **踩点拿分、确定性高**：小题答案要点来自材料，答全答准就能拿分，比行测的「蒙题」更可控。

## 申论考什么

申论核心测查 **五大能力**，对应五大题型：

| 能力 | 对应题型 |
| --- | --- |
| 阅读理解能力 | 归纳概括 |
| 综合分析能力 | 综合分析 |
| 提出和解决问题能力 | 提出对策 |
| 贯彻执行能力 | 贯彻执行（公文/应用文） |
| 文字表达能力 | 文章写作（大作文） |

## 试卷结构（以国考/陕西省考为例）

| 部分 | 内容 |
| --- | --- |
| 注意事项 | 考试要求、时限、填涂说明 |
| 给定资料 | 约 6000—8000 字，若干则材料 |
| 作答要求 | 4 道小题 + 1 篇大作文 |

## 作答时间分配（180 分钟）

| 环节 | 建议用时 |
| --- | --- |
| 读材料（带着问题读） | 40—50 分钟 |
| 小题 1—4 | 80—90 分钟 |
| 大作文 | 45—55 分钟 |
| 检查留白 | 5 分钟 |

:::warn
**大作文预留至少 45 分钟**。很多人前面小题写太慢，大作文草草收尾导致大丢分。先保证小题 + 大作文都能写完，再谈质量。
:::

## 高分核心逻辑

> **答案在材料里，要点是踩点得分，语言要规范。**

1. **小题**：从材料中找要点 → 提炼关键词 → 规范表达 → 分条作答。**踩点给分，宁多勿漏。**
2. **大作文**：立意（从材料主题出发）→ 结构（引论—本论—结论）→ 论证（道理论证 + 举例论证）→ 语言（规范、有文采）。
3. **卷面**：字迹工整、条理清晰，直接关系阅卷印象分。

## 阅卷怎么给分

- 申论由专家团队双人评阅、差分复评，实行**踩点得分 + 等级评分**结合。
- 小题：按采分点给分，要点全、表达准得高分，笼统空泛扣分。
- 大作文：按「**立意 + 结构 + 论证 + 语言 + 卷面**」分档给分（如一类文 30—40 分、四类文 0—10 分）。
- 套话连篇、直接抄材料、严重偏题，会被打低档分。

## 阅读材料的正确姿势

1. **先审题**：明确每道题问什么、答什么、多少字。
2. **边读边标**：用不同符号标出「问题、原因、影响、对策、案例、观点」。
3. **抓首尾句**：每段首尾句常是本段要点。
4. **看关键词**：但、然而、因此、总之、说明、指出——这些词后面往往跟着要点。
5. **整合归纳**：把分散要点按「总分/并列/递进」逻辑整合成条。

## 常见误区

| 误区 | 正确做法 |
| --- | --- |
| 只练行测不练申论 | 行测申论 1:1 时间投入 |
| 大作文靠背模板 | 模板只保底，内容靠立意与素材 |
| 小题答得又多又长 | 要点准而全，不堆废话 |
| 直接大段抄材料 | 提炼、概括、规范表达 |
| 不练整卷 | 平时限时整卷，考场才不会超时 |
