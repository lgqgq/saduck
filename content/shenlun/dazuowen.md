# 文章写作（大作文）

**大作文** 是申论分值最高的单题（国考/省考约 40—50 分），也是最让考生头疼的部分。核心认知：**大作文不靠文采取胜，靠「立意准确 + 结构清晰 + 论证有力」**。

## 立意的三个层级

1. **不偏题（保底）**：紧扣材料主题，不另起炉灶。偏题直接掉到低档分。
2. **准确（稳分）**：立意贴合题干与材料的核心观点。
3. **深刻（冲高）**：立意有高度、有角度，超越就事论事。

:::key
**立意的来源是「题干 + 材料」**：
- 题干中的**主题词、关键词**（如「基层治理」「青年担当」「数字中国」）是立意的锚点；
- 材料的**核心观点、政策表述**决定立意高度。
- 标题和总论点中，务必**亮出核心关键词**。
:::

## 文章结构（总分总）

| 部分 | 内容 | 占比 |
| --- | --- | --- |
| **引论（开头）** | 引题 + 亮明总论点 | 约 10% |
| **本论（主体）** | 2—3 个分论点 + 论证 | 约 70% |
| **结论（结尾）** | 总结升华 + 展望 | 约 10% |

### 分论点怎么定

分论点 = 总论点的分解。常见三种切分方式：

| 方式 | 例子（主题：基层治理现代化） |
| --- | --- |
| **并列式（维度）** | ① 治理重在党建引领；② 治理贵在群众参与；③ 治理新在科技赋能 |
| **递进式（层次）** | ① 夯实治理之基（制度）；② 激发治理之力（人才）；③ 提升治理之效（技术） |
| **因果式（逻辑）** | ① 治理为了谁（目标）；② 治理靠谁（主体）；③ 治理如何做（路径） |

## 论证方法（要多样）

| 方法 | 说明 | 示例 |
| --- | --- | --- |
| **道理论证** | 讲道理、分析因果 | 「民为邦本，本固邦宁，基层治理须以人民为中心」 |
| **举例论证** | 举典型事例 | 浙江「枫桥经验」、陕西乡村振兴样板村 |
| **对比论证** | 正反对比 | 重管理轻服务的短视 vs 服务型治理的长远 |
| **引用论证** | 引名言、政策 | 引用总书记论述、政策文件表述 |
| **数据论证** | 用数字支撑 | 某项投入增长数据、某项指标变化 |

> 每个分论点建议采用「**观点句 + 道理论证 + 举例论证 + 回扣观点**」的小结构。

## 开头写法（三种）

1. **引言式**：从名言、典故引入，顺势点题。
2. **背景式**：从现状、问题、政策切入，引出论点。
3. **对比式**：正反对比，凸显主题的重要性。

**示例（背景式）**：
> 当前，数字技术加速融入生产生活，为高质量发展注入强劲动力，同时也带来治理、伦理、安全等新课题。如何在数字化浪潮中既「乘势而上」又「行稳致远」，考验着治理智慧。

## 结尾写法（两种）

1. **总结回扣式**：总结分论点，回扣总论点。
2. **升华展望式**：上升到国家战略、时代使命，展望未来。

**示例**：
> 基层强则国家强，基层安则天下安。以党建引领定盘星、群众参与压舱石、科技赋能力增强，我们必能绘就基层善治新画卷，为高质量发展筑牢根基。

## 标题技巧

- **对仗式**：《以数字之翼，助腾飞之梦》
- **观点式**：《让创新成为高质量发展的第一动力》
- **引用式**：《民之所盼，政之所向》
- 标题要**短、亮、有观点**，出现核心关键词。

## 高分五要素

| 要素 | 要求 |
| --- | --- |
| 立意 | 准确、深刻、不偏题 |
| 结构 | 总分总、分论点清晰、层次分明 |
| 论证 | 多样、充实、有说服力 |
| 语言 | 规范、生动、善用排比与引用 |
| 卷面 | 字迹工整、段落清晰 |

## 备考建议

1. **每周一篇**：坚持每周完整写一篇大作文，练立意、练速度、练卷面。
2. **先列提纲**：动笔前 5 分钟列提纲（总论点 + 3 个分论点 + 每段要点），避免跑题。
3. **素材分类积累**：按「党建、基层、乡村振兴、科技、生态、民生、青年」分类积累（见[素材积累](sucai.html)）。
4. **范文仿写**：学范文的立意角度与论证结构，而不是背整篇。
5. **请人批改**：有条件找老师或有经验者批改，比自己闷头写进步快。

## 常见误区

| 误区 | 正确做法 |
| --- | --- |
| 堆砌名言套话 | 内容以分析论证为主，名言点到为止 |
| 大段抄材料 | 用自己的话论证，材料只作素材 |
| 观点模糊 | 首段亮明总论点，段首亮明分论点 |
| 只谈对策不分析 | 论证要「为什么」，不只是「怎么办」 |
| 结构失衡 | 开头结尾精简，主体部分充分展开 |

:::tip
大作文是**结构分 + 内容分 + 卷面分**的综合。先保证「不偏题 + 结构完整 + 字数达标」（稳拿二类文），再追求立意深度与论证文采（冲一类文）。稳扎稳打，比追求华丽更可靠。
:::
