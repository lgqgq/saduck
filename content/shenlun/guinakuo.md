# 归纳概括题

**归纳概括** 是申论的「地基」题型：归纳概括、综合分析、提出对策、贯彻执行的基础都是「从材料中找要点」。答好归纳概括，其他题型事半功倍。

## 题型识别

| 常见问法 | 实例 |
| --- | --- |
| 概括 | 「概括我国农业科技推广存在的主要问题」 |
| 归纳 | 「归纳总结 S 村产业发展的主要经验」 |
| 总结/提炼 | 「总结 M 市基层治理的主要做法」 |
| 启示 | 「分析 B 市的成功经验对 C 市的启示」 |

## 作答步骤

### 第一步：审题

- **对象**：概括什么问题/原因/做法/经验/影响/变化。
- **范围**：根据哪几则材料作答（未说明则通读全文找对应）。
- **要求**：字数限制、是否分条、是否「不超过 X 字」。
- **分值**：估要点数。一般 1 个采分点 2—3 分，据此判断要答几点。

### 第二步：阅读找点

- 用「圈点勾画」标出**问题、原因、对策、案例、观点、数据**。
- 抓关键词：**转折**（但是、然而、却）、**因果**（因此、所以、由于）、**总结**（总之、综上所述、这说明）。
- 注意**正反表述**：既找成绩也找问题，既找做法也找不足。

### 第三步：提炼整合

- 把口语化材料 → 规范表达：如材料说「村子里的路很烂」→「基础设施薄弱」。
- 合并同类项：多个细节归并成一个要点。
- 定序：按材料顺序或「总分」逻辑排列要点。

### 第四步：分条作答

```
一、基础设施薄弱。道路、水电等配套落后，制约发展。
二、人才支撑不足。青壮年外流，缺乏技术与管理人才。
三、产业同质化。结构单一，附加值低，抗风险能力弱。
```

## 三个关键要求

1. **要点齐全**：材料中的每个要点都要踩到，宁可多答不漏。**漏点是最大失分原因。**
2. **语言精炼**：用关键词表达，不写长句废话。字数紧张时优先保要点。
3. **逻辑清晰**：同类归并、分条呈现，避免要点散乱、重复。

## 常见陷阱

| 陷阱 | 对策 |
| --- | --- |
| 大段抄材料 | 提炼关键词，用自己的话概括 |
| 漏采分点 | 多读几遍，注意材料中的小细节 |
| 要点重复 | 合并同类项，不重复表述 |
| 语言口语化 | 用规范机关用语（积累见[素材积累](sucai.html)） |
| 超出字数 | 先写要点词，再压缩修饰语 |

## 一句话答题法

> **要点（关键词）+ 简要展开**。如：
> 「③群众参与度低。村民对项目不了解、不配合，参与意愿不足。」

## 进阶技巧

- **多角度找点**：从「主体」（政府、企业、群众）、「环节」（事前、事中、事后）、「维度」（经济、社会、生态、文化）多角度挖掘，避免漏点。
- **数字提炼**：材料中的数据背后往往有要点（如「70% 的外来务工人员子女随迁」→ 点出流动儿童教育问题）。
- **对比找差**：材料中的对比（过去 vs 现在、城市 vs 乡村）常隐含要点。

## 示例（要点型）

> 给定材料（节选）：某镇苹果产业虽种植面积大，但品种老化、管理粗放，部分果农盲目跟风扩种，导致品质参差、滞销时有发生；当地也缺乏专业农技人员指导……
>
> **问题类要点**：
> ① 品种老化，产业技术落后；
> ② 管理粗放，标准化程度低；
> ③ 盲目扩种，供需失衡、滞销；
> ④ 专业人才短缺，科技支撑不足。

:::tip
归纳概括是**踩点游戏**，不是写作题。平时练习对照参考答案，重点复盘「漏了哪个点、哪个点表达不规范」，这是提分最快的训练。
:::
