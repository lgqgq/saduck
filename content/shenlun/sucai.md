# 申论素材积累

申论大作文和贯彻执行都需要素材支撑。「**素材即弹药**」——平时分类积累，考场上才能信手拈来。

## 素材来源渠道

| 渠道 | 用途 |
| --- | --- |
| **学习强国** | 总书记重要讲话、重要文章、时政要闻 |
| **《人民日报》/ 人民日报评论** | 权威评论、社论，学立意与表达 |
| **《半月谈》** | 基层治理、民生话题，贴近申论材料 |
| **《求是》** | 理论文章，政治理论深度 |
| **陕西日报 / 陕西省人民政府网** | 陕西本土案例、政策 |
| **新华社 / 央视新闻** | 时政热点 |

## 按主题分类积累

### 1. 党建引领 / 政治建设
- 金句：「党政军民学，东西南北中，党是领导一切的。」
- 素材：基层党建引领社区治理、红色物业、「党建 + 网格」治理模式。

### 2. 基层治理
- 金句：「基层强则国家强，基层安则天下安。」
- 素材：**枫桥经验**（小事不出村、大事不出镇、矛盾不上交）、网格化管理、协商议事平台、数字治理（一网通办）。

### 3. 乡村振兴
- 金句：「民族要复兴，乡村必振兴。」
- 素材：产业振兴（一村一品）、人才振兴（大学生返乡）、文化振兴（乡风文明）、生态振兴（宜居宜业）、组织振兴（村两委）。
- **陕西案例**：陕南茶旅融合、陕北苹果产业、关中设施农业、汉中油菜花节。

### 4. 科技创新 / 高质量发展
- 金句：「发展新质生产力是推动高质量发展的内在要求和重要着力点。」
- 素材：数字经济、人工智能、专精特新企业、科技自立自强。
- **陕西案例**：**秦创原**创新驱动平台、西安综合性国家科学中心、先进制造业集群（新能源汽车、航空产业）。

### 5. 生态文明
- 金句：「绿水青山就是金山银山。」
- 素材：碳达峰碳中和、河湖长制、垃圾分类、生态补偿。
- **陕西案例**：**秦岭生态环境保护**、黄河流域生态保护和高质量发展（陕北黄土高原治理）、关中大气污染防治。

### 6. 民生保障
- 金句：「人民对美好生活的向往，就是我们的奋斗目标。」
- 素材：就业优先、一老一小（养老托育）、教育医疗资源均衡、保障性住房。

### 7. 青年担当 / 人才
- 金句：「青年强，则国家强。」
- 素材：新时代青年扎根基层、西部计划、选调生、人才强国战略。

### 8. 文化传承
- 金句：「文化自信是更基本、更深沉、更持久的力量。」
- 素材：非遗保护、文旅融合、城市更新中留住乡愁。
- **陕西案例**：**长安文化、延安精神**、西安文旅（大唐不夜城）、丝路文化（中欧班列长安号）。

## 常用规范表达

**四字短语（高频）**：
- 人才：引进人才、留住人才、用好人才、人尽其才
- 服务：优化服务、简政放权、一网通办、便民利企
- 治理：共建共治共享、自治法治德治、源头治理、精细化管理
- 发展：高质量发展、转型升级、创新驱动、绿色发展
- 民生：就业优先、精准帮扶、补齐短板、兜牢底线

**长句式开头**：
- 「站在新的历史起点上，……」
- 「当前，……已成为社会关注的焦点。」
- 「民之所盼，政之所向。……是……的题中应有之义。」

## 素材使用原则

1. **宁缺毋滥**：素材是佐证观点的，不是堆砌。每个分论点用 1—2 个贴切素材即可。
2. **准确第一**：人名、地名、政策表述务必准确，写错比不写更糟。
3. **本土加分**：报考陕西，答题多用陕西案例（秦岭、秦创原、延安精神、长安文化），体现对省情的了解（面试尤其重要）。
4. **常读常新**：每周更新时政，素材「保质期」有限。

## 素材本整理法

```
主题：基层治理
- 金句：基层强则国家强，基层安则天下安。
- 案例：枫桥经验 / 陕西网格化治理 / 社区协商议事
- 规范词：共建共治共享、源头化解、五社联动
- 可用题型：大作文分论点、综合分析、提出对策
```

:::tip
**素材本要「少而精」**：每个主题记 1—2 句金句、2—3 个案例、3—5 个规范词即可，贪多嚼不烂。考前一周集中回顾。
:::
