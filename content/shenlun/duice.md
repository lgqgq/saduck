# 提出对策题

**提出对策** 测查发现问题、解决问题的能力。核心不是「想点子」，而是**从材料中发现问题，再推导出针对性、可落地的对策**。

## 题型识别

| 问法 | 例子 |
| --- | --- |
| 提出措施 | 「针对 Y 市就业服务存在的问题，提出解决措施」 |
| 提出建议 | 「就解决农村留守儿童问题提出建议」 |
| 如何解决 | 「谈谈如何解决农产品滞销问题」 |
| 改进意见 | 「为改进政务服务中心服务提出改进意见」 |

## 作答步骤

### 第一步：找问题

先穷尽材料中的问题（什么问题对应什么原因），**对策必须与问题一一对应**。

### 第二步：区分对策来源

| 来源 | 含义 | 例子 |
| --- | --- | --- |
| **直接对策** | 材料里明说的做法 | 「村里建起了电商服务站」→「完善电商服务网络」 |
| **间接对策** | 从问题/原因反推 | 「缺少农技人才」→「加强人才引进与培训」 |
| **经验借鉴** | 借鉴成功地区做法 | 「B 市实行积分制」→「推广积分制管理」 |

### 第三步：对策具体化

**笼统的对策不得分**。对策要回答「谁来做、做什么、怎么做」：

| 笼统 | 具体 |
| --- | --- |
| 加强人才建设 | 引进对口专业人才，组织定期农技培训，落实人才补贴政策 |
| 完善基础设施 | 统筹资金实施道路硬化、管网改造，建立日常维护机制 |
| 加强宣传引导 | 通过村广播、微信群、入户宣讲普及政策，提高知晓率 |

## 高频问题 → 对策对应表

| 问题 | 对策方向 |
| --- | --- |
| 人才不足 | 引才（待遇、平台）＋育才（培训）＋留才（环境、晋升）＋用才 |
| 资金短缺 | 财政投入、专项资金、社会资本、金融支持（贷款、保险） |
| 基础设施落后 | 规划先行、统筹建设、管养并重 |
| 技术落后 | 科技支撑、产学研合作、成果转化、数字化赋能 |
| 意识不强/观念落后 | 宣传教育、典型示范、奖罚并重 |
| 监管不力 | 完善制度、明确责任、联合执法、智能监管、畅通举报 |
| 服务不足 | 一网通办、流程优化、窗口下沉、代办帮办 |
| 产业同质化 | 品牌化、深加工、延链条、差异化定位 |

## 作答结构

**分条作答，一问题一对策**：

```
① 针对农技人才短缺问题：……（引才育才留才的具体做法）。
② 针对销售渠道单一问题：……（电商、订单农业、品牌建设）。
③ 针对品质参差不齐问题：……（标准化种植、质量监管、认证）。
```

## 三个得分关键

1. **针对性**：对策针对材料中的具体问题，不空喊口号。
2. **可行性**：符合实际、可执行（有主体、有措施、有保障）。
3. **具体化**：把对策写实写细，拒绝「高度重视、加强领导、狠抓落实」式空话。

## 常见丢分点

| 问题 | 对策 |
| --- | --- |
| 对策与问题脱节 | 先列问题，再逐一对策 |
| 对策空洞套话 | 细化实施手段和操作步骤 |
| 只有对策没有操作 | 补充主体、抓手、机制 |
| 对策堆砌无逻辑 | 按轻重缓急或模块排序 |

## 常用对策表达

- **制度机制**：建立健全……制度；完善……考核激励机制；形成……长效机制
- **技术手段**：运用大数据、人工智能赋能；推进数字政务；完善监管平台
- **多元参与**：政府引导、市场运作、社会参与；发挥社会组织与群众自治作用
- **宣传引导**：创新宣传方式，线上线下结合；典型示范引领

:::tip
提出对策题可以**直接复用**到综合分析、贯彻执行（方案、建议）甚至大作文的分论点里。把「问题—对策」的对应练熟，一题多用。
:::
